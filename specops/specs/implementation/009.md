# Implementation: DuplicateFareMediaValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/duplicate_fare_media.py`

No shared utilities needed. This is a single-table validator with no
cross-table joins, no date logic, and no dependencies on other helpers.

## 2. Function Signature

```python
from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_duplicate_fare_media(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,

```

The `ctx` argument is unused but included to satisfy the standard
validator signature.

## 3. Notice Definitions

All notices have severity **WARNING**.

### `duplicate_fare_media`

Emitted when two distinct fare media entries share the same
`(fare_media_name, fare_media_type)` combination. Each duplicate row
after the first produces a separate notice paired with the first
occurrence.

```python
Notice(
    code="duplicate_fare_media",
    severity=Severity.WARNING,
    fields={
        "csv_row_number_1": <int>,     # row number of first occurrence
        "fare_media_id_1": <str>,      # ID of first occurrence
        "csv_row_number_2": <int>,     # row number of duplicate
        "fare_media_id_2": <str>,      # ID of duplicate
    },
)
```

Referenced file: `fare_media.txt`.

## 4. Implementation Approach

```
function validate_duplicate_fare_media(feed, ctx):
    # 1. Guard: table must exist and be non-empty
    if "fare_media" not in feed or feed["fare_media"].is_empty():
        return []

    df = feed["fare_media"]

    # 2. Select relevant columns and add row index
    #    The loader provides a 0-based row_number column or we use
    #    pl.int_range for the csv_row_number (1-based).
    #    Use with_row_index() to get a deterministic row order,
    #    then add 1 to convert to 1-based csv_row_number.
    df = df.with_row_index("_idx").with_columns(
        (pl.col("_idx") + 1).alias("csv_row_number")
    )

    # 3. Fill null fare_media_name with empty string so null-null matches
    df = df.with_columns(
        pl.col("fare_media_name").fill_null("").alias("fare_media_name")
    )

    # 4. Group by composite key (fare_media_name, fare_media_type)
    #    and filter to groups with more than one row
    groups = df.group_by("fare_media_name", "fare_media_type").agg(
        pl.col("csv_row_number"),
        pl.col("fare_media_id"),
    ).filter(pl.col("csv_row_number").list.len() > 1)

    # 5. Emit notices: pair first row with each subsequent row
    notices = []
    for row in groups.iter_rows(named=True):
        row_numbers = row["csv_row_number"]
        media_ids = row["fare_media_id"]

        first_row_number = row_numbers[0]
        first_media_id = media_ids[0]

        for i in range(1, len(row_numbers)):
            notices.append(
                Notice(
                    code="duplicate_fare_media",
                    severity=Severity.WARNING,
                    fields={
                        "csv_row_number_1": first_row_number,
                        "fare_media_id_1": first_media_id,
                        "csv_row_number_2": row_numbers[i],
                        "fare_media_id_2": media_ids[i],
                    },
                )
            )

    return notices
```

**Key design decisions:**

- **`with_row_index` for csv_row_number.** The loader preserves row
  order. `with_row_index` gives a 0-based index; adding 1 yields the
  1-based csv_row_number matching the Java convention.
- **`fill_null("")` on fare_media_name.** Ensures two rows with null or
  missing names and the same type are grouped together, matching the
  Java behavior where `fareMediaName()` returns an empty string when
  not set.
- **Polars `group_by` + `agg` with list collection.** Groups by the
  composite key and collects row numbers and IDs as lists. Filtering
  to `list.len() > 1` discards unique entries efficiently.
- **Python iteration for notice emission.** The number of duplicate
  groups is expected to be very small (fare_media tables are typically
  tens of rows), so iterating over groups in Python is appropriate.
  The first element of each list is always the "left" side of the
  notice, and every subsequent element is paired with it.
- **Deterministic pairing.** `group_by` with `agg` on list columns
  preserves insertion order within each group, so the first row seen
  in the original data is always `row_numbers[0]`. If Polars does not
  guarantee intra-group order, add `.sort("csv_row_number")` before
  the `group_by` to ensure it.

## 5. Registry Entry

In `src/gtfs_validator/validators/__init__.py`, add the import and
registry entry:

```python
from gtfs_validator.validators.duplicate_fare_media import validate_duplicate_fare_media

# Add to VALIDATOR_REGISTRY list:
ValidatorEntry(
    name="duplicate_fare_media",
    fn=validate_duplicate_fare_media,
    requires=["fare_media"],
),
```

The `requires` list specifies `"fare_media"` as the sole required table.
The runner will skip this validator if `fare_media.txt` is not present
in the feed.
