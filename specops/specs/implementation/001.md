# Implementation: AgencyConsistencyValidator

## 1. Module Location

`src/gtfs_validator/validators/agency_consistency.py`

This is a new file. No existing validator file covers agency-level consistency
checks. The validator operates exclusively on `agency.txt`.

## 2. Function Signature

```python
import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_agency_consistency(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice Definitions

### `missing_recommended_field` (WARNING)

Emitted when a single agency exists but has no `agency_id`. This is a generic
notice code reused across validators.

```python
Notice(
    code="missing_recommended_field",
    severity=Severity.WARNING,
    fields={
        "filename": "agency.txt",
        "csv_row_number": <int>,      # 1-based row index
        "field_name": "agency_id",
    },
)
```

### `missing_required_agency_id` (ERROR)

Emitted when multiple agencies exist and any row lacks `agency_id`. This is a
shared notice also used by route and fare_attribute validators.

```python
Notice(
    code="missing_required_agency_id",
    severity=Severity.ERROR,
    fields={
        "filename": "agency.txt",
        "csv_row_number": <int>,
        "agency_name": <str>,
    },
)
```

### `inconsistent_agency_timezone` (ERROR)

Emitted when any agency has a different timezone than the first agency.

```python
Notice(
    code="inconsistent_agency_timezone",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": <int>,
        "expected": <str>,            # e.g. "America/Montreal"
        "actual": <str>,
    },
)
```

### `inconsistent_agency_lang` (WARNING)

Emitted when any agency has a different language than the first agency that
specified one.

```python
Notice(
    code="inconsistent_agency_lang",
    severity=Severity.WARNING,
    fields={
        "csv_row_number": <int>,
        "expected": <str>,            # e.g. "en"
        "actual": <str>,
    },
)
```

## 4. Implementation Approach

Use Polars expressions on an eager DataFrame. The agency table is always small
(typically 1-10 rows), so eager mode is appropriate.

### Pseudocode

```python
def validate_agency_consistency(feed, ctx):
    notices = []

    # Guard: skip if agency table missing or empty
    if "agency" not in feed:
        return notices
    df = feed["agency"]
    if df.is_empty():
        return notices

    row_count = len(df)

    # --- Single-agency path ---
    if row_count == 1:
        # Check if agency_id is null or empty string
        val = df["agency_id"][0]
        if val is None or val == "":
            notices.append(Notice(
                code="missing_recommended_field",
                severity=Severity.WARNING,
                fields={
                    "filename": "agency.txt",
                    "csv_row_number": 1,
                    "field_name": "agency_id",
                },
            ))
        return notices

    # --- Multi-agency path ---

    # Step 2a: Required agency_id check
    # Add a row_number column (1-based) for notice reporting
    df = df.with_row_index("_row_idx")
    missing_id = df.filter(
        pl.col("agency_id").is_null() | (pl.col("agency_id") == "")
    )
    for row in missing_id.iter_rows(named=True):
        notices.append(Notice(
            code="missing_required_agency_id",
            severity=Severity.ERROR,
            fields={
                "filename": "agency.txt",
                "csv_row_number": row["_row_idx"],
                "agency_name": row["agency_name"],
            },
        ))

    # Step 2b: Timezone consistency
    expected_tz = df["agency_timezone"][0]
    tz_mismatch = df.filter(
        (pl.col("_row_idx") > 0)
        & (pl.col("agency_timezone") != expected_tz)
    )
    for row in tz_mismatch.iter_rows(named=True):
        notices.append(Notice(
            code="inconsistent_agency_timezone",
            severity=Severity.ERROR,
            fields={
                "csv_row_number": row["_row_idx"],
                "expected": expected_tz,
                "actual": row["agency_timezone"],
            },
        ))

    # Step 2c: Language consistency
    non_null_lang = df.filter(
        pl.col("agency_lang").is_not_null()
        & (pl.col("agency_lang") != "")
    )
    if len(non_null_lang) > 0:
        expected_lang = non_null_lang["agency_lang"][0]
        lang_mismatch = non_null_lang.filter(
            pl.col("agency_lang") != expected_lang
        )
        for row in lang_mismatch.iter_rows(named=True):
            notices.append(Notice(
                code="inconsistent_agency_lang",
                severity=Severity.WARNING,
                fields={
                    "csv_row_number": row["_row_idx"],
                    "expected": expected_lang,
                    "actual": row["agency_lang"],
                },
            ))

    return notices
```

### Key design decisions

- **`with_row_index("_row_idx")`**: Adds a 0-based row index column used for
  `csv_row_number` in notices. The analysis spec uses 0-based indexing for
  multi-agency rows (row 0 = first row, row 1 = second row). For single-agency
  the row number is 1 (matching the Java `csvRowNumber` which is 1-based after
  header). Confirm exact row numbering convention with test fixtures and adjust
  if needed.
- **Null-or-empty check**: `agency_id` may be null (missing column value) or
  empty string (present but blank). Both are treated as missing.
- **`iter_rows(named=True)`**: Safe here because agency tables are tiny. Avoids
  collecting to Python lists while still giving named access.
- **First-row baseline**: Timezone uses `df["agency_timezone"][0]`. Language
  uses the first non-null value from the filtered subset.

## 5. Registry Entry

Add to `src/gtfs_validator/validators/__init__.py`:

```python
from gtfs_validator.validators.agency_consistency import validate_agency_consistency

VALIDATOR_REGISTRY: list[ValidatorEntry] = [
    ValidatorEntry(
        name="agency_consistency",
        fn=validate_agency_consistency,
        requires=["agency"],
    ),
]
```

The `requires` list contains only `"agency"` since this validator reads no
other tables. The runner will skip this validator if the agency table failed to
load.

## 6. Test Plan

Test file: `tests/test_validators/test_agency_consistency.py`

All tests construct minimal `pl.DataFrame` inputs and call
`validate_agency_consistency` directly, asserting on returned notice codes,
severities, counts, and field values.

### `test_single_agency_missing_agency_id`
- **Input**: 1-row agency DataFrame with `agency_id=None`
- **Expected**: 1 notice with code `"missing_recommended_field"`, severity
  `WARNING`, fields `filename="agency.txt"`, `field_name="agency_id"`

### `test_multi_agency_missing_agency_id`
- **Input**: 2-row agency DataFrame. Row 0 has `agency_id="first agency"`,
  row 1 has `agency_id=None`, `agency_name="agency name"`
- **Expected**: 1 notice with code `"missing_required_agency_id"`, severity
  `ERROR`, fields include `agency_name="agency name"`

### `test_inconsistent_timezone`
- **Input**: 2-row agency DataFrame. Row 0 timezone `"America/Bogota"`,
  row 1 timezone `"America/Montreal"`
- **Expected**: 1 notice with code `"inconsistent_agency_timezone"`, severity
  `ERROR`, `expected="America/Bogota"`, `actual="America/Montreal"`

### `test_consistent_timezone`
- **Input**: 2-row agency DataFrame. Both timezone `"America/Montreal"`,
  both language `"en"`
- **Expected**: 0 notices

### `test_inconsistent_language`
- **Input**: 2-row agency DataFrame. Row 0 language `"en"`, row 1 language
  `"fr"`
- **Expected**: 1 notice with code `"inconsistent_agency_lang"`, severity
  `WARNING`, `expected="en"`, `actual="fr"`

### `test_consistent_language`
- **Input**: 2-row agency DataFrame. Both language `"en"`
- **Expected**: 0 notices

### `test_some_languages_null_rest_consistent`
- **Input**: 3-row agency DataFrame. Row 0 `agency_lang=None`, rows 1-2
  `agency_lang="fr"`
- **Expected**: 0 notices (null is skipped; both non-null values match)

### `test_agency_table_missing`
- **Input**: `feed` dict with no `"agency"` key
- **Expected**: 0 notices (early return)

### `test_agency_table_empty`
- **Input**: `feed` dict with `"agency"` mapped to a 0-row DataFrame
- **Expected**: 0 notices (early return)

### `test_single_agency_with_agency_id`
- **Input**: 1-row agency DataFrame with `agency_id="a1"` present
- **Expected**: 0 notices (single agency with ID present is valid; no
  timezone/language checks run)
