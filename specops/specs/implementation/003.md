## 1. Module Location

`src/gtfs_validator/validators/pathways.py`

Future pathway validators (e.g., pathway length checks, stair count checks)

## 2. Function Signature

```python
import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_bidirectional_exit_gate(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice Definitions

### `bidirectional_exit_gate` (ERROR)

Emitted when a row in `pathways.txt` has `pathway_mode == 7` (EXIT_GATE)
and `is_bidirectional == 1` (BIDIRECTIONAL). Exit gates are physically
one-way and must not be marked as bidirectional.

```python
Notice(
    code="bidirectional_exit_gate",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": <int>,       # 1-based row number
        "pathway_mode": <int>,         # always 7 when this notice fires
        "is_bidirectional": <int>,     # always 1 when this notice fires
    },
)
```

## 4. Implementation Approach

```
function validate_bidirectional_exit_gate(feed, ctx):
    # 1. Guard: table must exist
    if "pathways" not in feed:
        return []

    df = feed["pathways"]

    # 2. Guard: empty DataFrame
    if df.is_empty():
        return []

    # 3. Vectorized filter: pathway_mode == 7 AND is_bidirectional == 1
    violations = df.filter(
        (pl.col("pathway_mode") == 7) & (pl.col("is_bidirectional") == 1)
    )

    # 4. Emit notices for each violating row
    notices = []
    for row in violations.iter_rows(named=True):
        notices.append(
            Notice(
                code="bidirectional_exit_gate",
                severity=Severity.ERROR,
                fields={
                    "csv_row_number": row["csv_row_number"],
                    "pathway_mode": row["pathway_mode"],
                    "is_bidirectional": row["is_bidirectional"],
                },
            )
        )

    return notices
```

**Key Polars idioms used:**

- `df.filter(expr1 & expr2)` for a simple vectorized two-condition filter.
- `iter_rows(named=True)` to emit per-row notices (acceptable because only
  violating rows are iterated, which is typically a tiny subset).

**No null handling needed:** Both `pathway_mode` and `is_bidirectional` are
required fields (`Presence.REQUIRED`) in the `PATHWAYS` schema definition.
Load-time validation enforces their presence before this validator runs,
so null values will not reach this check.

**No column-existence guard needed:** Both columns are required schema fields.
If `pathways.txt` exists in the feed, the loader guarantees these columns
are present in the DataFrame.

## 6. Test Plan

Test file: `tests/test_validators/test_pathways.py`

All tests construct minimal `feed` dicts with Polars DataFrames and call
`validate_bidirectional_exit_gate` directly.

### Test 1: `test_bidirectional_exit_gate_generates_notice`
- **Input:** One row: `csv_row_number=1`, `pathway_mode=7`,
  `is_bidirectional=1`.
- **Expected:** Exactly one notice with `code="bidirectional_exit_gate"`,
  `severity=ERROR`, `fields={"csv_row_number": 1, "pathway_mode": 7,
  "is_bidirectional": 1}`.

### Test 2: `test_unidirectional_exit_gate_no_notice`
- **Input:** One row: `csv_row_number=1`, `pathway_mode=7`,
  `is_bidirectional=0`.
- **Expected:** No notices.

### Test 3: `test_bidirectional_non_exit_gate_no_notice`
- **Input:** Six rows, one for each non-exit-gate `pathway_mode` (1-6),
  all with `is_bidirectional=1`.
- **Expected:** No notices for any row.

### Test 4: `test_missing_pathways_table`
- **Input:** `feed` dict has no `"pathways"` key.
- **Expected:** Empty list.

### Test 5: `test_empty_dataframe`
- **Input:** `"pathways"` key exists with a zero-row DataFrame containing
  columns `csv_row_number`, `pathway_mode`, `is_bidirectional`.
- **Expected:** Empty list.

### Test 6: `test_multiple_rows_mixed`
- **Input:** Three rows:
  - `pathway_mode=7`, `is_bidirectional=1` (violation)
  - `pathway_mode=7`, `is_bidirectional=0` (valid)
  - `pathway_mode=6`, `is_bidirectional=1` (valid)
- **Expected:** Exactly one notice, for the first row only.

### Test 7: `test_multiple_violations`
- **Input:** Two rows both with `pathway_mode=7`, `is_bidirectional=1`,
  at `csv_row_number=2` and `csv_row_number=5`.
- **Expected:** Two notices with matching `csv_row_number` values.
