# Implementation: ShapeUsageValidator

## 1. Module location

```
src/gtfs_validator/validators/shape_usage.py
```

## 2. Function signature

```python
def validate_shape_usage(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted but unused; the validator is purely a cross-table set-membership check.

## 3. Notice definitions

### `unused_shape` — WARNING

Emitted once per distinct `shape_id` in `shapes.txt` that has no matching row in `trips.txt`.

```python
Notice(
    code="unused_shape",
    severity=Severity.WARNING,
    fields={
        "shape_id": str,          # the unreferenced shape_id
        "csv_row_number": int,    # csv_row_number of its first appearance in shapes.txt
    },
)
```

The `fields` dict contains exactly two keys: `shape_id` and `csv_row_number`.

## 4. Implementation approach

### Guard clauses (return `[]` immediately if)

1. `"shapes"` is not in `feed`, or `feed["shapes"]` is empty — nothing to check.
2. `"trips"` is not in `feed` — treat trips as empty; all shapes are unused, so continue with an empty reference set rather than returning early.

### Algorithm (Polars, anti-join approach)

```
# Step 1: build a deduplicated DataFrame of shape_ids referenced by trips
IF "trips" in feed AND NOT feed["trips"].is_empty():
    trips_shape_ids_df = (
        feed["trips"]
        .select("shape_id")
        .filter(col("shape_id").is_not_null() & (col("shape_id") != ""))
        .unique()
    )
ELSE:
    trips_shape_ids_df = empty DataFrame with schema {"shape_id": String}

# Step 2: compute first occurrence of each shape_id in file order
first_occurrences = (
    feed["shapes"]
    .with_row_index("_row_idx")        # stable file-order index (0-based integer)
    .group_by("shape_id")
    .agg(
        pl.col("csv_row_number").first(),   # first() preserves insertion/file order
        pl.col("_row_idx").min(),           # smallest row index = earliest occurrence
    )
    .sort("_row_idx")                  # restore file order for deterministic output
)

# Step 3: anti-join to find shapes not referenced by any trip
unused = first_occurrences.join(trips_shape_ids_df, on="shape_id", how="anti")

# Step 4: emit one notice per row
FOR row IN unused.iter_rows(named=True):
    EMIT Notice(code="unused_shape", severity=WARNING,
                fields={"shape_id": row["shape_id"],
                        "csv_row_number": row["csv_row_number"]})
```

### `csv_row_number` semantics

Use `.first()` on `csv_row_number` within `group_by("shape_id").agg(...)` after sorting by `_row_idx`. Do not use `.min()` on `csv_row_number` directly — this gives the numerically smallest value, which may not correspond to the first row in file order for pathological feeds. The `_row_idx` column from `with_row_index` gives a reliable file-order position.

### Why anti-join over Python set

The anti-join keeps the logic entirely in Polars expressions and avoids materialising a Python set for large feeds. It is the idiomatic Polars approach for cross-table membership exclusion.

## 5. Registry entry

Add to `VALIDATOR_REGISTRY` in `src/gtfs_validator/validators/__init__.py`:

```python
from gtfs_validator.validators.shape_usage import validate_shape_usage

# In VALIDATOR_REGISTRY list:
ValidatorEntry(
    name="shape_usage",
    fn=validate_shape_usage,
    requires=["shapes", "trips"],
),
```

The `requires` list declares both tables so the runner can gate dispatch correctly. The validator handles the `"trips"` absent case internally (treats it as an empty reference set) rather than relying on the runner to skip it.

## 6. Test plan

Test file: `tests/test_validators/test_shape_usage.py`

### Fixtures / helpers

```python
CTX = ValidationContext(country_code="US", date_for_validation=date(2024, 1, 1))

def make_shapes(shape_ids: list[str], csv_row_numbers: list[int]) -> pl.DataFrame:
    """Minimal shapes DataFrame (two columns only)."""
    return pl.DataFrame({
        "shape_id": shape_ids,
        "csv_row_number": csv_row_numbers,
    })

def make_trips(shape_ids: list[str | None]) -> pl.DataFrame:
    """Minimal trips DataFrame."""
    return pl.DataFrame({
        "shape_id": shape_ids,
        "trip_id": [f"t{i}" for i in range(len(shape_ids))],
        "csv_row_number": list(range(1, len(shape_ids) + 1)),
    })
```

---

**`test_all_shapes_used_no_notice`**

Mirrors the Java test `allShapeUsedShouldNotGenerateNotice`.

- shapes: `[("first shape id", 1), ("second shape id", 3)]`
- trips: `[("first shape id", row 2), ("second shape id", row 4)]`
- Expected: `notices == []`

**`test_unused_shape_emits_notice`**

Mirrors the Java test `unusedShapeShouldGenerateNotice`.

- shapes: `[("first shape id", 1), ("second shape id", 3)]`
- trips: `[("first shape id", row 2)]`
- Expected: exactly 1 notice
  - `code == "unused_shape"`
  - `severity == Severity.WARNING`
  - `fields["shape_id"] == "second shape id"`
  - `fields["csv_row_number"] == 3`

---

**`test_shapes_absent_no_notice`**

**`test_shapes_empty_no_notice`**

- Expected: `notices == []`

---

**`test_trips_absent_all_shapes_unused`**

- feed: `{"shapes": make_shapes(["s1", "s2"], [1, 2])}` — no `"trips"` key
- Expected: 2 notices with `shape_id` in `{"s1", "s2"}`

---

**`test_trips_empty_all_shapes_unused`**

- feed: `{"shapes": make_shapes(["s1"], [1]), "trips": empty DataFrame}`
- Expected: 1 notice with `shape_id == "s1"`

---

**`test_shape_id_spans_multiple_rows_one_notice`**

A `shape_id` appearing across multiple shape-point rows should produce exactly one notice, using the `csv_row_number` of its first occurrence.

- shapes: `[("shape_a", 1), ("shape_a", 2), ("shape_a", 3)]` — three points, same shape
- trips: `[]` (empty)
- Expected: exactly 1 notice with `fields["shape_id"] == "shape_a"` and `fields["csv_row_number"] == 1`

---

**`test_csv_row_number_from_first_occurrence`**

Verifies that the `csv_row_number` reported is that of the first file-order occurrence, not the minimum integer value.

- shapes: `[("shape_a", 5), ("shape_a", 3)]` — first occurrence has row 5, later occurrence has row 3
- trips: `[]`
- Expected: 1 notice with `fields["csv_row_number"] == 5` (first in file order, not minimum)

---

**`test_null_shape_id_in_trips_does_not_contribute`**

Null `shape_id` values in trips must not count as a reference.

- shapes: `[("s1", 1)]`
- trips: `[None]` (shape_id is null)
- Expected: 1 notice — `"s1"` is unused because the null trip entry is excluded from the reference set

---

**`test_empty_string_shape_id_in_trips_does_not_contribute`**

Empty-string `shape_id` in trips must be excluded from the reference set.

- shapes: `[("s1", 1)]`
- trips: `[""]` (shape_id is empty string)
- Expected: 1 notice — `"s1"` is unused

---

**`test_notice_fields_are_complete`**

Assert that `fields` contains exactly the keys `{"shape_id", "csv_row_number"}` and no others.

---

**`test_ctx_unused`**

Pass a deliberately wrong `ValidationContext`; assert the result is identical to the normal case, confirming `ctx` has no effect.
