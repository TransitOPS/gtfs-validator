# Implementation: MatchingFeedAndAgencyLangValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/matching_feed_and_agency_lang.py`

This is a cross-table validator that compares `feed_info.feed_lang` against `agency.agency_lang` for each agency row. It requires both `feed_info` and `agency` tables.

## 2. Function Signature

```python
from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_matching_feed_and_agency_lang(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

No internal helper functions are needed. The logic is a single scalar extraction from `feed_info` followed by a filter on `agency`.

## 3. Notice Definitions

### `feed_info_lang_and_agency_lang_mismatch` (WARNING)

Files `agency.txt` and `feed_info.txt` define mismatching `agency.agency_lang` and `feed_info.feed_lang`. When `feed_lang` is not `mul`, all agencies with a specified `agency_lang` should match `feed_lang`.

```python
Notice(
    code="feed_info_lang_and_agency_lang_mismatch",
    severity=Severity.WARNING,
    fields={
        "csvRowNumber": <int>,
        "agencyId": <str>,
        "agencyName": <str>,
        "agencyLang": <str>,
        "feedLang": <str>,
    },
)
```

## 4. Implementation Approach

### Strategy: Scalar extraction + vectorized filter

Extract `feed_lang` as a single scalar from the singleton `feed_info` table, then apply a Polars filter on `agency` to find mismatched rows. Only violation rows are iterated in Python for notice construction.

### Algorithm

```
1.  feed_info = feed.get("feed_info")
2.  if feed_info is None or feed_info.height == 0:
3.      return []
4.
5.  agency = feed.get("agency")
6.  if agency is None or agency.height == 0:
7.      return []
8.
9.  # Extract feed_lang from the first (and only) row
10. feed_lang_col = feed_info.get_column("feed_lang")
11. feed_lang_val = feed_lang_col[0]
12.
13. # Guard: feed_lang is null or empty
14. if feed_lang_val is None or feed_lang_val == "":
15.     return []
16.
17. # Guard: feed_lang is "mul" (case-insensitive)
18. if feed_lang_val.lower() == "mul":
19.     return []
20.
21. # Guard: agency_lang column must exist
22. if "agency_lang" not in agency.columns:
23.     return []
24.
25. # Filter agencies where agency_lang is non-null, non-empty,
26. # and does not match feed_lang (case-insensitive)
27. mismatched = agency.filter(
28.     pl.col("agency_lang").is_not_null()
29.     & (pl.col("agency_lang") != "")
30.     & (pl.col("agency_lang").str.to_lowercase() != feed_lang_val.lower())
31. )
32.
33. notices: list[Notice] = []
34. for row in mismatched.iter_rows(named=True):
35.     notices.append(
36.         Notice(
37.             code="feed_info_lang_and_agency_lang_mismatch",
38.             severity=Severity.WARNING,
39.             fields={
40.                 "csvRowNumber": row["csvRowNumber"],
41.                 "agencyId": row.get("agency_id", ""),
42.                 "agencyName": row.get("agency_name", ""),
43.                 "agencyLang": row["agency_lang"],
44.                 "feedLang": feed_lang_val,
45.             },
46.         )
47.     )
48.
49. return notices
```

### Handling missing tables and columns

- If `feed_info` is absent from the feed dict or empty, return early with no notices.
- If `agency` is absent from the feed dict or empty, return early with no notices.
- If `feed_lang` is null or empty in the single `feed_info` row, return early.
- If `agency_lang` column is missing from `agency`, return early (no language to compare).
- If `agency_id` or `agency_name` columns are missing, default to empty string via `row.get()`.

### Key design decisions

- **Case-insensitive comparison**: BCP-47 language tags are case-insensitive per the spec. Both `feed_lang` and `agency_lang` are lowercased before comparison, matching the Java `Locale` equality semantics for the common case.
- **No join needed**: `feed_lang` is a single scalar value. A column filter expression on `agency` is cleaner and more efficient than a cross-join.
- **Plain iteration is fine**: `agency.txt` is typically very small (rarely more than a few dozen rows). Iterating violation rows in Python for notice construction is acceptable.
- **Null vs empty semantics**: The loading phase normalizes empty strings to null for most columns, but the filter defensively checks both null and empty string.
- **Notice field naming**: Uses camelCase field names (`csvRowNumber`, `agencyId`, `agencyName`, `agencyLang`, `feedLang`) to match Java-era report conventions used throughout the codebase.

```python
from datetime import date
import polars as pl
import pytest
from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Severity
from gtfs_validator.validators.matching_feed_and_agency_lang import (
    validate_matching_feed_and_agency_lang,
)

CTX = ValidationContext(country_code="US", date_for_validation=date(2026, 3, 8))


def make_feed_info(feed_lang: str | None) -> pl.DataFrame:
    """Build a feed_info DataFrame with a single row."""
    return pl.DataFrame(
        {
            "csvRowNumber": [1],
            "feed_publisher_name": ["Test Publisher"],
            "feed_publisher_url": ["http://example.com"],
            "feed_lang": [feed_lang],
        },
        schema={
            "csvRowNumber": pl.Int64,
            "feed_publisher_name": pl.Utf8,
            "feed_publisher_url": pl.Utf8,
            "feed_lang": pl.Utf8,
        },
    )


def make_agency(rows: list[dict]) -> pl.DataFrame:
    """Build an agency DataFrame from row dicts."""
    schema = {
        "csvRowNumber": pl.Int64,
        "agency_id": pl.Utf8,
        "agency_name": pl.Utf8,
        "agency_lang": pl.Utf8,
    }
    data: dict[str, list] = {col: [] for col in schema}
    for r in rows:
        for col in schema:
            data[col].append(r.get(col))
    return pl.DataFrame(data, schema=schema)
```
