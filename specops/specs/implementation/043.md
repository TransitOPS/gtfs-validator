# Implementation: PathwayReachableLocationValidator

## 1. Module location

`src/gtfs_validator/validators/pathway_reachable_location.py`

This validator performs non-trivial graph reachability analysis over the pathway network, warranting its own dedicated file. It follows the one-concern-per-file pattern used by `pathway_dangling_generic_node.py` and `pathway_endpoint_type.py`.

## 2. Function signature

```python
def validate_pathway_reachable_location(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted for interface consistency but is not used by this validator.

## 3. Notice definitions

### `pathway_unreachable_location`

- **Code:** `"pathway_unreachable_location"`
- **Severity:** `Severity.ERROR`
- **Fields dict:**

```python
{
    "csvRowNumber": int,         # csv_row_number from stops.txt row
    "stopId":       str,         # stop_id of the unreachable location
    "stopName":     str | None,  # stop_name of the unreachable location (may be None)
    "locationType": int,         # location_type integer (0, 3, or 4)
    "parentStation": str | None, # parent_station of the unreachable location (may be None)
    "hasEntrance":  bool,        # True if the location is reachable from some entrance
    "hasExit":      bool,        # True if some entrance is reachable from this location
}
```

Note: at least one of `hasEntrance` or `hasExit` is `False` whenever the notice is emitted (the notice fires only when NOT both are true).

## 4. Implementation approach

Use plain Python with `collections.deque` for BFS. The graph traversal has no natural vectorized representation. Polars is used only in the preprocessing phase to extract data from the DataFrames into Python dicts efficiently.

### Location type constants

```python
_STOP         = 0
_STATION      = 1
_ENTRANCE     = 2
_GENERIC_NODE = 3
_BOARDING_AREA = 4
```

### Preprocessing — build lookup dicts

From `pathways.txt`, build two adjacency maps using `iter_rows(named=True)`:

```python
from_map: dict[str, list[tuple[str, int]]]  # from_stop_id -> [(to_stop_id, is_bidirectional)]
to_map:   dict[str, list[tuple[str, int]]]  # to_stop_id   -> [(from_stop_id, is_bidirectional)]
```

`is_bidirectional` should be cast to `int`; treat null as `0`.

From `stops.txt`, build two dicts using `iter_rows(named=True)`:

```python
stop_by_id:  dict[str, dict]       # stop_id -> full row dict (location_type, parent_station, ...)
children_of: dict[str, list[str]]  # parent_station -> [child stop_ids]
```

The `children_of` dict is built by iterating every stop row and, for each stop with a non-null `parent_station`, appending that stop's `stop_id` to `children_of[parent_station]`.

### Helper: `get_including_station`

```python
def get_including_station(
    stop_id: str,
    stop_by_id: dict[str, dict],
) -> str | None:
    for _ in range(3):
        stop = stop_by_id.get(stop_id)
        if stop is None:
            return None
        if stop["location_type"] == _STATION:
            return stop_id
        parent = stop.get("parent_station")
        if not parent:
            return None
        stop_id = parent
    return None
```

Caps traversal at 3 iterations to guard against cycles in the parent chain.

### Helper: `bfs`

```python
from collections import deque

def bfs(
    seeds: list[str],
    from_map: dict[str, list[tuple[str, int]]],
    to_map:   dict[str, list[tuple[str, int]]],
    direction: str,  # "FROM_ENTRANCES" or "TO_EXITS"
) -> set[str]:
    visited: set[str] = set(seeds)
    queue: deque[str] = deque(seeds)
    while queue:
        curr = queue.popleft()
        # Follow forward edges (from_map gives edges curr -> neighbor)
        for neighbor, is_bidir in from_map.get(curr, []):
            if direction == "FROM_ENTRANCES" or is_bidir == 1:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        # Follow reverse edges (to_map gives edges neighbor -> curr, reversed)
        for neighbor, is_bidir in to_map.get(curr, []):
            if direction == "TO_EXITS" or is_bidir == 1:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
    return visited
```

### Algorithm pseudocode

```
def validate_pathway_reachable_location(feed, ctx):
    stops    = feed.get("stops")
    pathways = feed.get("pathways")
    if stops is None or stops.is_empty():
        return []
    if pathways is None or pathways.is_empty():
        return []

    # --- Preprocessing ---
    from_map = defaultdict(list)
    to_map   = defaultdict(list)
    for row in pathways.select(["from_stop_id", "to_stop_id", "is_bidirectional"]).iter_rows(named=True):
        from_id = row["from_stop_id"]
        to_id   = row["to_stop_id"]
        is_bidir = row["is_bidirectional"] or 0
        if from_id and to_id:
            from_map[from_id].append((to_id, int(is_bidir)))
            to_map[to_id].append((from_id, int(is_bidir)))

    stop_by_id  = {}
    children_of = defaultdict(list)
    for row in stops.iter_rows(named=True):
        stop_by_id[row["stop_id"]] = row
        parent = row.get("parent_station")
        if parent:
            children_of[parent].append(row["stop_id"])

    # --- Step 1: Collect all pathway endpoint stop IDs ---
    pathway_stop_ids = set(from_map.keys()) | set(to_map.keys())

    # --- Step 2: Identify stations that have pathways ---
    stations_with_pathways: set[str] = set()
    for sid in pathway_stop_ids:
        station_id = get_including_station(sid, stop_by_id)
        if station_id:
            stations_with_pathways.add(station_id)

    if not stations_with_pathways:
        return []

    # --- Steps 3 & 4: BFS from all entrances in both directions ---
    entrances = [
        row["stop_id"]
        for row in stops.filter(pl.col("location_type") == _ENTRANCE).iter_rows(named=True)
    ]

    locations_having_entrances = bfs(entrances, from_map, to_map, "FROM_ENTRANCES")
    locations_having_exits     = bfs(entrances, from_map, to_map, "TO_EXITS")

    # --- Step 5: Emit notices ---
    notices = []
    for row in stops.iter_rows(named=True):
        stop_id       = row["stop_id"]
        location_type = row.get("location_type")

        # Determine including station
        station_id = get_including_station(stop_id, stop_by_id)
        if station_id is None:
            continue
        if station_id not in stations_with_pathways:
            continue

        # Filter to eligible location types
        if location_type == _STOP:
            # Skip if the platform has any boarding area children
            if children_of.get(stop_id):
                continue
        elif location_type in (_GENERIC_NODE, _BOARDING_AREA):
            pass  # eligible
        else:
            continue  # STATION, ENTRANCE, or unexpected type — skip

        has_entrance = stop_id in locations_having_entrances
        has_exit     = stop_id in locations_having_exits

        if not (has_entrance and has_exit):
            notices.append(Notice(
                code="pathway_unreachable_location",
                severity=Severity.ERROR,
                fields={
                    "csvRowNumber": row["csvRowNumber"],
                    "stopId":       stop_id,
                    "stopName":     row.get("stop_name"),
                    "locationType": location_type,
                    "parentStation": row.get("parent_station"),
                    "hasEntrance":  has_entrance,
                    "hasExit":      has_exit,
                },
            ))

    return notices
```

### Null handling

- `parent_station`: null terminates the `get_including_station` walk immediately.
- `stop_name`: may be null for some location types; passed as-is into the notice `fields` dict.
- `is_bidirectional`: null is treated as `0` (unidirectional) via `row["is_bidirectional"] or 0`.
- `location_type`: null stops will fail the eligibility filter (`location_type in (_STOP, _GENERIC_NODE, _BOARDING_AREA)` returns `False` for null) and produce no notice.

### Platform-with-boarding-areas check

A platform (`location_type == 0`) is skipped when `children_of.get(stop_id)` is non-empty. The `children_of` dict maps every `parent_station` value to the list of child stop IDs regardless of child type, matching Java's `byParentStation` behavior.

### Performance

Preprocessing builds all dicts in one pass over each table. Both BFS passes are O(V + E) over the pathway graph. The stop iteration is O(S) where S is the number of stops. No repeated scans.
