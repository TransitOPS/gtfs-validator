# Implementation: MissingFeedInfoValidator

## 1. Module location

`src/gtfs_validator/validators/missing_feed_info.py`

## 2. Function signature

```python
def validate_missing_feed_info(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted for signature consistency but is not used by this validator.

## 3. Notice definitions

### `missing_recommended_file` — WARNING

Emitted when `feed_info.txt` is absent and `translations.txt` is also absent. The file is recommended but not strictly required under these conditions.

```python
Notice(
    code="missing_recommended_file",
    severity=Severity.WARNING,
    fields={"filename": "feed_info.txt"},
)
```

| Field | Type | Value |
|---|---|---|
| `filename` | `str` | `"feed_info.txt"` |

### `missing_required_file` — ERROR

Emitted when `feed_info.txt` is absent but `translations.txt` is present. Because `translations.txt` depends on `feed_lang` from `feed_info.txt`, the latter becomes required.

```python
Notice(
    code="missing_required_file",
    severity=Severity.ERROR,
    fields={"filename": "feed_info.txt"},
)
```

| Field | Type | Value |
|---|---|---|
| `filename` | `str` | `"feed_info.txt"` |

## 4. Implementation approach

Plain Python — no Polars operations required. The validator inspects only dict key presence.

**Algorithm (pseudocode):**

```
if "feed_info" in feed:
    return []                          # file is present; nothing to do

if "translations" not in feed:
    return [WARNING missing_recommended_file, filename="feed_info.txt"]
else:
    return [ERROR missing_required_file, filename="feed_info.txt"]
```

**Key rules:**

- Presence is determined solely by whether the key exists in the `feed` dict. A key present with an empty DataFrame (zero rows) counts as present and produces no notice.
- The dict key for `feed_info.txt` is `"feed_info"` (filename stem, no extension). Same for `"translations"`.
- No column values are read from either table.
- `missing_recommended_file` and `missing_required_file` are shared general-purpose notice codes that accept a `filename` field. They are not specific to this validator.

## 5. Registry entry

Add to `VALIDATOR_REGISTRY` in `src/gtfs_validator/validators/__init__.py`, ordered alphabetically among the `missing_*` entries (after `missing_calendar_and_calendar_date`):

```python
from gtfs_validator.validators.missing_feed_info import validate_missing_feed_info

ValidatorEntry(
    name="missing_feed_info",
    fn=validate_missing_feed_info,
    requires=[],
)
```

`requires` is empty because this validator must run even when neither `feed_info` nor `translations` is present in the feed. An empty `requires` list means the runner will always dispatch this validator without gating on table availability.

## 6. Test plan

Test file: `tests/test_validators/test_missing_feed_info.py`

### Fixtures

```python
CTX = ValidationContext(country_code="US", date_for_validation=date(2026, 3, 8))

def make_feed_info() -> pl.DataFrame:
    """Minimal feed_info.txt DataFrame with one row."""
    return pl.DataFrame(
        {
            "feed_publisher_name": ["Test Publisher"],
            "feed_publisher_url": ["https://example.com"],
            "feed_lang": ["en"],
        },
        schema={
            "feed_publisher_name": pl.Utf8,
            "feed_publisher_url": pl.Utf8,
            "feed_lang": pl.Utf8,
        },
    )

def make_translations() -> pl.DataFrame:
    """Minimal translations.txt DataFrame with one row."""
    return pl.DataFrame(
        {
            "table_name": ["stops"],
            "field_name": ["stop_name"],
            "language": ["fr"],
            "translation": ["Gare"],
        },
        schema={
            "table_name": pl.Utf8,
            "field_name": pl.Utf8,
            "language": pl.Utf8,
            "translation": pl.Utf8,
        },
    )

def make_empty_feed_info() -> pl.DataFrame:
    """feed_info.txt present but zero data rows."""
    return pl.DataFrame(schema={"feed_publisher_name": pl.Utf8, "feed_lang": pl.Utf8})

def make_empty_translations() -> pl.DataFrame:
    """translations.txt present but zero data rows."""
    return pl.DataFrame(
        schema={
            "table_name": pl.Utf8,
            "field_name": pl.Utf8,
            "language": pl.Utf8,
            "translation": pl.Utf8,
        }
    )
```

### Test cases

#### `test_feed_info_present_translations_present_no_notice`
- Feed: `{"feed_info": make_feed_info(), "translations": make_translations()}`
- Expected: `notices == []`

#### `test_feed_info_present_translations_absent_no_notice`
- Feed: `{"feed_info": make_feed_info()}`
- Expected: `notices == []`

#### `test_feed_info_absent_translations_absent_emits_warning`
- Feed: `{}` (both keys absent)
- Expected: exactly one notice with `code == "missing_recommended_file"`, `severity == Severity.WARNING`, `fields == {"filename": "feed_info.txt"}`
- Mirrors Java test `missingFeedInfoTranslationTableNotPresent`

#### `test_feed_info_absent_translations_present_emits_error`
- Feed: `{"translations": make_translations()}`
- Expected: exactly one notice with `code == "missing_required_file"`, `severity == Severity.ERROR`, `fields == {"filename": "feed_info.txt"}`
- Mirrors Java test `missingFeedInfoWhenTranslationTableIsPresent`

#### `test_feed_info_present_empty_dataframe_no_notice`
- Feed: `{"feed_info": make_empty_feed_info()}`
- Expected: `notices == []`
- Confirms that an empty DataFrame (key present, zero rows) does not trigger either notice.

#### `test_translations_present_empty_dataframe_triggers_error_when_feed_info_absent`
- Feed: `{"translations": make_empty_translations()}`
- Expected: exactly one notice with `code == "missing_required_file"`, `severity == Severity.ERROR`
- Confirms that the presence check is on key existence, not row count. An empty `translations.txt` still counts as present.

#### `test_ctx_unused_does_not_affect_result`
- Construct two contexts with different `date_for_validation` values.
- Feed: `{}` (triggers WARNING path).
- Expected: both contexts produce identical single-notice output.
- Confirms the validator is pure with respect to context.

#### `test_warning_filename_field_value`
- Feed: `{}`
- Expected: `notices[0].fields["filename"] == "feed_info.txt"` (including `.txt` extension)

#### `test_error_filename_field_value`
- Feed: `{"translations": make_translations()}`
- Expected: `notices[0].fields["filename"] == "feed_info.txt"`
