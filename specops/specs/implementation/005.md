# Implementation: BlockTripsWithOverlappingStopTimesValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/block_trips_overlapping.py`

**Shared utility (new):** `src/gtfs_validator/calendar_utils.py`

The calendar utility module is needed because no service date resolution
helper exists yet. It will be shared by this validator and any future
validator that needs to resolve active service dates or check service ID
intersections.

## 2. Function Signatures

### Calendar utility — `calendar_utils.py`

```python
from __future__ import annotations

from datetime import date, timedelta

import polars as pl


def build_service_date_map(
    feed: dict[str, pl.DataFrame],
) -> dict[str, set[date]]:
    """Build a mapping from service_id to its full set of active dates.

    Combines calendar.txt (weekly patterns expanded into date sets) with
    calendar_dates.txt (additions via exception_type=1, removals via
    exception_type=2).

    Returns an empty dict if neither calendar nor calendar_dates is present.
    """


class ServiceIdIntersectionCache:
    """Cached pairwise service-date intersection lookups.

    Wraps a ``dict[str, set[date]]`` and caches the first intersecting
    date (or None) for each queried pair of service IDs.
    """

    def __init__(self, service_dates: dict[str, set[date]]) -> None:
        self._service_dates = service_dates
        self._cache: dict[tuple[str, str], date | None] = {}

    def first_intersecting_date(
        self, service_id_a: str, service_id_b: str
    ) -> date | None:
        """Return the earliest date active in both services, or None."""
```

## 3. Notice Definitions

### `block_trips_with_overlapping_stop_times` (ERROR)

Emitted when two trips in the same block have overlapping time intervals
and share at least one active service date.

```python
Notice(
    code="block_trips_with_overlapping_stop_times",
    severity=Severity.ERROR,
    fields={
        "csv_row_number_a": <int>,   # 1-based row of trip A in trips.txt
        "trip_id_a": <str>,          # trip_id of the first trip
        "service_id_a": <str>,       # service_id of the first trip
        "csv_row_number_b": <int>,   # 1-based row of trip B in trips.txt
        "trip_id_b": <str>,          # trip_id of the second trip
        "service_id_b": <str>,       # service_id of the second trip
        "block_id": <str>,           # shared block_id
        "intersection": <str>,       # ISO-format first shared active date
    },
)
```

The `intersection` field is serialized as an ISO date string (e.g.,
`"2021-01-04"`) for JSON compatibility.

## 4. Implementation Approach

### 4a. `build_service_date_map`

```
function build_service_date_map(feed):
    result = {}

    # Phase 1: Expand calendar.txt weekly patterns
    if "calendar" in feed and not feed["calendar"].is_empty():
        calendar = feed["calendar"]
        day_columns = ["monday", "tuesday", "wednesday", "thursday",
                       "friday", "saturday", "sunday"]

        for row in calendar.iter_rows(named=True):
            service_id = row["service_id"]
            start = row["start_date"]   # date object
            end = row["end_date"]        # date object
            if start is None or end is None:
                continue

            active_days = set()
            for i, col in enumerate(day_columns):
                if row[col] == 1:
                    active_days.add(i)   # Monday=0 .. Sunday=6

            dates = set()
            current = start
            while current <= end:
                if current.weekday() in active_days:
                    dates.add(current)
                current += timedelta(days=1)

            result[service_id] = dates

    # Phase 2: Apply calendar_dates.txt exceptions
    if "calendar_dates" in feed and not feed["calendar_dates"].is_empty():
        for row in feed["calendar_dates"].iter_rows(named=True):
            service_id = row["service_id"]
            d = row["date"]
            exc_type = row["exception_type"]
            if d is None or exc_type is None:
                continue

            if service_id not in result:
                result[service_id] = set()

            if exc_type == 1:       # added
                result[service_id].add(d)
            elif exc_type == 2:     # removed
                result[service_id].discard(d)

    return result
```

### 4b. `ServiceIdIntersectionCache.first_intersecting_date`

```
function first_intersecting_date(service_id_a, service_id_b):
    # Normalize key ordering for cache symmetry
    key = (min(service_id_a, service_id_b), max(service_id_a, service_id_b))

    if key in cache:
        return cache[key]

    dates_a = service_dates.get(service_id_a, set())
    dates_b = service_dates.get(service_id_b, set())

    common = dates_a & dates_b
    if common:
        result = min(common)
    else:
        result = None

    cache[key] = result
    return result
```

### 4c. `validate_block_trips_overlapping`

```
function validate_block_trips_overlapping(feed, ctx):
    # 1. Guard: required tables
    if "trips" not in feed or "stop_times" not in feed:
        return []
    trips = feed["trips"]
    stop_times = feed["stop_times"]
    if trips.is_empty() or stop_times.is_empty():
        return []

    # 2. Build service date intersection cache
    service_dates = build_service_date_map(feed)
    cache = ServiceIdIntersectionCache(service_dates)

    # 3. Filter trips with non-null, non-empty block_id
    blocked_trips = trips.filter(
        pl.col("block_id").is_not_null() & (pl.col("block_id") != "")
    )
    if blocked_trips.is_empty():
        return []

    # 4. Build trip time intervals using Polars
    #    Sort stop_times by (trip_id, stop_sequence), then aggregate
    #    first/last arrival and departure per trip.
    #
    #    Times are stored as integer seconds (the loader parses GTFS TIME
    #    fields into total-seconds integers to handle >24:00:00 values).

    intervals = (
        stop_times
        .sort("trip_id", "stop_sequence")
        .group_by("trip_id")
        .agg([
            pl.col("arrival_time").first().alias("first_arrival"),
            pl.col("departure_time").first().alias("first_departure"),
            pl.col("arrival_time").last().alias("last_arrival"),
            pl.col("departure_time").last().alias("last_departure"),
        ])
    )

    # 5. Join intervals onto blocked trips to get block_id, service_id,
    #    csv_row_number alongside the time bounds
    trip_data = blocked_trips.select(
        "trip_id", "block_id", "service_id", "csv_row_number"
    ).join(intervals, on="trip_id", how="inner")

    # 6. Filter out trips where any of the four time bounds is null
    trip_data = trip_data.filter(
        pl.col("first_arrival").is_not_null()
        & pl.col("first_departure").is_not_null()
        & pl.col("last_arrival").is_not_null()
        & pl.col("last_departure").is_not_null()
    )

    if trip_data.is_empty():
        return []

    # 7. Group by block_id and run pairwise overlap detection
    notices = []

    for block_id, group in trip_data.group_by("block_id"):
        block_id_str = block_id[0]  # group_by returns tuple keys

        # Sort by (first_arrival, last_departure) ascending
        sorted_group = group.sort("first_arrival", "last_departure")
        rows = sorted_group.to_dicts()

        # Pairwise comparison with early termination
        n = len(rows)
        for i in range(n):
            for j in range(i + 1, n):
                ri = rows[i]
                rj = rows[j]

                # Break: no further j can overlap with i
                if ri["last_departure"] <= rj["first_arrival"]:
                    break

                # Block transfer exception
                if (ri["last_arrival"] == rj["first_arrival"]
                        and ri["last_departure"] == rj["first_departure"]):
                    continue

                # Service date intersection check
                intersect_date = cache.first_intersecting_date(
                    ri["service_id"], rj["service_id"]
                )
                if intersect_date is None:
                    continue

                notices.append(Notice(
                    code="block_trips_with_overlapping_stop_times",
                    severity=Severity.ERROR,
                    fields={
                        "csv_row_number_a": ri["csv_row_number"],
                        "trip_id_a": ri["trip_id"],
                        "service_id_a": ri["service_id"],
                        "csv_row_number_b": rj["csv_row_number"],
                        "trip_id_b": rj["trip_id"],
                        "service_id_b": rj["service_id"],
                        "block_id": block_id_str,
                        "intersection": intersect_date.isoformat(),
                    },
                ))

    return notices
```

**Key design decisions:**

- **Polars for aggregation, Python for pairwise logic.** The group-by
  and first/last aggregation is done efficiently in Polars. The pairwise
  overlap detection with early termination and the block transfer
  exception is inherently sequential, so plain Python loops are used
  after extracting rows via `to_dicts()`.
- **`csv_row_number` column.** The loader is expected to populate this
  column on `trips.txt`. If the loader uses `with_row_index` instead,
  the validator should use that column name and add 2 (0-indexed + header
  row). The existing validators show mixed conventions (`csv_row_number`
  vs `_row_idx`); this spec assumes `csv_row_number` is present on
  trips, consistent with other validators that reference it directly.
- **Time representation.** GTFS times (including >24:00:00) are assumed
  to be loaded as integer seconds-since-midnight. Comparisons are simple
  integer comparisons.
- **Intersection date serialization.** The `intersection` field is
  stored as an ISO date string for JSON serialization in the report.

## 5. Registry Entry

In `src/gtfs_validator/validators/__init__.py`, add the import and
registry entry:

```python
from gtfs_validator.validators.block_trips_overlapping import validate_block_trips_overlapping

# Add to VALIDATOR_REGISTRY list:
ValidatorEntry(
    name="block_trips_overlapping",
    fn=validate_block_trips_overlapping,
    requires=["trips", "stop_times"],
),
```

Note: the `requires` list includes only `trips` and `stop_times`. The
`calendar` and `calendar_dates` tables are optional inputs — the
validator handles their absence gracefully via `build_service_date_map`
returning an empty dict (which means no service date intersections are
found, so no notices are emitted).
