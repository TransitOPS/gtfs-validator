## 3. Notice definition

### `unusable_trip` — WARNING

Emitted for each trip in `trips.txt` that has fewer than two rows in
`stop_times.txt`.

| Field | Python type | Source | Description |
|---|---|---|---|
| `csv_row_number` | `int` | `trips["csv_row_number"]` | 1-based physical row number of the trip in `trips.txt` |
| `trip_id` | `str` | `trips["trip_id"]` | ID of the trip with too few stop times |

Constructed as:

```python
Notice(
    code="unusable_trip",
    severity=Severity.WARNING,
    fields={
        "csv_row_number": <int>,
        "trip_id": <str>,
    },
)
```

Notice fields must contain **exactly** `csv_row_number` and `trip_id` — no
additional keys.

## 4. Implementation approach

### 4.1 Guard clauses

```python
if "trips" not in feed or "stop_times" not in feed:
    return []
trips = feed["trips"]
stop_times = feed["stop_times"]
if trips.is_empty():
    return []
```

When `stop_times` is absent, return `[]` immediately (the runner dependency
guard already enforces both tables are present, but the function must be
defensive on its own).

When `stop_times` is present but empty, do **not** short-circuit — the join
will assign a count of `0` to every trip, which correctly triggers notices for
all trips.

### 4.2 Vectorised core

```python
# Step 1: count stop_times rows per trip_id
counts = (
    stop_times
    .group_by("trip_id")
    .agg(pl.len().alias("stop_time_count"))
)

# Step 2: left-join trips → counts on trip_id
joined = trips.join(counts, on="trip_id", how="left")

# Step 3: fill null counts (trips with no stop_times rows) with 0
joined = joined.with_columns(
    pl.col("stop_time_count").fill_null(0)
)

# Step 4: filter to violating trips
violating = joined.filter(pl.col("stop_time_count") <= 1)
```

### 4.3 Notice emission

Iterate the (small) filtered result in plain Python:

```python
notices: list[Notice] = []
for row in violating.iter_rows(named=True):
    notices.append(
        Notice(
            code="unusable_trip",
            severity=Severity.WARNING,
            fields={
                "csv_row_number": row["csv_row_number"],
                "trip_id": row["trip_id"],
            },
        )
    )
return notices
```

### 4.4 Columns accessed

| DataFrame | Columns read |
|---|---|
| `trips` | `trip_id`, `csv_row_number` |
| `stop_times` | `trip_id` only |

No other columns are read. The validator must not fail if extra columns are
present.

### 4.5 Behavioural notes

- The threshold is strictly `<= 1`. Exactly 2 stop times → no notice.
- Only the row count is checked; `stop_sequence` values, stop IDs, and
  timestamps are irrelevant.
- Duplicate `stop_sequence` values within a trip are counted as-is (the
  validator does not deduplicate).
- `trip_id` values appearing in `stop_times` but not in `trips` are silently
  ignored (the validator iterates trips, not stop times).

## 7. Complete module skeleton

```python
"""Validator: warn when a trip has fewer than two stop time entries."""

from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_trip_usability(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
    """Emit unusable_trip WARNING for every trip with fewer than 2 stop times."""
    if "trips" not in feed or "stop_times" not in feed:
        return []
    trips = feed["trips"]
    stop_times = feed["stop_times"]
    if trips.is_empty():
        return []

    counts = (
        stop_times
        .group_by("trip_id")
        .agg(pl.len().alias("stop_time_count"))
    )
    joined = trips.join(counts, on="trip_id", how="left")
    joined = joined.with_columns(pl.col("stop_time_count").fill_null(0))
    violating = joined.filter(pl.col("stop_time_count") <= 1)

    notices: list[Notice] = []
    for row in violating.iter_rows(named=True):
        notices.append(
            Notice(
                code="unusable_trip",
                severity=Severity.WARNING,
                fields={
                    "csv_row_number": row["csv_row_number"],
                    "trip_id": row["trip_id"],
                },
            )
        )
    return notices
```
