# Implementation: FareAttributeAgencyIdValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/fare_attribute_agency_id.py`

No new shared utilities are needed. Both notice codes (`missing_required_agency_id`
and `missing_recommended_field`) already exist in the codebase and are used by
`validate_agency_consistency`. This validator follows the identical pattern.

## 2. Function Signature

```python
from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_fare_attribute_agency_id(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice Definitions

### `missing_required_agency_id`

Severity: **ERROR**

Emitted when `agency_id` is null or empty in a `fare_attributes.txt` row
and the feed contains more than one agency.

```python
Notice(
    code="missing_required_agency_id",
    severity=Severity.ERROR,
    fields={
        "filename": "fare_attributes.txt",
        "csv_row_number": <int>,   # 0-based data row index (matches agency_consistency convention)
        "agency_name": None,       # always None — matches Java MissingRequiredAgencyIdNotice
    },
)
```

### `missing_recommended_field`

Severity: **WARNING**

Emitted when `agency_id` is null or empty in a `fare_attributes.txt` row
and the feed contains exactly one agency.

```python
Notice(
    code="missing_recommended_field",
    severity=Severity.WARNING,
    fields={
        "filename": "fare_attributes.txt",
        "csv_row_number": <int>,   # 0-based data row index
        "field_name": "agency_id",
    },
)
```

**Note on `agency_name`:** The Java `MissingRequiredAgencyIdNotice` always
receives `null` for `agencyName`. The Python implementation must pass
`agency_name=None` to preserve wire-format compatibility.

**Note on `field_name`:** The string `"agency_id"` is the literal value,
matching `GtfsFareAttribute.AGENCY_ID_FIELD_NAME` in Java.

## 4. Implementation Approach

```
function validate_fare_attribute_agency_id(feed, ctx):
    # 1. Skip if agency.txt is absent or empty
    if "agency" not in feed or feed["agency"].is_empty():
        return []

    # 2. Skip if fare_attributes.txt is absent or empty
    if "fare_attributes" not in feed or feed["fare_attributes"].is_empty():
        return []

    agency_df = feed["agency"]
    fare_df = feed["fare_attributes"]

    # 3. Count total agencies to determine error vs. warning branch
    total_agencies = len(agency_df)

    # 4. Attach 0-based row index for csv_row_number (matches agency_consistency convention)
    fare_df = fare_df.with_row_index("_row_idx")

    # 5. Filter to rows where agency_id is null or empty string
    missing = fare_df.filter(
        pl.col("agency_id").is_null() | (pl.col("agency_id") == "")
    )

    if missing.is_empty():
        return []

    # 6. Emit one notice per offending row
    notices: list[Notice] = []
    if total_agencies > 1:
        # Multi-agency: missing agency_id is an ERROR
        for row in missing.iter_rows(named=True):
            notices.append(
                Notice(
                    code="missing_required_agency_id",
                    severity=Severity.ERROR,
                    fields={
                        "filename": "fare_attributes.txt",
                        "csv_row_number": row["_row_idx"],
                        "agency_name": None,
                    },
                )
            )
    else:
        # Single agency: missing agency_id is a WARNING
        for row in missing.iter_rows(named=True):
            notices.append(
                Notice(
                    code="missing_recommended_field",
                    severity=Severity.WARNING,
                    fields={
                        "filename": "fare_attributes.txt",
                        "csv_row_number": row["_row_idx"],
                        "field_name": "agency_id",
                    },
                )
            )

    return notices
```

**Key design decisions:**

- **Polars filter before iteration.** The filter to null/empty `agency_id` rows
  is done as a Polars expression. Only the (typically small) set of offending
  rows is iterated in Python, avoiding a full-table Python loop.
- **`with_row_index("_row_idx")` for csv_row_number.** This produces a 0-based
  integer index identical to the convention used in `agency_consistency.py`.
  The analysis spec test contracts confirm 0-based row numbering (row 0 for the
  first data row, row 1 for the second).
- **`total_agencies > 1` threshold.** Strictly greater than one. A single-agency
  feed — even if that agency row has no `agency_id` — always uses the warning
  branch. This matches the analysis spec and the Java implementation.
- **`agency_name=None` always.** The Java implementation never resolves the
  agency name when constructing `MissingRequiredAgencyIdNotice`. Python matches
  this exactly.
- **Empty string treated as missing.** The filter `pl.col("agency_id") == ""`
  catches the empty-string sentinel, matching Java's `hasAgencyId()` behavior.
- **No FK re-check.** If `agency_id` is present (non-null, non-empty), no
  notice is emitted here regardless of whether the value references a valid
  agency. FK validation is handled by the load-time `_FK` annotation on the
  `FARE_ATTRIBUTES` schema definition.
- **Notice ordering.** The Polars filter preserves DataFrame row order, so
  notices are emitted in ascending `_row_idx` order naturally. No explicit sort
  is required.

## 5. Registry Entry

In `src/gtfs_validator/validators/__init__.py`, add:

```python
from gtfs_validator.validators.fare_attribute_agency_id import validate_fare_attribute_agency_id

# Add to VALIDATOR_REGISTRY list (alphabetical by name, after "expired_calendar"):
ValidatorEntry(
    name="fare_attribute_agency_id",
    fn=validate_fare_attribute_agency_id,
    requires=["agency", "fare_attributes"],
),
```

The `requires` list includes both `"agency"` and `"fare_attributes"`. The
runner will skip the validator only if neither table is loaded at all. The
validator's own skip guards handle the case where either table is present but
empty.

def make_fare_attributes(agency_ids: list[str | None], fare_ids: list[str] | None = None) -> pl.DataFrame:

    if fare_ids is None:
