## 3. Notice Definitions

### `attribution_without_role` (WARNING)

Emitted when a row in `attributions.txt` has none of `is_producer`,
`is_operator`, or `is_authority` set to `1`.

```python
Notice(
    code="attribution_without_role",
    severity=Severity.WARNING,
    fields={
        "csv_row_number": <int>,      # 1-based row number
        "attribution_id": <str>,      # attribution_id value, or "" if missing/null
    },
)
```

## 4. Implementation Approach

```
function validate_attribution_without_role(feed, ctx):
    # 1. Guard: table must exist
    if "attributions" not in feed:
        return []

    df = feed["attributions"]

    # 2. Guard: at least one role column must be present
    ROLE_COLS = ["is_producer", "is_operator", "is_authority"]
    present_cols = [c for c in ROLE_COLS if c in df.columns]

    if not present_cols:
        return []

    # 3. Guard: empty DataFrame
    if df.is_empty():
        return []

    # 4. Build a filter expression: row has NO role assigned
    #    For each present role column, check != 1.
    #    Missing role columns are treated as 0 (NOT_ASSIGNED) implicitly
    #    by not including them in the "has role" check.
    #
    #    A row "has a role" if ANY present role column == 1.
    #    So "no role" means ALL present role columns are null or != 1.
    has_role_expr = pl.lit(False)
    for col in present_cols:
        has_role_expr = has_role_expr | (pl.col(col) == 1)

    # Filter to rows without any role
    no_role_df = df.filter(~has_role_expr)

    # 5. Emit notices
    notices = []
    for row in no_role_df.iter_rows(named=True):
        attribution_id = row.get("attribution_id") or ""
        # csv_row_number is expected to already be in the DataFrame
        # (added during loading as a 1-based row index)
        csv_row_number = row["csv_row_number"]
        notices.append(
            Notice(
                code="attribution_without_role",
                severity=Severity.WARNING,
                fields={
                    "csv_row_number": csv_row_number,
                    "attribution_id": str(attribution_id),
                },
            )
        )

    return notices
```

**Key Polars idioms used:**

- `pl.col(col) == 1` for vectorized enum comparison.
- `pl.lit(False)` as the identity element for an OR-chain across present columns.
- `df.filter(~has_role_expr)` to select violating rows in a single pass.
- `iter_rows(named=True)` to emit per-row notices (acceptable here since only
  violating rows are iterated, not the full table).

**Null handling:** The expression `pl.col(col) == 1` returns `null` when the
column value is null. The `|` operator with `null` propagates correctly:
`False | null = null`, and `~null = null`, which Polars treats as falsy in
`filter`. However, to be safe, fill nulls before comparison:
replace `pl.col(col) == 1` with `pl.col(col).fill_null(0) == 1`.

## 6. Test Plan

Test file: `tests/test_validators/test_attribution.py`

All tests construct minimal `feed` dicts with Polars DataFrames and call
`validate_attribution_without_role` directly.

- **Input:** One row: `csv_row_number=2`, `attribution_id="attr-1"`,
  `is_producer=0`, `is_operator=0`, `is_authority=0`.
- **Expected:** Exactly one notice with `code="attribution_without_role"`,
  `severity=WARNING`, `fields={"csv_row_number": 2, "attribution_id": "attr-1"}`.

- **Input:** One row: `csv_row_number=2`, `attribution_id=""`,
  `is_producer=0`, `is_operator=0`, `is_authority=0`.
- **Expected:** One notice with `attribution_id=""`.

### Test 3: `test_attribution_with_single_role_no_notice`

- **Expected:** No notices for any case.

### Test 4: `test_attribution_with_all_roles_no_notice`

- **Expected:** No notices.

### Test 5: `test_missing_attributions_table`

- **Expected:** Empty list.

### Test 6: `test_empty_dataframe`

  the expected columns.
- **Expected:** Empty list.

### Test 7: `test_no_role_columns_present`

  `csv_row_number` columns but none of `is_producer`, `is_operator`,

### Test 8: `test_partial_role_columns_no_role_assigned`

- **Expected:** One notice emitted (missing columns treated as 0).

### Test 9: `test_partial_role_columns_role_assigned`
- **Input:** DataFrame with only `is_producer` column present, value is `1`.
- **Expected:** No notices.

### Test 10: `test_null_role_values_treated_as_not_assigned`
- **Input:** One row with `is_producer=null`, `is_operator=null`,
  `is_authority=null`.
- **Expected:** One notice (nulls treated as NOT_ASSIGNED).

### Test 11: `test_multiple_rows_mixed`
- **Input:** Three rows: one with a role, one without, one with null values.
- **Expected:** Two notices (for the no-role and null-values rows).
