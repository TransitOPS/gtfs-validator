## 3. Notice definitions

### `missing_required_field` (ERROR)

Reuse the shared notice code already used by other validators. Emitted when none of
`stop_id`, `location_group_id`, or `location_id` are present on a row.

```python
Notice(
    code="missing_required_field",
    severity=Severity.ERROR,
    fields={
        "filename": "stop_times.txt",           # constant
        "csv_row_number": int,                   # stop_times.csv_row_number
        "field_name": "stop_id",                 # constant — always "stop_id"
    },
)
```

Condition: all three geography columns are absent/null/empty on the same row.

### `forbidden_geography_id` (ERROR)

New notice, defined in this validator. Emitted when more than one of the three geography
ID fields is present on the same row.

```python
Notice(
    code="forbidden_geography_id",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": int,          # stop_times.csv_row_number
        "stop_id": str | None,          # value of stop_id if present, else None
        "location_group_id": str | None,  # value if present, else None
        "location_id": str | None,      # value if present, else None
    },
)
```

Condition: two or more of `stop_id`, `location_group_id`, `location_id` are non-null and
non-empty on the same row.

Note: The Java test covering this notice is commented out (`// TODO: Put back when this
notice is ready to be published.`). Implement the full logic; do not suppress the notice.

## 4. Implementation approach

**Strategy**: Fully vectorized with Polars. No per-row Python loop for detection. Use
`.iter_rows(named=True)` only to construct notice objects from the filtered result sets.

### 4.1 Guard clauses (ordered)

```
1. if "stop_times" not in feed or feed["stop_times"] is None:
       return []
2. st = feed["stop_times"]
   if st.is_empty():
       return []
3. has_stop_id       = "stop_id" in st.columns
   has_location_group = "location_group_id" in st.columns
   has_location_id    = "location_id" in st.columns
   if not (has_stop_id or has_location_group or has_location_id):
       return []
```

Guard 3 mirrors the Java `shouldCallValidate` check: if none of the three geography
columns are present as file columns at all, skip the validator entirely. This avoids
emitting spurious `missing_required_field` notices for files that simply predate flex
columns — the load-time schema checks handle that case.

### 4.2 Build presence expressions

For each geography column that exists in the DataFrame, build a Polars boolean expression
that is `True` when the column has a non-null, non-empty value:

```python
flags: list[pl.Expr] = []
if has_stop_id:
    flags.append(
        pl.col("stop_id").is_not_null() & (pl.col("stop_id") != "")
    )
if has_location_group:
    flags.append(
        pl.col("location_group_id").is_not_null() & (pl.col("location_group_id") != "")
    )
if has_location_id:
    flags.append(
        pl.col("location_id").is_not_null() & (pl.col("location_id") != "")
    )
```

Cast each boolean flag to `pl.Int32` and sum them to get a `presence_count` per row:

```python
presence_expr = sum(f.cast(pl.Int32) for f in flags)
```

Add the computed column:

```python
st = st.with_columns(presence_expr.alias("_presence"))
```

### 4.3 Handle columns absent from the file

When a geography column does not exist in the DataFrame (i.e., its `has_*` flag is
`False`), it contributes nothing to `presence_expr`. For the `forbidden_geography_id`
notice fields, use `None` for those absent columns:

```python
def _get_or_none(row: dict, col: str, present: bool) -> str | None:
    if not present:
        return None
    val = row.get(col)
    return val if val else None
```

### 4.4 Emit `missing_required_field` notices (presence == 0)

```python
missing = st.filter(pl.col("_presence") == 0)
for row in missing.iter_rows(named=True):
    notices.append(Notice(
        code="missing_required_field",
        severity=Severity.ERROR,
        fields={
            "filename": "stop_times.txt",
            "csv_row_number": row["csv_row_number"],
            "field_name": "stop_id",
        },
    ))
```

### 4.5 Emit `forbidden_geography_id` notices (presence > 1)

```python
forbidden = st.filter(pl.col("_presence") > 1)
for row in forbidden.iter_rows(named=True):
    notices.append(Notice(
        code="forbidden_geography_id",
        severity=Severity.ERROR,
        fields={
            "csv_row_number": row["csv_row_number"],
            "stop_id": _get_or_none(row, "stop_id", has_stop_id),
            "location_group_id": _get_or_none(row, "location_group_id", has_location_group),
            "location_id": _get_or_none(row, "location_id", has_location_id),
        },
    ))
```

### 4.6 Column selection

Before applying the `with_columns` call, select only the columns needed to avoid carrying
the full stop_times width through the computation:

```python
select_cols = ["csv_row_number"]
if has_stop_id:
    select_cols.append("stop_id")
if has_location_group:
    select_cols.append("location_group_id")
if has_location_id:
    select_cols.append("location_id")
st = feed["stop_times"].select(select_cols)
```

`stop_times.txt` is present before the validator is called. The validator's own guard
clauses handle the column-level `shouldCallValidate` logic internally.
