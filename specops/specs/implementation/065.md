# Implementation: StopTimesShapeDistTraveledPresenceValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/stop_times_shape_dist_traveled_presence.py`

No new shared utilities are required. The validator reads only `stop_times.txt`
and all logic is self-contained.

## 2. Function Signature

```python
from __future__ import annotations

from typing import TYPE_CHECKING

import polars as pl

from gtfs_validator.notices import Notice, Severity

if TYPE_CHECKING:
    from gtfs_validator.context import ValidationContext


def validate_stop_times_shape_dist_traveled_presence(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted for signature consistency but is not used — all logic
depends solely on the contents of `stop_times.txt`.

## 3. Notice Definitions

### `forbidden_shape_dist_traveled` — severity ERROR

Emitted once per `stop_times.txt` row that:
- has no `stop_id` (null), AND
- has at least one flex location field (`location_group_id` or `location_id`)
  that is non-null, AND
- has a non-null `shape_dist_traveled`.

```python
Notice(
    code="forbidden_shape_dist_traveled",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": <int>,         # stop_times.csv_row_number
        "trip_id": <str>,                # stop_times.trip_id
        "location_group_id": <str | None>,  # None when column absent or value null
        "location_id": <str | None>,        # None when column absent or value null
        "shape_dist_traveled": <float>,  # stop_times.shape_dist_traveled
    },
)
```

**Null semantics for `location_group_id` / `location_id`:** The loading layer
normalises unset optional string columns to `None` (Python `None` / Polars
`null`). Notice fields for these two columns carry `None` when the column is
absent from the file or when the column exists but the value is null for the
offending row. Do not coerce to empty string `""` at this layer; the report
serialiser handles `None` downstream.

## 4. Implementation Approach

### Strategy

All conditions are independent per-row predicates with no cross-row aggregation.
Use Polars vectorised filter expressions to identify violations, then iterate
over the (typically small) violation set to construct notices.

### Guard clause ordering

```
1. "stop_times" not in feed  →  return []
2. "shape_dist_traveled" not in stop_times.columns  →  return []
3. "location_id" not in stop_times.columns
   AND "location_group_id" not in stop_times.columns  →  return []
4. stop_times.is_empty()  →  return []  (naturally; can also short-circuit)
```

Guards 2 and 3 implement the `shouldCallValidate` logic from the Java
original: if the feed cannot possibly have a violation (because the relevant
columns are absent), the validator exits immediately.

### Pseudocode

```
st = feed["stop_times"]

# Guard 1
if "stop_times" not in feed:
    return []

# Guard 2 — shape_dist_traveled column absent
if "shape_dist_traveled" not in st.columns:
    return []

# Guard 3 — neither flex location column present
has_location_id_col    = "location_id"       in st.columns
has_location_group_col = "location_group_id" in st.columns
if not has_location_id_col and not has_location_group_col:
    return []

# Guard 4 — empty table
if st.is_empty():
    return []

# Build filter predicates

# stop_id: if column absent, treat all rows as having no stop_id
if "stop_id" in st.columns:
    has_stop_id_expr = pl.col("stop_id").is_not_null()
else:
    has_stop_id_expr = pl.lit(False)

# At least one flex location field non-null
has_flex_expr = pl.lit(False)
if has_location_group_col:
    has_flex_expr = has_flex_expr | pl.col("location_group_id").is_not_null()
if has_location_id_col:
    has_flex_expr = has_flex_expr | pl.col("location_id").is_not_null()

# Violation = no stop_id AND has flex location AND shape_dist_traveled non-null
violations = st.filter(
    ~has_stop_id_expr
    & has_flex_expr
    & pl.col("shape_dist_traveled").is_not_null()
)

notices = []
for row in violations.iter_rows(named=True):
    notices.append(Notice(
        code="forbidden_shape_dist_traveled",
        severity=Severity.ERROR,
        fields={
            "csv_row_number":      row["csv_row_number"],
            "trip_id":             row["trip_id"],
            "location_group_id":   row.get("location_group_id") if has_location_group_col else None,
            "location_id":         row.get("location_id")       if has_location_id_col    else None,
            "shape_dist_traveled": row["shape_dist_traveled"],
        },
    ))
return notices
```

### Optional column handling

`stop_id`, `location_group_id`, and `location_id` are all optional columns in
`stop_times.txt`. Every reference to these columns is guarded by a
`"<column>" in st.columns` check performed once before the filter. This avoids
`ColumnNotFoundError` at runtime for feeds that omit those columns.

### Why `iter_rows` is acceptable here

The violation set is expected to be small in practice (feeds with flex
locations that also misuse `shape_dist_traveled` are unusual). Even for large
feeds, the Polars filter reduces the working set before row iteration.
Full-table Polars iteration is avoided — only the filtered violation rows are
iterated.

### No joins required

All required fields (`csv_row_number`, `trip_id`, `location_group_id`,
`location_id`, `shape_dist_traveled`) are present in `stop_times.txt` itself.
No cross-table joins are needed.

Append the entry to `VALIDATOR_REGISTRY`:

```python
    name="stop_times_shape_dist_traveled_presence",
    fn=validate_stop_times_shape_dist_traveled_presence,
    requires=["stop_times"],

```

Place this entry near other `stop_times`-only validators (e.g. after
`stop_times_geography_id_presence`) to keep single-table `stop_times`
validators grouped together.

1. `code="forbidden_shape_dist_traveled"`, `severity=Severity.ERROR`,

   "shape_dist_traveled": 10.0}`
2. `code="forbidden_shape_dist_traveled"`, `severity=Severity.ERROR`,
   `fields={"csv_row_number": 2, "trip_id": "first trip",
   "location_group_id": None, "location_id": "loc2",
   "shape_dist_traveled": 45.0}`

Row 3 must not appear in results (early exit: `stop_id` is non-null).
