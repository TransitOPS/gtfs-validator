# Implementation: TripAndShapeDistanceValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/trip_and_shape_distance.py`

No new shared utilities are required. The haversine helper is defined
as a private module-level function within this file. No changes to
`schemas.py` are needed: `shape_dist_traveled` is already defined on
`STOP_TIMES` (column index 14, `_FLT`) and `SHAPES` (column index 4,
`_FLT`); all other columns used (`trip_id`, `shape_id`, `stop_id`,
`stop_sequence`, `stop_lat`, `stop_lon`, `shape_pt_lat`,
`shape_pt_lon`, `shape_pt_sequence`) are already typed.

## 2. Function Signature

```python
from __future__ import annotations

import math

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


DISTANCE_THRESHOLD_METERS: float = 11.1
EARTH_RADIUS_METERS: float = 6_371_010.0


def _haversine_meters(
    lat1: float, lon1: float, lat2: float, lon2: float
) -> float:
    """Great-circle distance in meters using Earth radius 6,371,010 m.

    Matches S2Earth.getDistanceMeters used by the Java implementation.
    """
    phi1, phi2 = math.radians(lat1), math.radians(lat2)
    dphi = math.radians(lat2 - lat1)
    dlam = math.radians(lon2 - lon1)
    a = math.sin(dphi / 2) ** 2 + math.cos(phi1) * math.cos(phi2) * math.sin(dlam / 2) ** 2
    return 2.0 * math.asin(math.sqrt(a)) * EARTH_RADIUS_METERS


def validate_trip_and_shape_distance(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted to satisfy the standard validator signature but is
not used — no date or country-code dependency exists in this validator.

## 3. Notice Definitions

### `trip_distance_exceeds_shape_distance` (ERROR)

Emitted when the last stop time's `shape_dist_traveled` exceeds the
maximum shape-point `shape_dist_traveled` AND the geographic distance
between the last shape point and the last stop is greater than 11.1 m.

```python
Notice(
    code="trip_distance_exceeds_shape_distance",
    severity=Severity.ERROR,
    fields={
        "trip_id": <str>,                       # trips.trip_id
        "shape_id": <str>,                      # trips.shape_id
        "max_trip_distance_traveled": <float>,  # last stop time's shape_dist_traveled
        "max_shape_distance_traveled": <float>, # max shape_dist_traveled across shape points
        "geo_distance_to_shape": <float>,       # haversine distance in meters
    },
)
```

### `trip_distance_exceeds_shape_distance_below_threshold` (WARNING)

Emitted under identical conditions except the geographic distance is
at most 11.1 m (the numeric overshoot is treated as a rounding
artifact).

```python
Notice(
    code="trip_distance_exceeds_shape_distance_below_threshold",
    severity=Severity.WARNING,
    fields={
        "trip_id": <str>,
        "shape_id": <str>,
        "max_trip_distance_traveled": <float>,
        "max_shape_distance_traveled": <float>,
        "geo_distance_to_shape": <float>,
    },
)
```

The two notices are mutually exclusive per trip: at most one is
emitted for any given trip.

## 4. Implementation Approach

### Guard clauses

Return `[]` immediately if any of the four required tables is absent
from `feed` or is empty:

```python
for tbl in ("trips", "stop_times", "stops", "shapes"):
    if tbl not in feed or feed[tbl].is_empty():
        return []
```

This handles the cases where `trips.txt`, `stop_times.txt`,
`stops.txt`, or `shapes.txt` is missing or empty.

### Step 1 — Last stop time per trip (Polars)

Sort `stop_times` by `stop_sequence` ascending, then take the last
row per `trip_id`. This matches the Java behavior of using a list
already ordered by `stop_sequence` and calling `.get(nbStopTimes - 1)`.

```python
last_st = (
    feed["stop_times"]
    .select(["trip_id", "stop_id", "stop_sequence", "shape_dist_traveled"])
    .sort("stop_sequence")
    .group_by("trip_id")
    .last()
    # Replace null shape_dist_traveled with 0.0 (matches Java default getter)
    .with_columns(
        pl.col("shape_dist_traveled").fill_null(0.0)
    )
)
```

Selecting only the four required columns avoids carrying unnecessary
data through subsequent joins.

### Step 2 — Last shape point per shape_id (Polars)

For each `shape_id`, find the shape point with the maximum
`shape_dist_traveled`. Replace null `shape_dist_traveled` with 0.0
before aggregating so the `max_shape_dist == 0` guard behaves
consistently.

```python
max_shape = (
    feed["shapes"]
    .select(["shape_id", "shape_pt_lat", "shape_pt_lon", "shape_dist_traveled"])
    .with_columns(
        pl.col("shape_dist_traveled").fill_null(0.0)
    )
    .sort("shape_dist_traveled", descending=True)
    .group_by("shape_id")
    .first()
    .rename({
        "shape_dist_traveled": "max_shape_dist",
        "shape_pt_lat": "end_shape_lat",
        "shape_pt_lon": "end_shape_lon",
    })
)
```

Using `sort(..., descending=True).group_by().first()` retrieves the
full row (including `shape_pt_lat`/`shape_pt_lon`) for the
maximum-distance point without a secondary join.

### Step 3 — Joins (Polars)

```python
# trips → last stop time (inner join; drops trips without stop times)
joined = feed["trips"].select(["trip_id", "shape_id"]).join(
    last_st, on="trip_id", how="inner"
)

# → stops (inner join on stop_id; drops rows where stop not found)
stops_slim = feed["stops"].select(["stop_id", "stop_lat", "stop_lon"])
joined = joined.join(stops_slim, on="stop_id", how="inner")

# → max shape point (inner join on shape_id; drops trips with no shape or
#   shape_id absent from shapes.txt, including null shape_id)
joined = joined.join(max_shape, on="shape_id", how="inner")
```

An inner join on `shape_id` automatically handles both:
- trips with a null `shape_id` (null key never matches)
- trips whose `shape_id` is absent from `shapes.txt`

### Step 4 — Numeric filter (Polars)

```python
violations = joined.filter(
    (pl.col("max_shape_dist") > 0.0)
    & (pl.col("shape_dist_traveled") > pl.col("max_shape_dist"))
)
```

`max_shape_dist == 0` is excluded by the `> 0.0` guard, which
prevents false positives when shape has no distance data.
`shape_dist_traveled == 0` can never satisfy
`shape_dist_traveled > max_shape_dist` when `max_shape_dist > 0`, so
no explicit guard for zero stop-time distance is needed.

### Step 5 — Geographic distance and notice emission (Python loop)

The filtered result is expected to be small (only trips that have
already violated the numeric threshold). Compute the haversine
distance in a plain Python loop over the rows, then branch on the
threshold:

```python
notices: list[Notice] = []
for row in violations.iter_rows(named=True):
    geo_dist = _haversine_meters(
        row["end_shape_lat"], row["end_shape_lon"],
        row["stop_lat"], row["stop_lon"],
    )
    fields = {
        "trip_id": row["trip_id"],
        "shape_id": row["shape_id"],
        "max_trip_distance_traveled": row["shape_dist_traveled"],
        "max_shape_distance_traveled": row["max_shape_dist"],
        "geo_distance_to_shape": geo_dist,
    }
    if geo_dist > DISTANCE_THRESHOLD_METERS:
        notices.append(Notice(
            code="trip_distance_exceeds_shape_distance",
            severity=Severity.ERROR,
            fields=fields,
        ))
    else:
        notices.append(Notice(
            code="trip_distance_exceeds_shape_distance_below_threshold",
            severity=Severity.WARNING,
            fields=fields,
        ))
return notices
```

The `>` comparison is strict: `geo_dist == 11.1` falls into the
WARNING (below-threshold) path, matching the Java `>` comparator.

### Null handling summary

| Column | Null treatment |
|---|---|
| `stop_times.shape_dist_traveled` | `fill_null(0.0)` before join; 0.0 never exceeds `max_shape_dist` when `max_shape_dist > 0`, so no notice is emitted |
| `shapes.shape_dist_traveled` | `fill_null(0.0)` before `sort + group_by`; max becomes 0.0, which the `max_shape_dist > 0` guard catches |
| `trips.shape_id` | null key on inner join produces no match row; trip silently skipped |
| `stops.stop_lat`/`stop_lon` | treated as present when stop row exists; referential integrity is checked by FK validators elsewhere |

## 6. Test Plan

Test file: `tests/test_validators/test_trip_and_shape_distance.py`

All tests construct minimal `feed` dicts with Polars DataFrames and
call `validate_trip_and_shape_distance` directly. A shared
`ValidationContext` fixture is used (the context values are irrelevant
to this validator).

### Shared helpers

```python
import polars as pl
import pytest
from datetime import date
from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Severity
from gtfs_validator.validators.trip_and_shape_distance import (
    validate_trip_and_shape_distance,
    _haversine_meters,
)

CTX = ValidationContext(country_code="US", date_for_validation=date(2024, 1, 1))


def make_trips(n: int) -> pl.DataFrame:
    """Create n trips: trip_id='t0'..'t{n-1}', shape_id='s0'..'s{n-1}'."""
    return pl.DataFrame({
        "trip_id": [f"t{i}" for i in range(n)],
        "shape_id": [f"s{i}" for i in range(n)],
    })


def make_stop_times(n: int, base_dist: float) -> pl.DataFrame:
    """Create n stop times: trip_id='t0'..'t{n-1}', stop_id='st0'..'st{n-1}',
    stop_sequence=0 for all, shape_dist_traveled=base_dist+i."""
    return pl.DataFrame({
        "trip_id": [f"t{i}" for i in range(n)],
        "stop_id": [f"st{i}" for i in range(n)],
        "stop_sequence": [0] * n,
        "shape_dist_traveled": [base_dist + i for i in range(n)],
    })


def make_shapes(n: int, base_dist: float, lat_lon: float) -> pl.DataFrame:
    """Create n shapes: shape_id='s0'..'s{n-1}',
    shape_dist_traveled=base_dist+i, lat/lon=lat_lon."""
    return pl.DataFrame({
        "shape_id": [f"s{i}" for i in range(n)],
        "shape_pt_lat": [lat_lon] * n,
        "shape_pt_lon": [lat_lon] * n,
        "shape_pt_sequence": list(range(n)),
        "shape_dist_traveled": [base_dist + i for i in range(n)],
    })


def make_stops(n: int) -> pl.DataFrame:
    """Create n stops: stop_id='st0'..'st{n-1}', lat/lon=0.0."""
    return pl.DataFrame({
        "stop_id": [f"st{i}" for i in range(n)],
        "stop_lat": [0.0] * n,
        "stop_lon": [0.0] * n,
    })
```

### Tests derived from Java contracts

**Test 1: `test_trip_distance_exceeds_shape_distance_emits_error`**

Mirrors Java's `testTripDistanceExceedsShapeDistance`.

Setup:
- `trips = make_trips(2)` — trips `t0` (shape `s0`) and `t1` (shape `s1`)
- `stop_times = make_stop_times(1, 10.0)` — one row: `t0`, `st0`, `shape_dist_traveled=10.0`
- `shapes = make_shapes(1, 9.0, 10.0)` — one row: `s0`, `shape_dist_traveled=9.0`, lat/lon=10.0
- `stops = make_stops(1)` — one row: `st0`, lat/lon=0.0

Trip `t0`: `max_stop_time_dist=10.0 > max_shape_dist=9.0`. Geographic
distance between `(10.0, 10.0)` and `(0.0, 0.0)` is approximately
1,571 km, well above 11.1 m.
Trip `t1`: no stop time row; skipped via inner join.

Expected:
- Exactly 1 notice with `code="trip_distance_exceeds_shape_distance"`,
  `severity=Severity.ERROR`.
- `trip_id="t0"`, `shape_id="s0"`.
- `max_trip_distance_traveled=10.0`, `max_shape_distance_traveled=9.0`.
- `geo_distance_to_shape > 11.1`.

**Test 2: `test_zero_shape_distance_emits_no_notice`**

Mirrors Java's `testTripDistanceExceedsShapeDistanceNoShapeDistance`.

Setup: identical to Test 1 except `shapes = make_shapes(1, 0.0, 10.0)`
— `shape_dist_traveled=0.0`.

Expected: no notices. The `max_shape_dist == 0` guard fires; the trip
is silently skipped.

**Test 3: `test_trip_distance_exceeds_shape_distance_emits_warning`**

Mirrors Java's `testTripDistanceExceedsShapeDistanceWarning`.

Setup:
- `trips = make_trips(2)`, `stop_times = make_stop_times(1, 10.0)`,
  `stops = make_stops(1)` — identical to Test 1.

Trip `t0`: `10.0 > 9.0`. Geographic distance between `(0.000001, 0.000001)`

Expected:
- Exactly 1 notice with
  `code="trip_distance_exceeds_shape_distance_below_threshold"`,
  `severity=Severity.WARNING`.
- `trip_id="t0"`, `shape_id="s0"`.
- `geo_distance_to_shape <= 11.1`.
