# Implementation: ShapeIncreasingDistanceValidator

## 1. Module Location

**Validator file:** `src/gtfs_validator/validators/shape_increasing_distance.py`

This validator is self-contained and reads only `shapes.txt` from the feed dict. It requires no shared utilities beyond the standard imports and Python's `math` module.

## 2. Function Signature

```python
from __future__ import annotations

import math
import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity

EARTH_RADIUS_METERS: float = 6_371_010.0
DISTANCE_THRESHOLD_METERS: float = 1.11


def _geodesic_distance_meters(
    lat1: float, lon1: float, lat2: float, lon2: float
) -> float:
    """Great-circle distance in metres using the haversine formula (matches S2Earth)."""
    phi1, phi2 = math.radians(lat1), math.radians(lat2)
    dphi = math.radians(lat2 - lat1)
    dlambda = math.radians(lon2 - lon1)
    a = math.sin(dphi / 2) ** 2 + math.cos(phi1) * math.cos(phi2) * math.sin(dlambda / 2) ** 2
    return 2 * math.atan2(math.sqrt(a), math.sqrt(1 - a)) * EARTH_RADIUS_METERS


def validate_shape_increasing_distance(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted to satisfy the uniform validator signature but is not used by this validator — the check is purely structural against `shapes.txt`.

## 3. Notice Definitions

### `decreasing_shape_distance` — Severity: ERROR

Emitted when consecutive shape points (sorted by `shape_pt_sequence`) have `prev.shape_dist_traveled > curr.shape_dist_traveled`.

```python
Notice(
    code="decreasing_shape_distance",
    severity=Severity.ERROR,
    fields={
        "shape_id": <str>,                    # curr.shape_id
        "csv_row_number": <int>,              # curr.csv_row_number (1-based)
        "shape_dist_traveled": <float>,       # curr.shape_dist_traveled
        "shape_pt_sequence": <int>,           # curr.shape_pt_sequence
        "prev_csv_row_number": <int>,         # prev.csv_row_number (1-based)
        "prev_shape_dist_traveled": <float>,  # prev.shape_dist_traveled
        "prev_shape_pt_sequence": <int>,      # prev.shape_pt_sequence
    },
)
```

All fields are sourced from the **current** (offending lower-distance) point for the primary fields and the **previous** (higher-distance) point for the `prev_*` fields. This matches the Java `DecreasingShapeDistanceNotice(GtfsShape current, GtfsShape previous)` field assignment, regardless of argument order.

## 4. Implementation Approach

### Strategy: plain Python per-group loop

The core logic is pairwise comparison within sorted shape groups. Per AGENTS.md, plain Python algorithms are preferred for geometry/interval logic when clearer than forcing Polars. Group the DataFrame by `shape_id`, sort each group by `shape_pt_sequence`, convert each group to a list of row dicts, then iterate consecutive pairs.

Do **not** use `shapely`, `pyproj`, or any other external geospatial library — only `math` from the standard library.

### Column types from `schemas.py` (`SHAPES` definition)

- `shape_id` — `_ID` → `pl.Utf8`
- `shape_pt_lat` — `_LAT` → `pl.Float64`
- `shape_pt_lon` — `_LON` → `pl.Float64`
- `shape_pt_sequence` — `_INT` → `pl.Int64`
- `shape_dist_traveled` — `_FLT` (optional) → `pl.Float64`, nullable
- `csv_row_number` — injected by loader as `pl.Int64`, 1-based

### Pseudocode

```
def validate_shape_increasing_distance(feed, ctx):
    # Step 1: Guard — absent or empty table
    if "shapes" not in feed or feed["shapes"].is_empty():
        return []

    df = feed["shapes"]
    notices: list[Notice] = []

    # Step 2: Group by shape_id
    for (shape_id,), group in df.group_by("shape_id"):

        # Step 3: Sort ascending by shape_pt_sequence, convert to row dicts
        pts = (
            group
            .sort("shape_pt_sequence")
            .select([
                "csv_row_number",
                "shape_id",
                "shape_pt_lat",
                "shape_pt_lon",
                "shape_pt_sequence",
                "shape_dist_traveled",
            ])
            .to_dicts()
        )

        # Step 4: Iterate consecutive pairs
        for i in range(1, len(pts)):
            prev = pts[i - 1]
            curr = pts[i]

            # 4a: Skip pair if either shape_dist_traveled is null
            if prev["shape_dist_traveled"] is None or curr["shape_dist_traveled"] is None:
                continue

            prev_dist = prev["shape_dist_traveled"]
            curr_dist = curr["shape_dist_traveled"]

            # 4b: Decreasing distance → ERROR, then continue to next pair
            if prev_dist > curr_dist:
                notices.append(Notice(
                    code="decreasing_shape_distance",
                    severity=Severity.ERROR,
                    fields={
                        "shape_id": curr["shape_id"],
                        "csv_row_number": curr["csv_row_number"],
                        "shape_dist_traveled": curr_dist,
                        "shape_pt_sequence": curr["shape_pt_sequence"],
                        "prev_csv_row_number": prev["csv_row_number"],
                        "prev_shape_dist_traveled": prev_dist,
                        "prev_shape_pt_sequence": prev["shape_pt_sequence"],
                    },
                ))
                continue

            # 4c: Equal distance — examine coordinates
            if prev_dist == curr_dist:
                same_lat = curr["shape_pt_lat"] == prev["shape_pt_lat"]
                same_lon = curr["shape_pt_lon"] == prev["shape_pt_lon"]

                # Sub-case 1: Same coordinates → WARNING (duplicated point)
                if same_lat and same_lon:
                    notices.append(Notice(
                        code="equal_shape_distance_same_coordinates",
                        severity=Severity.WARNING,
                        fields={
                            "shape_id": curr["shape_id"],
                            "csv_row_number": curr["csv_row_number"],
                            "shape_dist_traveled": curr_dist,
                            "shape_pt_sequence": curr["shape_pt_sequence"],
                            "prev_csv_row_number": prev["csv_row_number"],
                            "prev_shape_dist_traveled": prev_dist,
                            "prev_shape_pt_sequence": prev["shape_pt_sequence"],
                        },
                    ))

                # Sub-cases 2, 3, 4: Different coordinates — compute geodesic distance
                else:
                    distance_m = _geodesic_distance_meters(
                        prev["shape_pt_lat"], prev["shape_pt_lon"],
                        curr["shape_pt_lat"], curr["shape_pt_lon"],
                    )

                    if distance_m >= DISTANCE_THRESHOLD_METERS:
                        # Sub-case 2: >= 1.11 m → ERROR
                        notices.append(Notice(
                            code="equal_shape_distance_diff_coordinates",
                            severity=Severity.ERROR,
                            fields={
                                "shape_id": curr["shape_id"],
                                "csv_row_number": curr["csv_row_number"],
                                "shape_dist_traveled": curr_dist,
                                "shape_pt_sequence": curr["shape_pt_sequence"],
                                "prev_csv_row_number": prev["csv_row_number"],
                                "prev_shape_dist_traveled": prev_dist,
                                "prev_shape_pt_sequence": prev["shape_pt_sequence"],
                                "actual_distance_between_shape_points": distance_m,
                            },
                        ))
                    elif distance_m > 0.0:
                        # Sub-case 3: 0 < distance < 1.11 m → WARNING
                        notices.append(Notice(
                            code="equal_shape_distance_diff_coordinates_distance_below_threshold",
                            severity=Severity.WARNING,
                            fields={
                                "shape_id": curr["shape_id"],
                                "csv_row_number": curr["csv_row_number"],
                                "shape_dist_traveled": curr_dist,
                                "shape_pt_sequence": curr["shape_pt_sequence"],
                                "prev_csv_row_number": prev["csv_row_number"],
                                "prev_shape_dist_traveled": prev_dist,
                                "prev_shape_pt_sequence": prev["shape_pt_sequence"],
                                "actual_distance_between_shape_points": distance_m,
                            },
                        ))
                    # Sub-case 4: distance == 0.0 exactly → no notice

            # 4d: prev_dist < curr_dist → increasing, normal case, no action

    return notices
```

### Key implementation notes

- **Coordinate equality**: use exact `==` (not `math.isclose`) to match Java's floating-point equality check.
- **Null handling**: the `is None` check on `prev["shape_dist_traveled"]` and `curr["shape_dist_traveled"]` skips the pair without emitting any notice. A shape where some points have no `shape_dist_traveled` simply has those pairs silently skipped.
- **Threshold boundary**: `distance_m >= 1.11` routes to ERROR; `distance_m > 0.0` (and `< 1.11`) routes to WARNING; `distance_m == 0.0` produces no notice.
- **`group_by` key unpacking**: Polars `group_by` yields tuple keys; destructure as `for (shape_id,), group in df.group_by("shape_id")`.
- **No cross-shape interference**: each shape group is processed independently; a problem in one shape does not affect others.

## 5. Registry Entry

Add the import to the import block in `src/gtfs_validator/validators/__init__.py`:

```python
from gtfs_validator.validators.shape_increasing_distance import validate_shape_increasing_distance
```

Append the entry to `VALIDATOR_REGISTRY`:

```python
ValidatorEntry(
    name="shape_increasing_distance",
    fn=validate_shape_increasing_distance,
    requires=["shapes"],
),
```

`requires=["shapes"]` is the complete dependency list. The runner will skip this validator automatically if `shapes` is absent from the feed. The validator also performs its own internal guard against an empty DataFrame.
