# Implementation: StopTimesTripBlockOrderValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/stop_times_trip_block_order.py`

No new shared utilities are required. The validator reads only `stop_times.txt`
and all logic is self-contained.

## 2. Function Signature

```python
from __future__ import annotations

from typing import TYPE_CHECKING

import polars as pl

from gtfs_validator.notices import Notice, Severity

if TYPE_CHECKING:
    from gtfs_validator.context import ValidationContext


def validate_stop_times_trip_block_order(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted for signature consistency but is not used — all logic depends
solely on the contents of `stop_times.txt`.

## 3. Notice Definitions

### `unsorted_stop_times` — severity INFO

Emitted once per `trip_id` whose stop_times rows are either:
- non-contiguous in the file (other trips' rows appear between this trip's
  rows), OR
- have `stop_sequence` values that are not strictly increasing in file order
  (includes duplicate `stop_sequence` values).

At most one notice is emitted per `trip_id`, regardless of how many
contiguity gaps or sequence inversions are present.

```python
Notice(
    code="unsorted_stop_times",
    severity=Severity.INFO,
    fields={
        "trip_id": <str>,                  # stop_times.trip_id
        "start_csv_row_number": <int>,     # min csv_row_number for this trip
        "end_csv_row_number": <int>,       # max csv_row_number for this trip
    },
)
```

## 4. Implementation Approach

### Strategy

Use Polars vectorised operations for both checks.

The **contiguity check** is a pure grouped aggregation: compute
`span = max(csv_row_number) - min(csv_row_number) + 1` and
`row_count = count(csv_row_number)` per `trip_id`. If `span > row_count`, the
trip's rows are non-contiguous.

The **unsorted sequence check** requires a within-group lag comparison that
respects file insertion order (not sorted `stop_sequence` order). Add a
monotonic row index with `with_row_index`, then use
`pl.col("stop_sequence").shift(1).over("trip_id", order_by="_file_row")` to
compute the previous `stop_sequence` in file order within each trip. Any row
where `stop_sequence <= _prev_seq` marks the trip as having an unsorted
sequence.

Both results are combined with a left join and a filter, producing at most one
row per violating trip, which is then iterated to construct notices.

### Guard clause ordering

```
1. "stop_times" not in feed          →  return []
2. feed["stop_times"].is_empty()     →  return []
3. all trip_id values are null       →  return []  (handled naturally by filter)
```

### Pseudocode

```
st = feed["stop_times"]

# Guard 1
if "stop_times" not in feed:
    return []

# Guard 2
if st.is_empty():
    return []

# Drop rows with null trip_id
st = st.filter(pl.col("trip_id").is_not_null())
if st.is_empty():
    return []

# --- Contiguity check (vectorised groupby) ---
agg = (
    st.group_by("trip_id")
    .agg(
        pl.col("csv_row_number").count().alias("row_count"),
        pl.col("csv_row_number").min().alias("min_row"),
        pl.col("csv_row_number").max().alias("max_row"),
    )
    .with_columns(
        (pl.col("max_row") - pl.col("min_row") + 1).alias("span")
    )
    .with_columns(
        (pl.col("span") > pl.col("row_count")).alias("non_contiguous")
    )
)

# --- Unsorted sequence check (file-order lag within trip) ---
# Add a monotonic file-position index to preserve row order within groups.
st_indexed = st.with_row_index("_file_row")

# Within each trip (file order), find rows where stop_sequence <= previous
st_lagged = st_indexed.with_columns(
    pl.col("stop_sequence")
      .shift(1)
      .over("trip_id", order_by="_file_row")
      .alias("_prev_seq")
).with_columns(
    (pl.col("stop_sequence") <= pl.col("_prev_seq")).alias("_is_unsorted")
)

unsorted_trips = (
    st_lagged
    .filter(pl.col("_is_unsorted"))
    .select("trip_id")
    .unique()
)

# --- Combine: join unsorted flag onto aggregated contiguity data ---
result = (
    agg
    .join(
        unsorted_trips.with_columns(pl.lit(True).alias("unsorted_sequence")),
        on="trip_id",
        how="left",
    )
    .with_columns(pl.col("unsorted_sequence").fill_null(False))
    .filter(pl.col("non_contiguous") | pl.col("unsorted_sequence"))
)

# --- Construct notices (one per violating trip) ---
notices = []
for row in result.iter_rows(named=True):
    notices.append(Notice(
        code="unsorted_stop_times",
        severity=Severity.INFO,
        fields={
            "trip_id": row["trip_id"],
            "start_csv_row_number": row["min_row"],
            "end_csv_row_number": row["max_row"],
        },
    ))
return notices
```

### Why `iter_rows` is acceptable here

The result set contains at most one row per violating trip. For real-world feeds
the number of violating trips is small. The expensive Polars work (groupby,
shift/over, join, filter) completes before any Python-level iteration.

### File order preservation

Do not sort `stop_times` by `stop_sequence` before the sequence check. The
validator explicitly checks file order. The `_file_row` index added with
`with_row_index` captures the position of each row as it exists after the null
`trip_id` filter, which is sufficient to determine within-group file order.

### One-notice-per-trip guarantee

The `group_by().agg()` step produces exactly one row per `trip_id` for the
contiguity data. The join onto `unsorted_trips` (which uses `.unique()`) also
produces one row per `trip_id`. The final filter does not duplicate rows.
The one-notice-per-trip guarantee is structurally enforced.

### `csv_row_number` requirement

This validator depends on `csv_row_number` being present in `stop_times.txt` as
a 1-based integer column injected by the loading layer. Both notice fields
(`start_csv_row_number`, `end_csv_row_number`) and the contiguity calculation
use this column. The validator will raise a `ColumnNotFoundError` at runtime if
the loading layer omits it — this is intentional and surfaces a loader bug.

`stop_times_record`) to keep single-table `stop_times` validators grouped
together.

### Tests derived from the Java contract

**`test_non_contiguous_trip_block_emits_notice`**

Mirrors `UnsortedStopTimesNotice_generateNotice_nonContiguousTripBlock`.

Input: four rows, two trips interleaved:
- `{"trip_id": "0914", "stop_sequence": 1, "csv_row_number": 1}`
- `{"trip_id": "0914", "stop_sequence": 2, "csv_row_number": 2}`
- `{"trip_id": "0915", "stop_sequence": 1, "csv_row_number": 3}`
- `{"trip_id": "0914", "stop_sequence": 3, "csv_row_number": 4}`

Expected: result list contains exactly one notice:
```python
Notice(
    code="unsorted_stop_times",
    severity=Severity.INFO,
    fields={"trip_id": "0914", "start_csv_row_number": 1, "end_csv_row_number": 4},
)
```
Trip `"0915"` must NOT appear in the results (span=1, count=1, no sequence
inversion).

---

**`test_non_increasing_stop_sequence_emits_notice`**

Mirrors `UnsortedStopTimesNotice_generateNotice_nonIncreasingStopSequence`.

Input: three rows, one trip with non-monotonic sequence:
- `{"trip_id": "0916", "stop_sequence": 1, "csv_row_number": 1}`
- `{"trip_id": "0916", "stop_sequence": 3, "csv_row_number": 2}`
- `{"trip_id": "0916", "stop_sequence": 2, "csv_row_number": 3}`

Expected: result list contains exactly one notice:
```python
Notice(
    code="unsorted_stop_times",
    severity=Severity.INFO,
    fields={"trip_id": "0916", "start_csv_row_number": 1, "end_csv_row_number": 3},
)
```
Rationale: at row 3, `stop_sequence=2 <= last=3`; span equals count so
non-contiguous is false; notice is triggered by sequence check alone.
