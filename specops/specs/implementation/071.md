## 1. Module location

`src/gtfs_validator/validators/timepoint_time.py`

## 2. Function signature

```python
def validate_timepoint_time(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

Standard validator signature per AGENTS.md. `ctx` is accepted but not used.

## 3. Notice definitions

### `missing_timepoint_value`

```python
Notice(
    code="missing_timepoint_value",
    severity=Severity.WARNING,
    fields={
        "csv_row_number": int,  # from stop_times.csv_row_number
        "trip_id": str,         # from stop_times.trip_id
        "stop_sequence": int,   # from stop_times.stop_sequence
    },
)
```

Condition: `timepoint` column is present in the header AND the cell value is
null (empty) for this row AND at least one of `arrival_time` or
`departure_time` is non-null on this row.

Severity: WARNING.

### `stop_time_timepoint_without_times`

```python
Notice(
    code="stop_time_timepoint_without_times",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": int,   # from stop_times.csv_row_number
        "trip_id": str,          # from stop_times.trip_id
        "stop_sequence": int,    # from stop_times.stop_sequence
        "specified_field": str,  # literal "arrival_time" or "departure_time"
    },
)
```

Condition: `timepoint == 1` (EXACT) AND the named time field is null. Emitted
once per missing time field per row — up to two notices for a single row when
both times are absent.

Severity: ERROR.

## 4. Implementation approach

**Strategy**: Polars vectorized filtering. Three independent filter passes over
the `stop_times` DataFrame produce the violation sets. The function first
applies header-level and table-level guard clauses, then runs the two checks
independently.

**Column guard order**:
1. Table absent or empty — return `[]`.
2. `"timepoint"` not in `st.columns` — return `[]`.

**Timepoint enum values** (used only for equality comparison, not numeric
arithmetic):

```
EXACT = 1
```

`timepoint == 0` (APPROXIMATE) rows are invisible to both checks.

**Time field representation**: `arrival_time` and `departure_time` are Utf8
strings after loading. Null means absent. No numeric parsing is needed — only
null/non-null checks are required.

**Required columns** (checked defensively before filter passes):

```
{"csv_row_number", "trip_id", "stop_sequence", "arrival_time", "departure_time", "timepoint"}
```

If any required column is absent, return `[]`.

**Pseudocode**:

```
def validate_timepoint_time(feed, ctx):
    if "stop_times" not in feed or feed["stop_times"].is_empty():
        return []

    st = feed["stop_times"]

    # Guard: timepoint column must exist in the header
    if "timepoint" not in st.columns:
        return []

    required = {"csv_row_number", "trip_id", "stop_sequence",
                "arrival_time", "departure_time", "timepoint"}
    if not required.issubset(set(st.columns)):
        return []

    notices = []

    # Check 1: row has at least one time but timepoint cell is null (WARNING)
    has_time = pl.col("arrival_time").is_not_null() | pl.col("departure_time").is_not_null()
    missing_tp = pl.col("timepoint").is_null()

    check1_rows = st.filter(has_time & missing_tp)
    for row in check1_rows.iter_rows(named=True):
        notices.append(Notice(
            code="missing_timepoint_value",
            severity=Severity.WARNING,
            fields={
                "csv_row_number": row["csv_row_number"],
                "trip_id": row["trip_id"],
                "stop_sequence": row["stop_sequence"],
            },
        ))

    # Check 2a: exact timepoints (timepoint == 1) missing arrival_time
    exact = st.filter(pl.col("timepoint") == 1)

    for row in exact.filter(pl.col("arrival_time").is_null()).iter_rows(named=True):
        notices.append(Notice(
            code="stop_time_timepoint_without_times",
            severity=Severity.ERROR,
            fields={
                "csv_row_number": row["csv_row_number"],
                "trip_id": row["trip_id"],
                "stop_sequence": row["stop_sequence"],
                "specified_field": "arrival_time",
            },
        ))

    # Check 2b: exact timepoints (timepoint == 1) missing departure_time
    for row in exact.filter(pl.col("departure_time").is_null()).iter_rows(named=True):
        notices.append(Notice(
            code="stop_time_timepoint_without_times",
            severity=Severity.ERROR,
            fields={
                "csv_row_number": row["csv_row_number"],
                "trip_id": row["trip_id"],
                "stop_sequence": row["stop_sequence"],
                "specified_field": "departure_time",
            },
        ))

    return notices
```

**Emission order**: All Check 1 notices (WARNING) precede all Check 2a notices
(`arrival_time` ERROR), which precede all Check 2b notices (`departure_time`
ERROR). Within each pass, row order follows DataFrame order (input CSV row
order). This differs from the Java per-row interleaved order but is
behaviorally equivalent for all notice count and correctness assertions.

**Mutual exclusivity**: Check 1 fires only when `timepoint IS NULL`; Check 2
fires only when `timepoint == 1`. A single row cannot trigger both checks
simultaneously.

**No joins or cross-table references**: This validator reads only
`stop_times`. No other table or `ctx` field is accessed.

## 6. Test plan

Test file: `tests/test_validators/test_timepoint_time.py`

All tests build minimal DataFrames containing at least the columns
`trip_id`, `stop_sequence`, `arrival_time`, `departure_time`, `timepoint`, and
`csv_row_number`. Integer columns use Python `int` (or `None`); string columns
use Python `str` (or `None`). Polars infers dtypes from the Python values.
Assertions check exact notice count, `code`, `severity`, and relevant `fields`
keys.

Helper to build a minimal one-row DataFrame:

```python
def _make_st(
    *,
    trip_id="T1",
    stop_sequence=1,
    arrival_time=None,
    departure_time=None,
    timepoint=None,
    csv_row_number=1,
    include_timepoint_col=True,
) -> pl.DataFrame:
    data = {
        "trip_id": [trip_id],
        "stop_sequence": [stop_sequence],
        "arrival_time": [arrival_time],
        "departure_time": [departure_time],
        "csv_row_number": [csv_row_number],
    }
    if include_timepoint_col:
        data["timepoint"] = [timepoint]
    return pl.DataFrame(data)
```
