# Implementation: ContinuousPickupDropOffValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/continuous_pickup_drop_off.py`

No new shared utilities are required. This is a cross-table validator
joining `routes.txt`, `trips.txt`, and `stop_times.txt`. The join-based
approach is well suited to Polars expressions and does not require
row-level iteration.

## 2. Function Signature

```python
from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_continuous_pickup_drop_off(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice Definitions

All notices have severity **ERROR**.

### `forbidden_continuous_pickup_drop_off`

Emitted when a stop time defines a pickup/drop-off window on a route
that has continuous pickup or drop-off enabled.

```python
Notice(
    code="forbidden_continuous_pickup_drop_off",
    severity=Severity.ERROR,
    fields={
        "route_csv_row_number": <int>,
        "trip_id": <str>,
        "stop_time_csv_row_number": <int>,
        "start_pickup_drop_off_window": <str | None>,
        "end_pickup_drop_off_window": <str | None>,
    },
)
```

One notice is emitted per offending stop_time row. If a stop_time has
both window fields set, only one notice is emitted (not two). The window
values are included in the notice for informational purposes; either may
be `None` if only one is populated.

## 4. Implementation Approach

### Constants

```python
# The only non-continuous value for continuous_pickup / continuous_drop_off
NOT_AVAILABLE = 1
```

### Skip condition

The validator should not run unless the required tables and columns are
present. This mirrors the Java `shouldCallValidate` logic:

```python
def _should_run(feed: dict[str, pl.DataFrame]) -> bool:
    if "routes" not in feed or "stop_times" not in feed:
        return False
    routes_cols = feed["routes"].columns
    st_cols = feed["stop_times"].columns

    has_continuous_pickup = "continuous_pickup" in routes_cols
    has_continuous_drop_off = "continuous_drop_off" in routes_cols
    has_start_window = "start_pickup_drop_off_window" in st_cols
    has_end_window = "end_pickup_drop_off_window" in st_cols

    # Java operator precedence: hasCol(cp) || (hasCol(cdo) && (hasCol(sw) || hasCol(ew)))
    return has_continuous_pickup or (
        has_continuous_drop_off and (has_start_window or has_end_window)
    )
```

### Main validator pseudocode

```
function validate_continuous_pickup_drop_off(feed, ctx):
    # 1. Guard: skip condition
    if not _should_run(feed):
        return []

    routes = feed["routes"]
    stop_times = feed["stop_times"]

    # trips table is needed for the join; if absent, no join path exists
    if "trips" not in feed:
        return []
    trips = feed["trips"]

    # 2. Filter routes to those with continuous behavior.
    #    A route is "continuous" when continuous_pickup != 1 OR
    #    continuous_drop_off != 1. Null values mean the column exists
    #    but the cell is empty — treat null as non-continuous (skip).
    #
    #    Build filter expression based on which columns are present.
    routes_cols = routes.columns
    conditions = []
    if "continuous_pickup" in routes_cols:
        conditions.append(
            pl.col("continuous_pickup").is_not_null()
            & (pl.col("continuous_pickup") != NOT_AVAILABLE)
        )
    if "continuous_drop_off" in routes_cols:
        conditions.append(
            pl.col("continuous_drop_off").is_not_null()
            & (pl.col("continuous_drop_off") != NOT_AVAILABLE)
        )

    if not conditions:
        return []

    # Combine with OR — at least one field indicates continuous
    continuous_filter = conditions[0]
    for c in conditions[1:]:
        continuous_filter = continuous_filter | c

    continuous_routes = routes.filter(continuous_filter).select(
        "route_id", "csv_row_number"
    )
    if continuous_routes.is_empty():
        return []

    # Rename to avoid column collision after join
    continuous_routes = continuous_routes.rename(
        {"csv_row_number": "route_csv_row_number"}
    )

    # 3. Join continuous routes -> trips -> stop_times
    joined = (
        continuous_routes
        .join(trips.select("trip_id", "route_id"), on="route_id", how="inner")
        .join(stop_times, on="trip_id", how="inner")
    )

    if joined.is_empty():
        return []

    # 4. Filter to rows where at least one window field is non-null
    st_cols = stop_times.columns
    window_conditions = []
    if "start_pickup_drop_off_window" in st_cols:
        window_conditions.append(pl.col("start_pickup_drop_off_window").is_not_null())
    if "end_pickup_drop_off_window" in st_cols:
        window_conditions.append(pl.col("end_pickup_drop_off_window").is_not_null())

    if not window_conditions:
        return []

    window_filter = window_conditions[0]
    for w in window_conditions[1:]:
        window_filter = window_filter | w

    violations = joined.filter(window_filter)

    if violations.is_empty():
        return []

    # 5. Emit one notice per violation row
    notices = []
    for row in violations.iter_rows(named=True):
        notices.append(Notice(
            code="forbidden_continuous_pickup_drop_off",
            severity=Severity.ERROR,
            fields={
                "route_csv_row_number": row["route_csv_row_number"],
                "trip_id": row["trip_id"],
                "stop_time_csv_row_number": row["csv_row_number"],
                "start_pickup_drop_off_window": (
                    str(row["start_pickup_drop_off_window"])
                    if row.get("start_pickup_drop_off_window") is not None
                    else None
                ),
                "end_pickup_drop_off_window": (
                    str(row["end_pickup_drop_off_window"])
                    if row.get("end_pickup_drop_off_window") is not None
                    else None
                ),
            },
        ))
    return notices
```

**Key design decisions:**

- **Polars join pipeline over row iteration for filtering.** The core
  logic is a three-table join with simple column-presence filters, which
  maps naturally to Polars joins and `filter`. Row iteration is used only
  at the final step to construct `Notice` objects from the violation rows.
- **Dynamic column checks.** The validator checks whether
  `continuous_pickup`, `continuous_drop_off`, `start_pickup_drop_off_window`,
  and `end_pickup_drop_off_window` columns exist in the loaded DataFrames
  before referencing them. This handles feeds where optional columns are
  absent.
- **Null individual values treated as non-continuous.** When the column
  exists but a cell is null, the route is not treated as continuous. This
  differs from the default value (0 = ALLOWED) which IS continuous. The
  loader should cast the column and apply schema defaults; if the loader
  fills defaults, null cells become 0 and are correctly treated as
  continuous. If the loader leaves nulls, they are safely excluded.
- **`csv_row_number` column.** Assumes the loader populates a 1-based
  `csv_row_number` column on each DataFrame, consistent with other
  validators.
- **Window values as strings.** The `start_pickup_drop_off_window` and
  `end_pickup_drop_off_window` fields are TIME type columns. They are
  cast to strings in the notice for informational display, matching the
  Java `GtfsTime` toString representation.

## 5. Registry Entry

In `src/gtfs_validator/validators/__init__.py`, add the import and
registry entry:

```python
from gtfs_validator.validators.continuous_pickup_drop_off import validate_continuous_pickup_drop_off

# Add to VALIDATOR_REGISTRY list:
ValidatorEntry(
    name="continuous_pickup_drop_off",
    fn=validate_continuous_pickup_drop_off,
    requires=["routes", "trips", "stop_times"],
),
```

The `requires` list contains all three tables used in the join path.

  `end_pickup_drop_off_window="09:00:00"`.
