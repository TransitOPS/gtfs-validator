## 3. Notice definitions

### `missing_pickup_drop_off_booking_rule_id`

- **Code**: `"missing_pickup_drop_off_booking_rule_id"`
- **Severity**: `Severity.WARNING`
- **Fields dict structure**:

```python
{
    "csv_row_number": int,          # stop_times.csv_row_number for the offending row
    "pickup_type": int | None,      # the row's pickup_type value, or None if absent/null
    "drop_off_type": int | None,    # the row's drop_off_type value, or None if absent/null
}
```

For sub-check A violations (missing `pickup_booking_rule_id`):
- `pickup_type` is always `2` (MUST_PHONE)
- `drop_off_type` is the row's `drop_off_type` value, which may be None

For sub-check B violations (missing `drop_off_booking_rule_id`):
- `drop_off_type` is always `2` (MUST_PHONE)
- `pickup_type` is the row's `pickup_type` value, which may be None

## 4. Implementation approach

**Approach**: Polars vectorized filter, then row iteration for notice construction.

The logic uses two independent Polars filter passes over `stop_times`, one for each sub-check. The filter conditions directly encode the three-part trigger condition per sub-check. Absent optional columns are handled before filtering by checking `df.columns`.

**Pseudocode**:

```
function validate_pickup_booking_rule_id(feed, ctx):

    # Guard: both tables must be present
    if "booking_rules" not in feed:
        return []
    if "stop_times" not in feed:
        return []

    df = feed["stop_times"]
    cols = set(df.columns)

    # Guard: at least one of pickup_type / drop_off_type must exist
    if "pickup_type" not in cols and "drop_off_type" not in cols:
        return []

    notices = []

    # Sub-check A: missing pickup_booking_rule_id
    if "pickup_type" in cols:
        # Window column absent → treat as all-null → no rows match
        if "start_pickup_drop_off_window" in cols:
            pickup_violations = df.filter(
                pl.col("pickup_type").eq(2)
                & pl.col("start_pickup_drop_off_window").is_not_null()
                & (
                    pl.col("pickup_booking_rule_id").is_null()
                    if "pickup_booking_rule_id" in cols
                    else pl.lit(True)
                )
            )
            for row in pickup_violations.iter_rows(named=True):
                notices.append(Notice(
                    code="missing_pickup_drop_off_booking_rule_id",
                    severity=Severity.WARNING,
                    fields={
                        "csv_row_number": row["csv_row_number"],
                        "pickup_type": 2,
                        "drop_off_type": row.get("drop_off_type"),  # None if column absent
                    },
                ))

    # Sub-check B: missing drop_off_booking_rule_id
    if "drop_off_type" in cols:
        if "end_pickup_drop_off_window" in cols:
            dropoff_violations = df.filter(
                pl.col("drop_off_type").eq(2)
                & pl.col("end_pickup_drop_off_window").is_not_null()
                & (
                    pl.col("drop_off_booking_rule_id").is_null()
                    if "drop_off_booking_rule_id" in cols
                    else pl.lit(True)
                )
            )
            for row in dropoff_violations.iter_rows(named=True):
                notices.append(Notice(
                    code="missing_pickup_drop_off_booking_rule_id",
                    severity=Severity.WARNING,
                    fields={
                        "csv_row_number": row["csv_row_number"],
                        "pickup_type": row.get("pickup_type"),  # None if column absent
                        "drop_off_type": 2,
                    },
                ))

    return notices
```

**Column presence handling details**:

- If `pickup_booking_rule_id` is absent from `df.columns`, treat every row as having a null booking rule ID (all rows with `pickup_type=2` and non-null window would trigger). Use `pl.lit(True)` in the filter for the null-booking-rule clause.
- If `drop_off_booking_rule_id` is absent, same treatment.
- If `start_pickup_drop_off_window` is absent, skip sub-check A entirely (no filter match possible; no rows to iterate).
- If `end_pickup_drop_off_window` is absent, skip sub-check B entirely.
- When building the notice, `row.get("drop_off_type")` returns `None` if the column is absent from the DataFrame (since `iter_rows(named=True)` only yields present columns). Use `row.get(col_name)` rather than `row[col_name]` for optional sibling fields.

**Null semantics enforced by Polars**:

- `pl.col("pickup_type").eq(2)` returns `False` for null values, so null `pickup_type` rows are naturally excluded from sub-check A.
- `pl.col("drop_off_type").eq(2)` returns `False` for null, naturally excluding them from sub-check B.
- `pl.col("start_pickup_drop_off_window").is_not_null()` requires the window field to carry a non-null value.
