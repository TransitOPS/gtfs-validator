# Implementation: RouteNameValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/route_name.py`

No shared utilities needed. This is a single-table, per-row validator
that reads only `routes.txt`. The regex pattern is compiled once at
module level. All validation logic is plain Python row iteration after a
Polars guard check.

## 2. Function Signature

```python
from __future__ import annotations

import re

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity

MAX_SHORT_NAME_LENGTH = 12
LONG_NAME_CONTAINS_SHORT_NAME_RE = re.compile(r"^\s?[\s\-\(\)].*")


def validate_route_name(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`MAX_SHORT_NAME_LENGTH` and `LONG_NAME_CONTAINS_SHORT_NAME_RE` are
module-level definitions. `ctx` is unused but required by the standard
validator signature.

## 3. Notice Definitions

### `route_both_short_and_long_name_missing` (ERROR)

Emitted when a route row has neither `route_short_name` nor
`route_long_name` (both are null).

```python
Notice(
    code="route_both_short_and_long_name_missing",
    severity=Severity.ERROR,
    fields={
        "route_id": <str>,          # routes.route_id
        "csv_row_number": <int>,    # 1-based row number from routes.txt
    },
)
```

### `route_short_name_too_long` (WARNING)

Emitted when `route_short_name` is present and its character length is
strictly greater than 12.

```python
Notice(
    code="route_short_name_too_long",
    severity=Severity.WARNING,
    fields={
        "route_id": <str>,           # routes.route_id
        "csv_row_number": <int>,     # 1-based row number from routes.txt
        "route_short_name": <str>,   # the too-long short name value (original case)
    },
)
```

### `route_long_name_contains_short_name` (WARNING)

Emitted when `route_long_name` begins with `route_short_name`
(case-insensitive) and the remainder is either empty or starts with a
separator pattern.

```python
Notice(
    code="route_long_name_contains_short_name",
    severity=Severity.WARNING,
    fields={
        "route_id": <str>,           # routes.route_id
        "csv_row_number": <int>,     # 1-based row number from routes.txt
        "route_short_name": <str>,   # the short name found as prefix (original case)
        "route_long_name": <str>,    # the long name containing the prefix (original case)
    },
)
```

### `same_name_and_description_for_route` (WARNING)

Emitted when `route_desc` duplicates either `route_short_name` or
`route_long_name` (case-insensitive exact match). The `specified_field`
field names which name was duplicated. The `route_desc` value stored in
the notice is always the **raw** (original case) value from the feed.

```python
Notice(
    code="same_name_and_description_for_route",
    severity=Severity.WARNING,
    fields={
        "csv_row_number": <int>,      # 1-based row number from routes.txt
        "route_id": <str>,            # routes.route_id
        "route_desc": <str>,          # the description value (original case)
        "specified_field": <str>,     # "route_short_name" or "route_long_name"
    },
)
```

## 4. Implementation Approach

Plain Python row iteration (Option A from the analysis spec) is used for
all four checks. The logic involves a regex on a string remainder and a
short-circuit `continue` in check 4, both of which are awkward to
express as Polars expressions. The expected number of violations is
small, so row iteration over `routes.txt` is acceptable.

### Algorithm

```
MAX_SHORT_NAME_LENGTH = 12
LONG_NAME_CONTAINS_SHORT_NAME_RE = re.compile(r"^\s?[\s\-\(\)].*")


function validate_route_name(feed, ctx):
    # Guard: table must exist and be non-empty
    if "routes" not in feed or feed["routes"].is_empty():
        return []

    routes = feed["routes"]
    notices = []

    for row in routes.iter_rows(named=True):
        short    = row["route_short_name"]   # str | None
        long_    = row["route_long_name"]    # str | None
        desc     = row["route_desc"]         # str | None
        route_id = row["route_id"]
        csv_row  = row["csv_row_number"]

        # Check 1: both names missing
        if short is None and long_ is None:
            notices.append(Notice(
                code="route_both_short_and_long_name_missing",
                severity=Severity.ERROR,
                fields={"route_id": route_id, "csv_row_number": csv_row},
            ))

        # Check 2: short name too long
        if short is not None and len(short) > MAX_SHORT_NAME_LENGTH:
            notices.append(Notice(
                code="route_short_name_too_long",
                severity=Severity.WARNING,
                fields={
                    "route_id": route_id,
                    "csv_row_number": csv_row,
                    "route_short_name": short,
                },
            ))

        # Check 3: long name contains short name as prefix
        if short is not None and long_ is not None:
            if long_.lower().startswith(short.lower()):
                remainder = long_[len(short):]
                if remainder == "" or LONG_NAME_CONTAINS_SHORT_NAME_RE.match(remainder):
                    notices.append(Notice(
                        code="route_long_name_contains_short_name",
                        severity=Severity.WARNING,
                        fields={
                            "route_id": route_id,
                            "csv_row_number": csv_row,
                            "route_short_name": short,
                            "route_long_name": long_,
                        },
                    ))

        # Check 4: description duplicates a name
        if desc is not None:
            # Sub-check 4a: desc vs. short name (takes precedence)
            if short is not None and desc.lower() == short.lower():
                notices.append(Notice(
                    code="same_name_and_description_for_route",
                    severity=Severity.WARNING,
                    fields={
                        "csv_row_number": csv_row,
                        "route_id": route_id,
                        "route_desc": desc,
                        "specified_field": "route_short_name",
                    },
                ))
                continue  # suppress sub-check 4b for this row

            # Sub-check 4b: desc vs. long name (only if 4a did not fire)
            if long_ is not None and desc.lower() == long_.lower():
                notices.append(Notice(
                    code="same_name_and_description_for_route",
                    severity=Severity.WARNING,
                    fields={
                        "csv_row_number": csv_row,
                        "route_id": route_id,
                        "route_desc": desc,
                        "specified_field": "route_long_name",
                    },
                ))

    return notices
```

**Key design decisions:**

- **Plain Python row iteration.** The separator-regex check on the
  string remainder (check 3) and the `continue`-based short-circuit in
  check 4 are both cleaner as imperative Python than as Polars
  expressions. `routes.txt` is typically small; row iteration introduces
  no meaningful performance concern.
- **`csv_row_number` is provided by the loader.** The loading pipeline
  attaches a 1-based `csv_row_number` integer column to every table.
  This validator reads it directly without computing it.
- **Null handling.** `iter_rows(named=True)` returns Python `None` for
  null cells. Null checks use `is None` / `is not None`.
- **Case sensitivity.** All string comparisons are performed on
  `.lower()` versions. The original-case values are stored in notices,
  not the lowercased copies.
- **Remainder extraction for check 3.** The `startswith` comparison is
  on lowercased strings, but the remainder is sliced from the
  **original-case** `long_` using `len(short)` as the offset. This is
  correct because `len(short) == len(short.lower())`.
- **Short-circuit in check 4.** The `continue` after emitting
  `same_name_and_description_for_route` for `route_short_name` is
  semantically required: it prevents a second notice for `route_long_name`
  when `desc` happens to match both (which only occurs when all three
  values are equal).
- **Checks 1 and 2 are independent.** A row that fails both (e.g.,
  both names missing is impossible to also have a too-long short name,
  but conceptually) they do not gate each other. In practice check 1
  fires when `short is None`, so check 2 cannot also fire on the same
  row; however the implementation makes no explicit coupling between them.

### Regex pattern note

The module-level constant `LONG_NAME_CONTAINS_SHORT_NAME_RE` is
compiled once:

```python
LONG_NAME_CONTAINS_SHORT_NAME_RE = re.compile(r"^\s?[\s\-\(\)].*")
```

This matches strings where:
- The first character is an optional whitespace (`\s?`)
- The next character is one of: whitespace, hyphen, `(`, `)` (`[\s\-\(\)]`)
- Followed by anything (`.*`)

An empty string does not match this regex (the `[\s\-\(\)]` group
requires at least one character), which is why the empty-remainder case
is handled separately with `remainder == ""`.

## 5. Registry Entry

In `src/gtfs_validator/validators/__init__.py`, add the import and
registry entry:

```python
from gtfs_validator.validators.route_name import validate_route_name

# Add to VALIDATOR_REGISTRY list:
ValidatorEntry(
    name="route_name",
    fn=validate_route_name,
    requires=["routes"],
),
```

The `requires` list contains only `"routes"`. The runner skips this
validator entirely if `routes.txt` is absent, consistent with the
`if "routes" not in feed` guard inside the function.

### Shared test helpers

```python
from datetime import date

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Severity
from gtfs_validator.validators.route_name import validate_route_name

CTX = ValidationContext(country_code="US", date_for_validation=date(2024, 1, 1))


def make_feed(rows: list[dict]) -> dict[str, pl.DataFrame]:
    """Build a minimal feed dict with a routes DataFrame."""
    schema = {
        "route_id": pl.Utf8,
        "csv_row_number": pl.Int64,
        "route_short_name": pl.Utf8,
        "route_long_name": pl.Utf8,
        "route_desc": pl.Utf8,
    }
    if not rows:
        return {"routes": pl.DataFrame(schema=schema)}
    return {"routes": pl.DataFrame(rows).cast(schema)}


def make_route(
    short: str | None,
    long_: str | None,
    desc: str | None,
    route_id: str = "r1",
    csv_row_number: int = 2,
) -> dict[str, pl.DataFrame]:
    return make_feed([{
        "route_id": route_id,
        "csv_row_number": csv_row_number,
        "route_short_name": short,
        "route_long_name": long_,
        "route_desc": desc,
    }])
```
