## 3. Notice definitions

### `wrong_parent_location_type` — ERROR

Emitted when a stop's `parent_station` points to a record whose `location_type` is not the expected type for that child's `location_type`.

```python
Notice(
    code="wrong_parent_location_type",
    severity=Severity.ERROR,
    fields={
        "csvRowNumber": <int>,              # csvRowNumber of the child stop row
        "stopId": <str>,                    # child stop_id
        "stopName": <str | None>,           # child stop_name (null passed through as-is)
        "locationType": <int>,              # child location_type (raw integer)
        "parentCsvRowNumber": <int>,        # csvRowNumber of the parent stop row
        "parentStation": <str>,             # child's parent_station value (parent stop_id)
        "parentStopName": <str | None>,     # parent stop_name (null passed through as-is)
        "parentLocationType": <int>,        # parent location_type (raw integer)
        "expectedLocationType": <int>,      # expected location_type for the parent
    },
)
```

| Field | Type | Source | Description |
|---|---|---|---|
| `csvRowNumber` | `int` | child row | Row number of the child record |
| `stopId` | `str` | child `stop_id` | ID of the child stop |
| `stopName` | `str \| None` | child `stop_name` | Name of the child stop; null passed through |
| `locationType` | `int` | child `location_type` | Actual location type of the child (raw integer) |
| `parentCsvRowNumber` | `int` | parent row | Row number of the parent record |
| `parentStation` | `str` | child `parent_station` | ID of the parent stop |
| `parentStopName` | `str \| None` | parent `stop_name` | Name of the parent stop; null passed through |
| `parentLocationType` | `int` | parent `location_type` | Actual location type of the parent (raw integer) |
| `expectedLocationType` | `int` | computed | Expected location type for the parent |

Severity: `Severity.ERROR`.

### `unused_station` — INFO

Emitted when a record has `location_type == 1` (STATION) but no stop with `location_type == 0` (STOP) references it via `parent_station`.

```python
Notice(
    code="unused_station",
    severity=Severity.INFO,
    fields={
        "csvRowNumber": <int>,      # csvRowNumber of the station row
        "stopId": <str>,            # station stop_id
        "stopName": <str | None>,   # station stop_name (null passed through as-is)
    },
)
```

| Field | Type | Source | Description |
|---|---|---|---|
| `csvRowNumber` | `int` | station row | Row number of the unused station |
| `stopId` | `str` | station `stop_id` | ID of the unused station |
| `stopName` | `str \| None` | station `stop_name` | Name of the unused station; null passed through |

Severity: `Severity.INFO`.

Note: `unused_parent_station` is a deprecated predecessor of `unused_station`, renamed in Java version 7.0.0. This implementation uses only `unused_station`.

## 4. Implementation approach

Pure Polars for both checks. The logic maps cleanly to self-joins and anti-joins and avoids Python row loops on large feeds.

### Module-level constants

```python
# Child location_type values that are checked for correct parent type
_CHECKED_CHILD_TYPES: frozenset[int] = frozenset({0, 2, 3, 4})

# Mapping from child location_type to required parent location_type
_EXPECTED_PARENT_TYPE: dict[int, int] = {
    0: 1,  # STOP requires STATION parent
    2: 1,  # ENTRANCE requires STATION parent
    3: 1,  # GENERIC_NODE requires STATION parent
    4: 0,  # BOARDING_AREA requires STOP parent
}
```

### Algorithm (pseudocode)

```
stops = feed.get("stops")
if stops is None or stops.is_empty():
    return []

# Ensure required columns are present
if "stop_id" not in stops.columns or "location_type" not in stops.columns:
    return []

notices = []

# --- Check A: wrong_parent_location_type ---
# Only proceed if parent_station column exists in the DataFrame
if "parent_station" in stops.columns:

    # Build parent lookup table (all stops, selecting identifying columns)
    # Rename columns to avoid collision after the self-join
    parent_lookup = stops.select(["stop_id", "stop_name", "location_type", "csvRowNumber"]).rename({
        "stop_id": "parent_station",
        "stop_name": "parentStopName",
        "location_type": "parentLocationType",
        "csvRowNumber": "parentCsvRowNumber",
    })

    # Filter child rows: recognized types that have a non-null, non-empty parent_station
    children = stops.filter(
        pl.col("location_type").is_in(list(_CHECKED_CHILD_TYPES))
        & pl.col("parent_station").is_not_null()
        & (pl.col("parent_station") != "")
    )

    if not children.is_empty():
        # Inner join drops unresolvable parent references (FK violations handled elsewhere)
        joined = children.join(parent_lookup, on="parent_station", how="inner")

        # Add expected parent location_type column via when/then chain
        expected_expr = (
            pl.when(pl.col("location_type").is_in([0, 2, 3]))
            .then(pl.lit(1))
            .when(pl.col("location_type") == 4)
            .then(pl.lit(0))
            .otherwise(pl.lit(-1))  # should not occur; child pre-filter ensures recognized types
        )
        joined = joined.with_columns(expected_expr.alias("expectedLocationType"))

        # Filter mismatches: actual parent type != expected parent type
        mismatches = joined.filter(
            pl.col("parentLocationType") != pl.col("expectedLocationType")
        ).sort("csvRowNumber")  # stable output order by child row number

        for row in mismatches.iter_rows(named=True):
            notices.append(Notice(
                code="wrong_parent_location_type",
                severity=Severity.ERROR,
                fields={
                    "csvRowNumber": row["csvRowNumber"],
                    "stopId": row["stop_id"],
                    "stopName": row.get("stop_name"),
                    "locationType": row["location_type"],
                    "parentCsvRowNumber": row["parentCsvRowNumber"],
                    "parentStation": row["parent_station"],
                    "parentStopName": row["parentStopName"],
                    "parentLocationType": row["parentLocationType"],
                    "expectedLocationType": row["expectedLocationType"],
                },
            ))

# --- Check B: unused_station ---
# Stations: rows where location_type == 1
stations = stops.filter(pl.col("location_type") == 1).select(
    ["stop_id", "stop_name", "csvRowNumber"]
)

if not stations.is_empty():
    # Stop parents: STOP children (location_type == 0) with a non-null, non-empty parent_station
    if "parent_station" in stops.columns:
        stop_parents = stops.filter(
            (pl.col("location_type") == 0)
            & pl.col("parent_station").is_not_null()
            & (pl.col("parent_station") != "")
        ).select(pl.col("parent_station").alias("stop_id"))
    else:
        stop_parents = pl.DataFrame({"stop_id": []}, schema={"stop_id": pl.Utf8})

    # Anti-join: stations with no matching STOP child
    unused = stations.join(stop_parents, on="stop_id", how="anti").sort("csvRowNumber")

    for row in unused.iter_rows(named=True):
        notices.append(Notice(
            code="unused_station",
            severity=Severity.INFO,
            fields={
                "csvRowNumber": row["csvRowNumber"],
                "stopId": row["stop_id"],
                "stopName": row.get("stop_name"),
            },
        ))

return notices
```

### Key implementation notes

- The `csvRowNumber` column is the camelCase row counter added by the loader (1-based integer). Access it as `row["csvRowNumber"]` in `iter_rows(named=True)` output.
- For Check A, `iter_rows` is used after the Polars mismatch filter; this is acceptable because the result set is expected to be small (validation errors in well-formed feeds are rare).
- For Check B, `iter_rows` is used after the anti-join; unused stations are also expected to be few in valid feeds.
- The `stop_name` field may be null; pass it through to the notice without defaulting to an empty string. Use `row.get("stop_name")` which returns `None` for null values.
- The `when/then` expected type expression covers only the four recognized child types (0, 2, 3, 4). The pre-filter on `_CHECKED_CHILD_TYPES` ensures no other types reach the expression, making the `.otherwise(pl.lit(-1))` branch unreachable in practice.
- Empty-string `parent_station` is treated as absent (same as null), consistent with other validators in this codebase.
- Notices are sorted by `csvRowNumber` before iteration to ensure deterministic output order regardless of Polars internal ordering. This is a stronger guarantee than the Java implementation (which iterates hash-set order).
- Stations that appear only in `parent_station` references but have no row in `stops.txt` are never added to the stations set and therefore cannot appear in `unused_station` output. This is correct per the spec.

## 5. Registry entry

Add the following import to `src/gtfs_validator/validators/__init__.py` (with the other `p*` imports):

```python
from gtfs_validator.validators.parent_station import validate_parent_station
```

Add the following entry to `VALIDATOR_REGISTRY` (alphabetically after `overlapping_pickup_drop_off_zone`, before `trip_service_id_foreign_key`):

```python
ValidatorEntry(
    name="parent_station",
    fn=validate_parent_station,
    requires=["stops"],
),
```

`requires=["stops"]` causes the runner's `should_skip` logic to bypass this validator automatically when `stops.txt` is absent from the feed.

### Fixtures and helpers

from datetime import date

import polars as pl
import pytest

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Severity

CTX = ValidationContext(country_code="US", date_for_validation=date(2026, 3, 8))


def make_stops(rows: list[dict]) -> pl.DataFrame:
    """Build a stops DataFrame from row dicts."""
    schema = {
        "csvRowNumber": pl.Int64,
        "stop_id": pl.Utf8,
        "stop_name": pl.Utf8,
        "location_type": pl.Int64,
        "parent_station": pl.Utf8,
    }
    data: dict[str, list] = {col: [] for col in schema}
    for r in rows:
        for col in schema:
            data[col].append(r.get(col))
    return pl.DataFrame(data, schema=schema)
