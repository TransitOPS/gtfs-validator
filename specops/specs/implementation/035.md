# Implementation: MissingTripEdgeValidator

## 1. Module location

`src/gtfs_validator/validators/missing_trip_edge.py`

## 2. Function signature

```python
def validate_missing_trip_edge(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`ctx` is accepted for signature consistency but is not used by this validator.

## 3. Notice definitions

### `missing_trip_edge` — ERROR

Emitted when the first or last stop time of a trip is missing `arrival_time` or `departure_time` and the row is not exempt due to a pickup/drop-off window.

```python
Notice(
    code="missing_trip_edge",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": <int>,       # 1-based row number from _row_number column
        "stop_sequence": <int>,        # stop_sequence value of the offending row
        "trip_id": <str>,              # trip_id of the offending row
        "specified_field": <str>,      # "arrival_time" or "departure_time"
    },
)
```

| Field | Type | Source |
|---|---|---|
| `csv_row_number` | `int` | `_row_number` column on the `stop_times` DataFrame (1-based, header = row 1, first data row = 2) |
| `stop_sequence` | `int` | `stop_sequence` value of the offending edge row |
| `trip_id` | `str` | `trip_id` of the offending edge row |
| `specified_field` | `str` | `"arrival_time"` or `"departure_time"` — whichever field is null |

Up to two notices are emitted per edge row (one per missing field). First and last edges are processed independently: a single-stop trip produces up to four notices (first-edge arrival, first-edge departure, last-edge arrival, last-edge departure), even though first and last refer to the same row.

## 4. Implementation approach

Use plain Python iteration over grouped Polars data. The validator must identify the minimum and maximum `stop_sequence` row per `trip_id`, then check each for null `arrival_time` / `departure_time` (subject to the window exemption). Plain Python loops over groups are acceptable here per AGENTS.md because the grouping logic involves selecting specific rows per group rather than a purely vectorized transformation.

**Columns selected from `stop_times`:**

```
trip_id, stop_sequence, arrival_time, departure_time,
start_pickup_drop_off_window, end_pickup_drop_off_window, _row_number
```

Only these columns need to be in scope. All other columns are ignored.

**Exemption rule:**

A row is exempt if `start_pickup_drop_off_window` is not null **or** `end_pickup_drop_off_window` is not null. The inverse of the Java condition `!hasStart && !hasEnd` — i.e., checks proceed only when both window fields are null.

**Algorithm (pseudocode):**

```
notices = []

stop_times = feed.get("stop_times")
if stop_times is None or stop_times is empty:
    return []

select relevant columns from stop_times

sort stop_times by stop_sequence ascending (guarantees min is first, max is last)

for each (trip_id,), group in stop_times.group_by("trip_id"):
    first_row = group.row(0, named=True)   # lowest stop_sequence (after sort)
    last_row  = group.row(-1, named=True)  # highest stop_sequence (after sort)

    # Process first and last independently; duplicated if single-stop trip
    for edge in [first_row, last_row]:
        # Exemption: skip if either window field is present
        if edge["start_pickup_drop_off_window"] is not None:
            continue
        if edge["end_pickup_drop_off_window"] is not None:
            continue

        # Check arrival_time
        if edge["arrival_time"] is None:
            notices.append(Notice(
                code="missing_trip_edge",
                severity=Severity.ERROR,
                fields={
                    "csv_row_number": edge["_row_number"],
                    "stop_sequence": edge["stop_sequence"],
                    "trip_id": edge["trip_id"],
                    "specified_field": "arrival_time",
                },
            ))

        # Check departure_time
        if edge["departure_time"] is None:
            notices.append(Notice(
                code="missing_trip_edge",
                severity=Severity.ERROR,
                fields={
                    "csv_row_number": edge["_row_number"],
                    "stop_sequence": edge["stop_sequence"],
                    "trip_id": edge["trip_id"],
                    "specified_field": "departure_time",
                },
            ))

return notices
```

**Key implementation notes:**

- Call `.sort("stop_sequence")` before `.group_by("trip_id")` so that `group.row(0)` is guaranteed to be the minimum `stop_sequence` row and `group.row(-1)` is the maximum. Do not assume input order.
- Do not de-duplicate first and last when they refer to the same row (single-stop trip). Process the list `[first_row, last_row]` unconditionally; if both are the same dict, both iterations fire.
- `group_by` in Polars does not guarantee stable iteration order across trips. The order of notices in the output may vary by trip, but within each trip the first-edge notices always precede last-edge notices.
- The `_row_number` column is injected by the orchestrator's loading layer. If it is absent for any reason, the validator should fail loudly (a `KeyError` is acceptable; do not silently substitute a default).
- The selected columns must be verified to exist before slicing. If any required column other than optional window columns is missing, return `[]` with a comment — but in practice the schema guarantees all six non-underscore columns are declared in `STOP_TIMES`.

**Full implementation:**

```python
"""Validator: MissingTripEdgeValidator.

Checks that the first and last stop time of every trip each define both
arrival_time and departure_time, unless the row uses a continuous
pickup/drop-off window (start_pickup_drop_off_window /
end_pickup_drop_off_window).
"""

from __future__ import annotations

from typing import TYPE_CHECKING

import polars as pl

from gtfs_validator.notices import Notice, Severity

if TYPE_CHECKING:
    from gtfs_validator.context import ValidationContext

_REQUIRED_COLS = {
    "trip_id",
    "stop_sequence",
    "arrival_time",
    "departure_time",
    "_row_number",
}
_WINDOW_COLS = {
    "start_pickup_drop_off_window",
    "end_pickup_drop_off_window",
}


def validate_missing_trip_edge(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
    """Emit an error for each trip edge missing arrival_time or departure_time."""
    stop_times = feed.get("stop_times")
    if stop_times is None or stop_times.is_empty():
        return []

    available = set(stop_times.columns)
    if not _REQUIRED_COLS.issubset(available):
        return []

    select_cols = list(_REQUIRED_COLS | (_WINDOW_COLS & available))
    df = stop_times.select(select_cols).sort("stop_sequence")

    # Ensure window columns exist (fill with null if absent from the file)
    for col in _WINDOW_COLS:
        if col not in df.columns:
            df = df.with_columns(pl.lit(None).cast(pl.Utf8).alias(col))

    notices: list[Notice] = []

    for (trip_id,), group in df.group_by(["trip_id"]):
        first_row = group.row(0, named=True)
        last_row = group.row(-1, named=True)

        for edge in [first_row, last_row]:
            # Exemption: either window field non-null means skip all time checks
            if (
                edge["start_pickup_drop_off_window"] is not None
                or edge["end_pickup_drop_off_window"] is not None
            ):
                continue

            if edge["arrival_time"] is None:
                notices.append(
                    Notice(
                        code="missing_trip_edge",
                        severity=Severity.ERROR,
                        fields={
                            "csv_row_number": edge["_row_number"],
                            "stop_sequence": edge["stop_sequence"],
                            "trip_id": edge["trip_id"],
                            "specified_field": "arrival_time",
                        },
                    )
                )

            if edge["departure_time"] is None:
                notices.append(
                    Notice(
                        code="missing_trip_edge",
                        severity=Severity.ERROR,
                        fields={
                            "csv_row_number": edge["_row_number"],
                            "stop_sequence": edge["stop_sequence"],
                            "trip_id": edge["trip_id"],
                            "specified_field": "departure_time",
                        },
                    )
                )

    return notices
```

Add an import and a `ValidatorEntry` to `src/gtfs_validator/validators/__init__.py`.

**Import** (group with other `missing_*` imports):

```python
from gtfs_validator.validators.missing_trip_edge import validate_missing_trip_edge
```

**Registry entry** (place alphabetically among `missing_*` entries, after `missing_level_id`):

```python
ValidatorEntry(
    name="missing_trip_edge",
    fn=validate_missing_trip_edge,
    requires=["stop_times"],
),
```

`requires=["stop_times"]` allows the runner's `should_skip` logic to bypass the validator automatically when `stop_times.txt` is absent from the feed (no file, no notices — consistent with the spec).

```python
            "arrival_time": pl.Utf8,
```

```python
    assert trip_c_notices[0].fields["specified_field"] == "departure_time"
```

#### `test_unsorted_input_still_finds_correct_edges`

Input rows are provided out of `stop_sequence` order to verify that the sort step is correctly applied before selecting first/last.

- Setup: One trip with sequences provided in order 3, 1, 2. Sequence 1 is missing `arrival_time`; sequences 2 and 3 are complete.
- Expected: Exactly one notice for sequence 1 (`arrival_time`), not for sequence 3 (the last row in input but not the last in sequence order).

```python
def test_unsorted_input_still_finds_correct_edges() -> None:
```
