## 1. Module location

`src/gtfs_validator/validators/pickup_drop_off_type.py`

## 2. Function signature

```python
def validate_pickup_drop_off_type(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
```

## 3. Notice definitions

### `forbidden_pickup_type`

- **Code**: `"forbidden_pickup_type"`
- **Severity**: `Severity.ERROR`
- **Fields dict structure**:

```python
{
    "csv_row_number": int,                    # stop_times.csv_row_number for the offending row
    "start_pickup_drop_off_window": int | None,  # seconds-since-midnight value, or None if absent/null
    "end_pickup_drop_off_window": int | None,    # seconds-since-midnight value, or None if absent/null
}
```

Emitted when at least one of `start_pickup_drop_off_window` or `end_pickup_drop_off_window` is non-null on a row where `pickup_type` is `0` (REGULAR) or `3` (ON_REQUEST_TO_DRIVER). The window fields carry the raw loaded values from the row, which may individually be null if only the other window column is set.

### `forbidden_drop_off_type`

- **Code**: `"forbidden_drop_off_type"`
- **Severity**: `Severity.ERROR`
- **Fields dict structure**:

```python
{
    "csv_row_number": int,                    # stop_times.csv_row_number for the offending row
    "start_pickup_drop_off_window": int | None,  # seconds-since-midnight value, or None if absent/null
    "end_pickup_drop_off_window": int | None,    # seconds-since-midnight value, or None if absent/null
}
```

Emitted when at least one of `start_pickup_drop_off_window` or `end_pickup_drop_off_window` is non-null on a row where `drop_off_type` is `0` (REGULAR). The window fields carry the raw loaded values, which may individually be null.

## 4. Implementation approach

**Approach**: Polars vectorized filter, then row iteration for notice construction.

Two independent Polars filter passes are made over `stop_times` — one for each sub-check. A shared `window_expr` encodes the "at least one window column is non-null" condition and is reused for both passes. Column presence is checked before each filter to handle optional columns gracefully.

**Pseudocode**:

```
function validate_pickup_drop_off_type(feed, ctx):

    # Guard: stop_times must be present
    if "stop_times" not in feed:
        return []

    df = feed["stop_times"]
    cols = set(df.columns)

    has_start = "start_pickup_drop_off_window" in cols
    has_end   = "end_pickup_drop_off_window" in cols

    # Guard: at least one window column must be present in the header
    if not has_start and not has_end:
        return []

    # Build shared window-present expression (OR of non-null checks for each present column)
    window_expr = pl.lit(False)
    if has_start:
        window_expr = window_expr | pl.col("start_pickup_drop_off_window").is_not_null()
    if has_end:
        window_expr = window_expr | pl.col("end_pickup_drop_off_window").is_not_null()

    notices = []

    # Sub-check A: forbidden pickup type (REGULAR=0 or ON_REQUEST_TO_DRIVER=3) with window set
    if "pickup_type" in cols:
        pickup_violations = df.filter(
            window_expr & pl.col("pickup_type").is_in([0, 3])
        )
        for row in pickup_violations.iter_rows(named=True):
            notices.append(Notice(
                code="forbidden_pickup_type",
                severity=Severity.ERROR,
                fields={
                    "csv_row_number": row["csv_row_number"],
                    "start_pickup_drop_off_window": row.get("start_pickup_drop_off_window"),
                    "end_pickup_drop_off_window": row.get("end_pickup_drop_off_window"),
                },
            ))

    # Sub-check B: forbidden drop-off type (REGULAR=0) with window set
    if "drop_off_type" in cols:
        dropoff_violations = df.filter(
            window_expr & pl.col("drop_off_type").eq(0)
        )
        for row in dropoff_violations.iter_rows(named=True):
            notices.append(Notice(
                code="forbidden_drop_off_type",
                severity=Severity.ERROR,
                fields={
                    "csv_row_number": row["csv_row_number"],
                    "start_pickup_drop_off_window": row.get("start_pickup_drop_off_window"),
                    "end_pickup_drop_off_window": row.get("end_pickup_drop_off_window"),
                },
            ))

    return notices
```

**Column presence handling details**:

- The whole validator is skipped if neither `start_pickup_drop_off_window` nor `end_pickup_drop_off_window` is in `df.columns`. This mirrors the Java `shouldCallValidate()` guard.
- If only `start_pickup_drop_off_window` is present, `window_expr` checks only that column; `end_pickup_drop_off_window` is absent so notice fields for it will be `None` (via `row.get()`).
- If only `end_pickup_drop_off_window` is present, symmetric behavior applies.
- Sub-check A is skipped entirely when `pickup_type` is absent from `df.columns`.
- Sub-check B is skipped entirely when `drop_off_type` is absent from `df.columns`.
- Use `row.get("start_pickup_drop_off_window")` and `row.get("end_pickup_drop_off_window")` (not `row["..."]`) when building notice fields, so absent columns yield `None` naturally rather than raising `KeyError`.

**Null semantics enforced by Polars**:

- `pl.col("pickup_type").is_in([0, 3])` returns `False` for null `pickup_type`, so null pickup rows do not trigger sub-check A.
- `pl.col("drop_off_type").eq(0)` returns `False` for null `drop_off_type`, so null drop-off rows do not trigger sub-check B.
- `pl.col("start_pickup_drop_off_window").is_not_null()` requires a non-null value; a null window column does not satisfy the window condition.
- A row where both window columns are null produces `window_expr = False`; neither sub-check fires for that row regardless of type values.

**Time field representation**:

After loading, `start_pickup_drop_off_window` and `end_pickup_drop_off_window` are stored as integers (seconds since midnight) per the `_TIME` field type in the schema. The validator carries these raw integer values into notice fields unchanged; no arithmetic on time values is performed.

**Pickup/drop-off type enum reference**:

| Name | Integer |
|---|---|
| REGULAR | 0 |
| NOT_AVAILABLE | 1 |
| MUST_PHONE | 2 |
| ON_REQUEST_TO_DRIVER | 3 |

Forbidden pickup types: `{0, 3}`. Forbidden drop-off type: `{0}`.
