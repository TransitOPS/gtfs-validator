## 3. Notice definitions

### `overlapping_zone_and_pickup_drop_off_window` — ERROR

Emitted when two `stop_times.txt` entries within the same trip have overlapping pickup/drop-off time windows and overlapping geographic zones (as determined by the Shapely `.overlaps()` predicate on their corresponding GeoJSON polygon geometries).

```python
Notice(
    code="overlapping_zone_and_pickup_drop_off_window",
    severity=Severity.ERROR,
    fields={
        "trip_id": <str>,                         # shared trip identifier
        "stop_sequence1": <int>,                  # stop_sequence of the first entry
        "location_id1": <str>,                    # location_id of the first entry
        "start_pickup_drop_off_window1": <str>,   # HH:MM:SS start of first entry's window
        "end_pickup_drop_off_window1": <str>,     # HH:MM:SS end of first entry's window
        "stop_sequence2": <int>,                  # stop_sequence of the second entry
        "location_id2": <str>,                    # location_id of the second entry
        "start_pickup_drop_off_window2": <str>,   # HH:MM:SS start of second entry's window
        "end_pickup_drop_off_window2": <str>,     # HH:MM:SS end of second entry's window
    },
)
```

| Field | Type | Source | Description |
|---|---|---|---|
| `trip_id` | `str` | `stopTime1.trip_id` (same as `stopTime2.trip_id`) | Shared trip identifier |
| `stop_sequence1` | `int` | `stopTime1.stop_sequence` | Stop sequence of the first entry |
| `location_id1` | `str` | `stopTime1.location_id` | Location ID of the first entry |
| `start_pickup_drop_off_window1` | `str` | `stopTime1.start_pickup_drop_off_window` | Start of first entry's pickup/drop-off window (HH:MM:SS) |
| `end_pickup_drop_off_window1` | `str` | `stopTime1.end_pickup_drop_off_window` | End of first entry's pickup/drop-off window (HH:MM:SS) |
| `stop_sequence2` | `int` | `stopTime2.stop_sequence` | Stop sequence of the second entry |
| `location_id2` | `str` | `stopTime2.location_id` | Location ID of the second entry |
| `start_pickup_drop_off_window2` | `str` | `stopTime2.start_pickup_drop_off_window` | Start of second entry's pickup/drop-off window (HH:MM:SS) |
| `end_pickup_drop_off_window2` | `str` | `stopTime2.end_pickup_drop_off_window` | End of second entry's pickup/drop-off window (HH:MM:SS) |

Severity: `Severity.ERROR`.

Multiple notices may be emitted per trip when more than two entries form qualifying overlapping pairs. Each qualifying pair produces exactly one notice.

## 4. Implementation approach

Mixed Polars + plain Python. Polars is used for table access, required-column pre-filtering, and per-trip grouping. Plain Python is used for the all-pairs comparison loop, time-interval checking, and geometry overlap testing (via Shapely). This approach is correct for O(n²) per-trip pair logic combined with geometry operations, which Polars is not designed for.

### Helper functions

All helpers are module-level pure functions.

#### `_build_geometry_index`

```python
from shapely.geometry import shape

def _build_geometry_index(geojson_features: list[dict]) -> dict[str, object]:
    """Build a mapping of feature ID to Shapely geometry from the locations_geojson list."""
    index: dict[str, object] = {}
    for f in geojson_features:
        fid = f.get("id")
        geom_type = f.get("geometry_type")
        coords = f.get("coordinates")
        if not fid or not geom_type or coords is None:
            continue
        try:
            geom = shape({"type": geom_type, "coordinates": coords})
        except Exception:
            continue  # invalid geometries are reported by geojson_geometry validator
        index[fid] = geom
    return index
```

Built once before the trip iteration loop. Invalid or unrecognised geometries are silently skipped here; they are reported separately by `validate_geojson_geometry`.

### Algorithm (pseudocode)

```
stop_times = feed.get("stop_times")
geojson_features = feed.get("locations_geojson")

# Step 1: Guard — missing tables
if stop_times is None or stop_times.is_empty():
    return []
if not geojson_features:
    return []

# Step 1a: Guard — required columns must exist in the DataFrame
required_cols = {"trip_id", "stop_sequence", "location_id",
                 "pickup_type", "drop_off_type",
                 "start_pickup_drop_off_window", "end_pickup_drop_off_window"}
if not required_cols.issubset(set(stop_times.columns)):
    return []

# Pre-filter to rows that have non-null location_id and non-null window fields.
# This reduces pair candidates before the all-pairs loop.
candidates = stop_times.filter(
    pl.col("location_id").is_not_null()
    & pl.col("start_pickup_drop_off_window").is_not_null()
    & pl.col("end_pickup_drop_off_window").is_not_null()
)
if candidates.is_empty():
    return []

# Select only the columns needed to minimise memory per group
candidates = candidates.select([
    "trip_id", "stop_sequence", "location_id",
    "pickup_type", "drop_off_type",
    "start_pickup_drop_off_window", "end_pickup_drop_off_window",
])

# Build geometry lookup once
geom_index = _build_geometry_index(geojson_features)

notices = []

# Step 2: Group by trip_id; process each trip independently
for (trip_id,), group in candidates.group_by("trip_id"):
    rows = group.to_dicts()

    if len(rows) < 2:
        continue

    # Step 3: All-pairs comparison (i < j, unordered pairs, file order)
    for i in range(len(rows)):
        st1 = rows[i]
        for j in range(i + 1, len(rows)):
            st2 = rows[j]

            # Step 4: Skip if pickup/drop-off types are incompatible or unrecognized
            pt1 = st1["pickup_type"]
            dt1 = st1["drop_off_type"]
            pt2 = st2["pickup_type"]
            dt2 = st2["drop_off_type"]

            # Treat null pickup/drop-off types as unrecognized
            if pt1 is None: pt1 = -1
            if dt1 is None: dt1 = -1
            if pt2 is None: pt2 = -1
            if dt2 is None: dt2 = -1

            if (pt1 not in _RECOGNIZED_TYPES or dt1 not in _RECOGNIZED_TYPES or
                    pt2 not in _RECOGNIZED_TYPES or dt2 not in _RECOGNIZED_TYPES):
                continue  # any unrecognized type → skip
            if pt1 != pt2 and dt1 != dt2:
                continue  # both differ → skip

            # Step 5: Skip if required fields are missing (already filtered above,
            # but guard against nulls surviving in pickup_type-adjacent fields)
            # (location_id and window fields are guaranteed non-null by the pre-filter)

            # Step 6: Skip if same location
            loc1 = st1["location_id"]
            loc2 = st2["location_id"]
            if loc1 == loc2:
                continue

            # Step 7: Skip if time windows do not strictly overlap
            # [s1, e1) and [s2, e2) strictly overlap iff s1 < e2 AND s2 < e1
            s1 = _time_to_secs(st1["start_pickup_drop_off_window"])
            e1 = _time_to_secs(st1["end_pickup_drop_off_window"])
            s2 = _time_to_secs(st2["start_pickup_drop_off_window"])
            e2 = _time_to_secs(st2["end_pickup_drop_off_window"])
            if not (s1 < e2 and s2 < e1):
                continue

            # Step 8: Look up GeoJSON geometries
            geom1 = geom_index.get(loc1)
            geom2 = geom_index.get(loc2)
            if geom1 is None or geom2 is None:
                continue

            # Step 9: Check geometric overlap using Shapely DE-9IM predicate
            if not geom1.overlaps(geom2):
                continue

            # Step 10: Emit notice
            notices.append(Notice(
                code="overlapping_zone_and_pickup_drop_off_window",
                severity=Severity.ERROR,
                fields={
                    "trip_id": trip_id,
                    "stop_sequence1": st1["stop_sequence"],
                    "location_id1": loc1,
                    "start_pickup_drop_off_window1": st1["start_pickup_drop_off_window"],
                    "end_pickup_drop_off_window1": st1["end_pickup_drop_off_window"],
                    "stop_sequence2": st2["stop_sequence"],
                    "location_id2": loc2,
                    "start_pickup_drop_off_window2": st2["start_pickup_drop_off_window"],
                    "end_pickup_drop_off_window2": st2["end_pickup_drop_off_window"],
                },
            ))

return notices
```

### Key implementation notes

- `pickup_type` defaults to `0` (REGULAR) and `drop_off_type` defaults to `0` (REGULAR) in `stop_times.txt`. If the loader has applied defaults, null values will not appear for these columns in practice. If nulls are possible (feed loaded without defaults applied), treat null as `-1` (unrecognized) so the pair is skipped — this is conservative and correct.
- The pre-filter on `location_id`, `start_pickup_drop_off_window`, and `end_pickup_drop_off_window` being non-null reduces the candidate set before the expensive pair loop.
- The required-column existence check guards against feeds where the flex-service columns (`location_id`, window fields) were never loaded because the feed does not use them.
- `group_by` returns tuple keys; unpack as `(trip_id,)`.
- `to_dicts()` is appropriate: per-trip groups in flex-service feeds are expected to be small (typically 2–10 rows referencing `location_id`).
- `geom1.overlaps(geom2)` uses Shapely's DE-9IM predicate, which is the exact equivalent of JTS `Geometry.overlaps()`. Two polygons touching at a single point or sharing only a boundary edge return `False`. Two identical polygons return `False` (one contains the other entirely). Only partial interior overlap returns `True`.
- The geometry index is built once per validator invocation, not once per trip or pair.
- Shapely is already a project dependency (used by `geojson_geometry.py`).

### Full implementation

```python
"""Validator: OverlappingPickupDropOffZoneValidator.

Detects pairs of stop_times.txt entries within the same trip that have
overlapping pickup/drop-off time windows AND overlapping geographic zones
(as defined by their locations.geojson polygons), which would create an
ambiguous service area during that time period.
"""

from __future__ import annotations

from typing import TYPE_CHECKING, Any

import polars as pl
from shapely.geometry import shape

from gtfs_validator.notices import Notice, Severity

if TYPE_CHECKING:
    from gtfs_validator.context import ValidationContext

_RECOGNIZED_TYPES: frozenset[int] = frozenset({0, 1, 2, 3})


def _time_to_secs(t: str) -> int:
    """Convert a GTFS HH:MM:SS time string to total seconds since midnight."""
    h, m, s = t.split(":")
    return int(h) * 3600 + int(m) * 60 + int(s)


def _build_geometry_index(geojson_features: list[dict[str, Any]]) -> dict[str, Any]:
    """Build a mapping of feature ID to Shapely geometry."""
    index: dict[str, Any] = {}
    for f in geojson_features:
        fid = f.get("id")
        geom_type = f.get("geometry_type")
        coords = f.get("coordinates")
        if not fid or not geom_type or coords is None:
            continue
        try:
            geom = shape({"type": geom_type, "coordinates": coords})
        except Exception:
            continue
        index[fid] = geom
    return index


def validate_overlapping_pickup_drop_off_zone(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
    """Emit overlapping_zone_and_pickup_drop_off_window (ERROR) for qualifying stop-time pairs."""
    stop_times = feed.get("stop_times")
    geojson_features = feed.get("locations_geojson")

    if stop_times is None or stop_times.is_empty():
        return []
    if not geojson_features:
        return []

    required_cols = {
        "trip_id", "stop_sequence", "location_id",
        "pickup_type", "drop_off_type",
        "start_pickup_drop_off_window", "end_pickup_drop_off_window",
    }
    if not required_cols.issubset(set(stop_times.columns)):
        return []

    candidates = stop_times.filter(
        pl.col("location_id").is_not_null()
        & pl.col("start_pickup_drop_off_window").is_not_null()
        & pl.col("end_pickup_drop_off_window").is_not_null()
    ).select(list(required_cols))

    if candidates.is_empty():
        return []

    geom_index = _build_geometry_index(geojson_features)

    notices: list[Notice] = []

    for (trip_id,), group in candidates.group_by("trip_id"):
        rows = group.to_dicts()
        if len(rows) < 2:
            continue

        for i in range(len(rows)):
            st1 = rows[i]
            for j in range(i + 1, len(rows)):
                st2 = rows[j]

                pt1 = st1["pickup_type"] if st1["pickup_type"] is not None else -1
                dt1 = st1["drop_off_type"] if st1["drop_off_type"] is not None else -1
                pt2 = st2["pickup_type"] if st2["pickup_type"] is not None else -1
                dt2 = st2["drop_off_type"] if st2["drop_off_type"] is not None else -1

                if (pt1 not in _RECOGNIZED_TYPES or dt1 not in _RECOGNIZED_TYPES or
                        pt2 not in _RECOGNIZED_TYPES or dt2 not in _RECOGNIZED_TYPES):
                    continue
                if pt1 != pt2 and dt1 != dt2:
                    continue

                loc1: str = st1["location_id"]
                loc2: str = st2["location_id"]
                if loc1 == loc2:
                    continue

                s1 = _time_to_secs(st1["start_pickup_drop_off_window"])
                e1 = _time_to_secs(st1["end_pickup_drop_off_window"])
                s2 = _time_to_secs(st2["start_pickup_drop_off_window"])
                e2 = _time_to_secs(st2["end_pickup_drop_off_window"])
                if not (s1 < e2 and s2 < e1):
                    continue

                geom1 = geom_index.get(loc1)
                geom2 = geom_index.get(loc2)
                if geom1 is None or geom2 is None:
                    continue

                if not geom1.overlaps(geom2):
                    continue

                notices.append(
                    Notice(
                        code="overlapping_zone_and_pickup_drop_off_window",
                        severity=Severity.ERROR,
                        fields={
                            "trip_id": trip_id,
                            "stop_sequence1": st1["stop_sequence"],
                            "location_id1": loc1,
                            "start_pickup_drop_off_window1": st1["start_pickup_drop_off_window"],
                            "end_pickup_drop_off_window1": st1["end_pickup_drop_off_window"],
                            "stop_sequence2": st2["stop_sequence"],
                            "location_id2": loc2,
                            "start_pickup_drop_off_window2": st2["start_pickup_drop_off_window"],
                            "end_pickup_drop_off_window2": st2["end_pickup_drop_off_window"],
                        },
                    )
                )

    return notices
```

#### `test_multiple_qualifying_pairs_emit_multiple_notices`

- Input: trip `"t0"` with three stop times where all three pairwise combinations have overlapping windows and overlapping geometries (using the same pair of overlapping features for all three stop times with distinct location IDs requires at least three overlapping features; alternatively use two features with three stop times where two reference the same feature — but same location is skipped. Use three GeoJSON features where each pair overlaps).
- Simplest approach: two features `"1"` and `"2"` that overlap with each other, and a third feature `"3"` that overlaps with both `"1"` and `"2"`. All three windows overlap.
- Expected: 3 notices (pairs: (1,2), (1,3), (2,3)).

```python
def test_multiple_qualifying_pairs_emit_multiple_notices() -> None:
    # Three mutually overlapping squares arranged in a triangle overlap pattern
    geojson = [
        {"id": "1", "geometry_type": "Polygon",
         "coordinates": [[[0, 0], [4, 0], [4, 4], [0, 4], [0, 0]]]},
        {"id": "2", "geometry_type": "Polygon",
         "coordinates": [[[2, 0], [6, 0], [6, 4], [2, 4], [2, 0]]]},
        {"id": "3", "geometry_type": "Polygon",
         "coordinates": [[[1, 0], [5, 0], [5, 4], [1, 4], [1, 0]]]},
    ]
    feed = {
        "stop_times": make_stop_times([
            {"trip_id": "t0", "stop_sequence": 1, "location_id": "1",
             "pickup_type": 0, "drop_off_type": 0,
             "start_pickup_drop_off_window": "05:00:00",
             "end_pickup_drop_off_window": "08:00:00"},
            {"trip_id": "t0", "stop_sequence": 2, "location_id": "2",
             "pickup_type": 0, "drop_off_type": 0,
             "start_pickup_drop_off_window": "06:00:00",
             "end_pickup_drop_off_window": "09:00:00"},
            {"trip_id": "t0", "stop_sequence": 3, "location_id": "3",
             "pickup_type": 0, "drop_off_type": 0,
             "start_pickup_drop_off_window": "07:00:00",
             "end_pickup_drop_off_window": "10:00:00"},
        ]),
        "locations_geojson": geojson,
    }
    notices = validate_overlapping_pickup_drop_off_zone(feed, CTX)
    assert len(notices) == 3
    for n in notices:
        assert n.code == "overlapping_zone_and_pickup_drop_off_window"
        assert n.severity == Severity.ERROR
```
