# Implementation: PathwayEndpointTypeValidator

## 1. Module location

`src/gtfs_validator/validators/pathway_endpoint_type.py`

## 2. Function signature

```python
def validate_pathway_endpoint_type(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice definitions

### `pathway_to_wrong_location_type`

- **Code:** `"pathway_to_wrong_location_type"`
- **Severity:** `Severity.ERROR`
- **Fields dict:**

```python
{
    "csvRowNumber": int,   # csv_row_number from pathways.txt
    "pathwayId":   str,   # pathway_id from pathways.txt
    "fieldName":   str,   # literal "from_stop_id" or "to_stop_id"
    "stopId":      str,   # the stop_id value that resolved to a STATION
}
```

### `pathway_to_platform_with_boarding_areas`

- **Code:** `"pathway_to_platform_with_boarding_areas"`
- **Severity:** `Severity.ERROR`
- **Fields dict:**

```python
{
    "csvRowNumber": int,   # csv_row_number from pathways.txt
    "pathwayId":   str,   # pathway_id from pathways.txt
    "fieldName":   str,   # literal "from_stop_id" or "to_stop_id"
    "stopId":      str,   # the stop_id value that resolved to a STOP with children
}
```

## 4. Implementation approach

Use plain Python iteration over `pathways` rows (AGENTS.md permits this when per-row logic involves independent conditions with early exits and the cross-table lookup is done via precomputed dicts/sets rather than repeated DataFrame scans).

### Preprocessing (eager, once before the row loop)

1. **Guard clauses** — return `[]` early if `pathways` is absent or empty. Also return `[]` if `stops` is absent or empty (all endpoint lookups would be silent skips, so no notices can fire).

2. **`stop_type` dict** — build `dict[str, int | None]` mapping `stop_id` → `location_type` from `stops`. Use `stops.select(["stop_id", "location_type"])` and `iter_rows(named=True)`. A null `location_type` maps to `None`.

3. **`parents_with_children` set** — build `set[str]` of every non-null `parent_station` value in `stops`. Use `stops.filter(pl.col("parent_station").is_not_null())["parent_station"].to_list()`. Any stop that appears as `parent_station` — regardless of child `location_type` — causes its parent STOP endpoint to be flagged (mirrors Java's `byParentStation` non-empty check).

### Row loop pseudocode

```
STATION = 1
STOP    = 0

for each row in pathways.select(["csv_row_number", "pathway_id", "from_stop_id", "to_stop_id"]).iter_rows(named=True):
    for (field_name, stop_id) in [("from_stop_id", row["from_stop_id"]),
                                   ("to_stop_id",   row["to_stop_id"])]:
        loc_type = stop_type.get(stop_id)          # None if stop_id not found
        if loc_type is None:
            continue                                # broken FK — skip silently
        if loc_type == STATION:
            emit pathway_to_wrong_location_type(
                csvRowNumber = row["csv_row_number"],
                pathwayId    = row["pathway_id"],
                fieldName    = field_name,
                stopId       = stop_id,
            )
        elif loc_type == STOP and stop_id in parents_with_children:
            emit pathway_to_platform_with_boarding_areas(
                csvRowNumber = row["csv_row_number"],
                pathwayId    = row["pathway_id"],
                fieldName    = field_name,
                stopId       = stop_id,
            )
        # ENTRANCE (2), GENERIC_NODE (3), BOARDING_AREA (4): no notice
```

### Ordering guarantee

Notices are emitted in pathway row order, with `from_stop_id` checked before `to_stop_id` for each row. This matches Java's `checkEndpoint` call order.

### Column requirements

From `pathways`: `csv_row_number`, `pathway_id`, `from_stop_id`, `to_stop_id`.
From `stops`: `stop_id`, `location_type`, `parent_station`.
