## 3. Notice definition

### `unused_trip` — WARNING

Emitted for each unique `trip_id` in `trips.txt` that has no corresponding row
in `stop_times.txt`.

| Field | Python type | Source | Description |
|---|---|---|---|
| `trip_id` | `str` | `trips["trip_id"]` | ID of the trip with no stop times |
| `csv_row_number` | `int` | `trips["csv_row_number"]` | 1-based physical row number of the first occurrence of the trip in `trips.txt` |

Constructed as:

```python
Notice(
    code="unused_trip",
    severity=Severity.WARNING,
    fields={
        "trip_id": <str>,
        "csv_row_number": <int>,
    },
)
```

Notice fields must contain **exactly** `trip_id` and `csv_row_number` — no
additional keys.

**Notice code derivation:**
- Java class: `UnusedTripNotice`
- Python notice code: `unused_trip`

## 4. Implementation approach

### 4.1 Guard clauses

```python
if "trips" not in feed or feed["trips"].is_empty():
    return []
if "stop_times" not in feed:
    return []
```

When `trips` is absent or empty, no trips can be checked; return immediately.

When `stop_times` is absent, return `[]` immediately — the runner dependency
guard already enforces both tables are present, but the function must be
defensive on its own.

When `stop_times` is present but empty, do **not** short-circuit — the filter
will correctly flag every trip as unused.

### 4.2 Vectorised core (is_in approach)

```python
trips_df = feed["trips"]

# Build set of trip_ids that appear in stop_times
if not feed["stop_times"].is_empty():
    used_trip_ids = feed["stop_times"]["trip_id"].unique()
else:
    used_trip_ids = pl.Series("trip_id", [], dtype=pl.String)

# Filter to trips whose trip_id is not in that set,
# then deduplicate by trip_id keeping first occurrence
unused_trips = trips_df.filter(
    ~pl.col("trip_id").is_in(used_trip_ids)
).unique(subset=["trip_id"], maintain_order=True)
```

**Alternative: anti-join (preferred for very large feeds)**

```python
used_df = feed["stop_times"].select("trip_id").unique()
unused_trips = (
    feed["trips"]
    .join(used_df, on="trip_id", how="anti")
    .unique(subset=["trip_id"], maintain_order=True)
)
```

The `is_in` approach is idiomatic for this single-column membership check and
is equivalent in correctness. Either approach is acceptable; the `is_in`
pattern matches the pattern used in the reference implementation.

### 4.3 Deduplication

`unique(subset=["trip_id"], maintain_order=True)` ensures at most one notice
per unique `trip_id`. When `trips.txt` contains duplicate `trip_id` rows,
`csv_row_number` will be taken from the **first** occurrence encountered during
DataFrame iteration (load order).

### 4.4 Notice emission

Iterate the (typically small) filtered result in plain Python:

```python
notices: list[Notice] = []
for row in unused_trips.iter_rows(named=True):
    notices.append(
        Notice(
            code="unused_trip",
            severity=Severity.WARNING,
            fields={
                "trip_id": row["trip_id"],
                "csv_row_number": row["csv_row_number"],
            },
        )
    )
return notices
```

### 4.5 Columns accessed

| DataFrame | Columns read |
|---|---|
| `trips` | `trip_id`, `csv_row_number` |
| `stop_times` | `trip_id` only |

No other columns are read. The validator must not fail if extra columns are
present.

### 4.6 Behavioural notes

- The check is a pure existence check: does any row in `stop_times` reference
  this `trip_id`? The count of stop time rows is irrelevant (that is the
  concern of `TripUsabilityValidator`).
- Duplicate `trip_id` values in `trips.txt` generate exactly one notice per
  unique trip ID, using the first row's `csv_row_number`.
- `trip_id` values appearing in `stop_times` but not in `trips` are silently
  ignored (the validator iterates trips, not stop times).
- This validator checks the "orphan trip" condition and emits a WARNING, not an
  ERROR. It is a best-practices check, not a spec violation.
- Load-time PK/FK checks handle type validation and the reverse FK direction
  (`stop_times.trip_id → trips.trip_id`); this validator must not duplicate
  those checks.

## 7. Complete module skeleton

```python
"""Validator: warn when trips.txt contains trips not referenced in stop_times.txt."""

from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_trip_usage(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
    """Emit unused_trip WARNING for every trip with no stop times."""
    if "trips" not in feed or feed["trips"].is_empty():
        return []
    if "stop_times" not in feed:
        return []

    trips_df = feed["trips"]

    # Build set of trip_ids that appear in stop_times
    if not feed["stop_times"].is_empty():
        used_trip_ids = feed["stop_times"]["trip_id"].unique()
    else:
        used_trip_ids = pl.Series("trip_id", [], dtype=pl.String)

    # Filter to unused trips, deduplicate by trip_id keeping first occurrence
    unused_trips = trips_df.filter(
        ~pl.col("trip_id").is_in(used_trip_ids)
    ).unique(subset=["trip_id"], maintain_order=True)

    notices: list[Notice] = []
    for row in unused_trips.iter_rows(named=True):
        notices.append(
            Notice(
                code="unused_trip",
                severity=Severity.WARNING,
                fields={
                    "trip_id": row["trip_id"],
                    "csv_row_number": row["csv_row_number"],
                },
            )
        )

    return notices
```
