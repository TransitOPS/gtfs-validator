## 3. Notice definitions

### `same_route_and_agency_url`

- **Severity**: `Severity.WARNING`
- **Code**: `"same_route_and_agency_url"`
- **When emitted**: A `routes.route_url` matches an `agency.agency_url` case-insensitively. One notice per (route, agency) pair.

| Field | Type | Description |
|---|---|---|
| `route_csv_row_number` | `int` | `csv_row_number` of the offending route in `routes.txt` |
| `route_id` | `str` | `route_id` of the offending route |
| `agency_name` | `str` | `agency_name` of the matching agency |
| `route_url` | `str` | The duplicate URL as stored in `routes.txt` (not lowercased) |
| `agency_csv_row_number` | `int` | `csv_row_number` of the matching agency in `agency.txt` |

Construction:
```python
Notice(
    code="same_route_and_agency_url",
    severity=Severity.WARNING,
    fields={
        "route_csv_row_number": row["csv_row_number"],
        "route_id": row["route_id"],
        "agency_name": row["agency_name_right"],
        "route_url": row["route_url"],
        "agency_csv_row_number": row["csv_row_number_right"],
    },
)
```

## 4. Implementation approach

### 4.1 Overview

Three independent Polars inner-join checks are performed. Each check:
1. Filters the relevant tables to rows where the URL column is non-null.
2. Adds a lowercase key column (`_url_key`) to both sides.
3. Joins on `_url_key`.
4. Iterates the matched rows to emit one notice per row.

The join approach avoids Python-level loops over potentially large tables. The original (non-lowercased) URL value from the left-side table (route or stop) is stored in the notice.

### 4.2 Check 1 — route_url vs agency_url

```python
agency = feed.get("agency")
routes = feed.get("routes")

if (
    agency is not None and not agency.is_empty()
    and routes is not None and not routes.is_empty()
    and "agency_url" in agency.columns
    and "route_url" in routes.columns
):
    agency_keyed = (
        agency
        .filter(pl.col("agency_url").is_not_null())
        .with_columns(pl.col("agency_url").str.to_lowercase().alias("_url_key"))
        .select("_url_key", "agency_name", "csv_row_number")
    )
    routes_keyed = (
        routes
        .filter(pl.col("route_url").is_not_null())
        .with_columns(pl.col("route_url").str.to_lowercase().alias("_url_key"))
        .select("_url_key", "route_id", "route_url", "csv_row_number")
    )
    matches = routes_keyed.join(agency_keyed, on="_url_key", how="inner")
    for row in matches.iter_rows(named=True):
        notices.append(Notice(
            code="same_route_and_agency_url",
            severity=Severity.WARNING,
            fields={
                "route_csv_row_number": row["csv_row_number"],
                "route_id": row["route_id"],
                "agency_name": row["agency_name_right"],
                "route_url": row["route_url"],
                "agency_csv_row_number": row["csv_row_number_right"],
            },
        ))
```

### 4.3 Check 2 — stop_url vs agency_url

### 4.5 Key implementation rules

- **Column name collisions after join**: Polars suffixes right-side duplicate column names with `_right`. Columns shared between left and right (e.g. `csv_row_number`) become `csv_row_number` (left) and `csv_row_number_right` (right). Use these suffixed names when constructing notices.
- **`_url_key` column**: Computed with `pl.col("...").str.to_lowercase()`. Drop it via `select(...)` before the join or after — either approach is fine. Using `.select(...)` before the join keeps the frame narrow and avoids carrying the key column into the notice row dict.
- **Null filtering before join**: Filter out null URL rows before computing `_url_key` to avoid null keys being joined incorrectly. Use `.filter(pl.col("...").is_not_null())`.
- **Original URL preserved**: The notice stores the original value from the left-side table's URL column (`route_url` or `stop_url`), not the lowercased key. This matches Java behavior.
- **No deduplication**: The join naturally produces one result row per (left row, right row) pair. No deduplication step is needed or wanted.
- **Column presence guard**: Check `"agency_url" in agency.columns`, etc. before building the keyed frames. If a URL column is absent (e.g. feed was loaded without it), skip the relevant checks gracefully rather than crashing.
- **Reuse of keyed frames**: `agency_keyed`, `routes_keyed`, and `stops_keyed` may each be needed in two checks. Compute each once at most. Structure the function so the guard conditions for checks 1, 2, and 3 share these computations where possible. A clean pattern is to compute each keyed frame at the top of the function under its own guard, then reference it in each applicable check.

### 4.6 Suggested function structure

```
validate_url_consistency(feed, ctx):
    notices = []

    agency = feed.get("agency")
    routes = feed.get("routes")
    stops = feed.get("stops")

    # Build keyed frames (only when the table and URL column are present and non-empty)
    agency_keyed = _keyed(agency, "agency_url", ["agency_name", "csv_row_number"])
    routes_keyed = _keyed(routes, "route_url", ["route_id", "route_url", "csv_row_number"])
    stops_keyed  = _keyed(stops,  "stop_url",  ["stop_id",  "stop_url",  "csv_row_number"])

    # Check 1
    if agency_keyed is not None and routes_keyed is not None:
        ...

    # Check 2
    if agency_keyed is not None and stops_keyed is not None:
        ...

    # Check 3
    if routes_keyed is not None and stops_keyed is not None:
        ...

    return notices
```

Where `_keyed` is a module-level helper:

```python
def _keyed(
    df: pl.DataFrame | None,
    url_col: str,
    keep_cols: list[str],
) -> pl.DataFrame | None:
    if df is None or df.is_empty() or url_col not in df.columns:
        return None
    return (
        df
        .filter(pl.col(url_col).is_not_null())
        .with_columns(pl.col(url_col).str.to_lowercase().alias("_url_key"))
        .select(["_url_key"] + keep_cols)
    )
```

If `_keyed` returns a non-None result but is empty (all URL values were null), `join(..., how="inner")` will produce zero rows — no extra empty-frame guard is needed.
