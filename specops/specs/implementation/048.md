# Implementation: RouteAgencyIdValidator

## 1. Module location

```
src/gtfs_validator/validators/route_agency_id.py
```

## 2. Function signature

```python
def validate_route_agency_id(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice definitions

### `missing_required_agency_id` — ERROR

Emitted per route row when `agency_id` is null/empty and the feed has more than one agency.

```python
Notice(
    code="missing_required_agency_id",
    severity=Severity.ERROR,
    fields={
        "filename": "routes.txt",          # str literal
        "csv_row_number": <int>,           # from routes["csv_row_number"]
        "agency_name": None,               # always None for route rows
    },
)
```

### `missing_recommended_field` — WARNING

Emitted per route row when `agency_id` is null/empty and the feed has exactly one agency.

```python
Notice(
    code="missing_recommended_field",
    severity=Severity.WARNING,
    fields={
        "filename": "routes.txt",          # str literal
        "csv_row_number": <int>,           # from routes["csv_row_number"]
        "field_name": "agency_id",         # str literal
    },
)
```

## 4. Implementation approach

Use Polars for the missing-row filter; use `iter_rows` for notice construction (acceptable because the missing set is small in practice).

The `csv_row_number` column is injected by the loader and is available directly on the DataFrame — do not call `with_row_index`.

**Pseudocode:**

```
function validate_route_agency_id(feed, ctx):
    # Guard 1: agency.txt absent or empty
    if "agency" not in feed or feed["agency"].is_empty():
        return []

    # Guard 2: routes.txt absent or empty
    if "routes" not in feed or feed["routes"].is_empty():
        return []

    agency_df = feed["agency"]
    routes_df  = feed["routes"]
    total_agencies = len(agency_df)

    # Filter to rows where agency_id is null or empty string.
    # If the agency_id column is entirely absent from the header, all rows will
    # have a null agency_id (schema loading guarantees the column exists with
    # null values when absent from the CSV header).
    missing = routes_df.filter(
        pl.col("agency_id").is_null() | (pl.col("agency_id") == "")
    )

    if missing.is_empty():
        return []

    notices = []
    if total_agencies > 1:
        for row in missing.iter_rows(named=True):
            notices.append(Notice(
                code="missing_required_agency_id",
                severity=Severity.ERROR,
                fields={
                    "filename": "routes.txt",
                    "csv_row_number": row["csv_row_number"],
                    "agency_name": None,
                },
            ))
    else:
        for row in missing.iter_rows(named=True):
            notices.append(Notice(
                code="missing_recommended_field",
                severity=Severity.WARNING,
                fields={
                    "filename": "routes.txt",
                    "csv_row_number": row["csv_row_number"],
                    "field_name": "agency_id",
                },
            ))
    return notices
```

**Do not** add a foreign-key check (does `agency_id` exist in `agency.txt`?). That is handled by `load_validators.py` via the FK annotation on the `routes.agency_id` column definition.

## 5. Registry entry

Add to `VALIDATOR_REGISTRY` in `src/gtfs_validator/validators/__init__.py`:

```python
from gtfs_validator.validators.route_agency_id import validate_route_agency_id

ValidatorEntry(
    name="route_agency_id",
    fn=validate_route_agency_id,
    requires=["agency", "routes"],
),
```

Place it alphabetically near the other route-level validators (e.g., after `"network_id_consistency"` and before `"overlapping_frequency"`).

## 6. Test plan

Test file: `tests/test_validators/test_route_agency_id.py`

All tests build minimal Polars DataFrames inline. Every assertion checks exact notice `code`, `severity`, and key `fields` values.

---

### `test_multi_agency_missing_agency_id_emits_error`

**Mirrors:** `agencyIdRequiredErrorWhenMoreThanOneAgency`

Setup:
- `agency`: 2 rows (content irrelevant — only row count matters).
- `routes`: 2 rows.
  - Row 0: `csv_row_number=0`, `agency_id="agency0"`.
  - Row 1: `csv_row_number=1`, `agency_id=None`.

Expected:
- Exactly 1 notice.
- `code == "missing_required_agency_id"`.
- `severity == Severity.ERROR`.
- `fields["filename"] == "routes.txt"`.
- `fields["csv_row_number"] == 1`.
- `fields["agency_name"] is None`.
