# Implementation: TransfersTripReferenceValidator

## 1. Module location

`src/gtfs_validator/validators/transfers_trip_reference.py`

## 2. Function signature

```python
def validate_transfers_trip_reference(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice definitions

Notices are constructed as `Notice(code=..., severity=..., fields={...})` using the project's existing `Notice` dataclass from `gtfs_validator.notices`.

### `transfer_with_invalid_trip_and_route` — ERROR

Emitted when `from_route_id` or `to_route_id` does not match the `route_id` of the corresponding trip.

```python
Notice(
    code="transfer_with_invalid_trip_and_route",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": int,        # from transfers.csv_row_number
        "trip_field_name": str,       # "from_trip_id" or "to_trip_id"
        "trip_id": str,               # the referenced trip ID
        "route_field_name": str,      # "from_route_id" or "to_route_id"
        "route_id": str,              # the route ID in the transfer row
        "expected_route_id": str,     # the actual route_id from trips.txt
    },
)
```

### `transfer_with_invalid_trip_and_stop` — ERROR

Emitted when `from_stop_id` or `to_stop_id` is not served by the corresponding trip's stop-times (considering station expansion).

```python
Notice(
    code="transfer_with_invalid_trip_and_stop",
    severity=Severity.ERROR,
    fields={
        "csv_row_number": int,        # from transfers.csv_row_number
        "trip_field_name": str,       # "from_trip_id" or "to_trip_id"
        "trip_id": str,               # the referenced trip ID
        "stop_field_name": str,       # "from_stop_id" or "to_stop_id"
        "stop_id": str,               # the referenced stop ID
    },
)
```

## 4. Implementation approach

### 4.1 Guard clauses

```python
if "transfers" not in feed:
    return []
transfers = feed["transfers"]
if transfers.is_empty():
    return []
required_cols = {"from_trip_id", "to_trip_id", "from_route_id", "to_route_id",
                 "from_stop_id", "to_stop_id", "csv_row_number"}
if not required_cols.issubset(transfers.columns):
    return []
```

### 4.2 Pre-build lookup structures (plain Python, Polars for iteration only)

```python
# trips lookup: trip_id -> route_id
trips_by_id: dict[str, str] = {}
trips_df = feed.get("trips")
if trips_df is not None and {"trip_id", "route_id"}.issubset(trips_df.columns):
    for row in trips_df.select(["trip_id", "route_id"]).iter_rows(named=True):
        if row["trip_id"] is not None:
            trips_by_id[row["trip_id"]] = row["route_id"] or ""

# stop_times lookup: trip_id -> set of stop_ids served
stop_times_by_trip: dict[str, set[str]] = {}
stop_times_df = feed.get("stop_times")
if stop_times_df is not None and {"trip_id", "stop_id"}.issubset(stop_times_df.columns):
    for row in stop_times_df.select(["trip_id", "stop_id"]).iter_rows(named=True):
        if row["trip_id"] is not None and row["stop_id"] is not None:
            stop_times_by_trip.setdefault(row["trip_id"], set()).add(row["stop_id"])

# stops lookups: stop_id -> location_type, parent_station -> set of child stop_ids
stops_location: dict[str, int] = {}
children_by_station: dict[str, set[str]] = {}
stops_df = feed.get("stops")
if stops_df is not None and {"stop_id", "location_type", "parent_station"}.issubset(stops_df.columns):
    for row in stops_df.select(["stop_id", "location_type", "parent_station"]).iter_rows(named=True):
        sid = row["stop_id"]
        if sid is not None:
            stops_location[sid] = row["location_type"] if row["location_type"] is not None else 0
            if row["parent_station"]:
                children_by_station.setdefault(row["parent_station"], set()).add(sid)
```

### 4.3 Station expansion helper

Define as a module-level pure function:

```python
def _expand_stop(
    stop_id: str,
    stops_location: dict[str, int],
    children_by_station: dict[str, set[str]],
) -> set[str]:
    loc_type = stops_location.get(stop_id)
    if loc_type is None:
        return set()       # not found; FK validator handles this
    if loc_type == 0:      # STOP
        return {stop_id}
    if loc_type == 1:      # STATION
        return children_by_station.get(stop_id, set())
    return set()           # ENTRANCE / GENERIC_NODE / BOARDING_AREA
```

### 4.4 Direction configuration

Avoids duplicated FROM/TO branching — use a module-level list of dicts:

```python
_TRANSFER_DIRECTIONS: list[dict[str, str]] = [
    {
        "trip_field":   "from_trip_id",
        "route_field":  "from_route_id",
        "stop_field":   "from_stop_id",
    },
    {
        "trip_field":   "to_trip_id",
        "route_field":  "to_route_id",
        "stop_field":   "to_stop_id",
    },
]
```

### 4.5 Main validation loop

Iterate each transfer row. For each direction, in order:

1. Read `trip_id` from the direction's `trip_field`. Skip direction if null.
2. Look up `trip_id` in `trips_by_id`. Skip direction if not found (FK validator owns that error).
3. Read `route_id` from the direction's `route_field`. If not null and does not match `trips_by_id[trip_id]`, emit `transfer_with_invalid_trip_and_route`.
4. Read `stop_id` from the direction's `stop_field`. If not null:
   a. If `stop_id` is not in `stops_location`, skip (FK validator owns that error).
   b. Compute `candidates = _expand_stop(stop_id, stops_location, children_by_station)`.
   c. Compute `trip_stops = stop_times_by_trip.get(trip_id, set())`.
   d. If `candidates.isdisjoint(trip_stops)` (no overlap), emit `transfer_with_invalid_trip_and_stop`.

Route check always runs before stop check within a direction (matches Java ordering, which matters when both errors fire for the same direction).

### 4.6 Column presence check pattern

Follow the same pattern as existing transfer validators (`transfers_stop_type.py`, `transfers_in_seat_transfer_type.py`): use `required_cols.issubset(transfers.columns)` before the loop; use `.get()` on row dicts when accessing optional fields that may be absent from sparse rows.

## 5. Registry entry

Add to `src/gtfs_validator/validators/__init__.py`:

**Import:**
```python
from gtfs_validator.validators.transfers_trip_reference import (
    validate_transfers_trip_reference,
)
```

**Registry entry** (insert after the `"transfers_stop_type"` entry, maintaining alphabetical/topological order with related transfer validators):
```python
ValidatorEntry(
    name="transfers_trip_reference",
    fn=validate_transfers_trip_reference,
    requires=["transfers"],
),
```

`requires` lists only `"transfers"` because `trips`, `stop_times`, and `stops` are accessed with graceful fallback (`feed.get(...)` returning `None` → empty lookups), matching the Java guard pattern. Missing tables silently produce empty lookup dicts, and the validator degrades safely.

## 6. Test plan

Test file: `tests/test_validators/test_transfers_trip_reference.py`

All tests build minimal `pl.DataFrame` objects directly; no file I/O.

### Helper fixture conventions

- Use a `make_feed(**overrides)` helper that returns a `dict[str, pl.DataFrame]` with the minimum tables needed.
- Use `int` literals for `location_type` (0 = STOP, 1 = STATION).
- All DataFrames must include `csv_row_number` on `transfers`.

Mirrors Java `testValidTripReferences` (direct-stop branch).

Setup:

- `stops`: `[("s0", 0, None)]`  — STOP type
- `stop_times`: `[("t0", "s0")]`
- `transfers`: one row — `from_trip_id="t0"`, `from_route_id="r0"`, `from_stop_id="s0"`, all `to_*=None`, `csv_row_number=2`

Expected: zero notices.

#### `test_valid_station_reference`

Mirrors Java `testValidTripReferences` (station expansion branch).

Setup:
- `trips`: `[("t1", "r1")]`

Expected: exactly one notice.
- code = `"transfer_with_invalid_trip_and_route"`
- `trip_field_name = "from_trip_id"`, `trip_id = "t0"`, `route_field_name = "from_route_id"`, `route_id = "DNE"`, `expected_route_id = "r0"`

#### `test_invalid_stop_to_direction`

Mirrors Java `testInvalidTripReferences` (TO-side stop not in trip's stop-times).

Setup:

- `transfers`: one row — `to_trip_id="t1"`, `to_route_id="r1"`, `to_stop_id="s2"`, all `from_*=None`, `csv_row_number=2`

Expected: exactly one notice.
- code = `"transfer_with_invalid_trip_and_stop"`

Full reproduction of Java `testInvalidTripReferences` — both errors on one transfer row.

Expected: exactly two notices, in order:
1. `transfer_with_invalid_trip_and_route` for FROM direction (`trip_id="t0"`, `route_id="DNE"`, `expected_route_id="r0"`)
2. `transfer_with_invalid_trip_and_stop` for TO direction (`trip_id="t1"`, `stop_id="s2"`)

## 7. Key implementation details

- `csv_row_number` is always present in loaded DataFrames (the loader appends it). Access it directly from the row dict without `.get()`.
- All other transfer fields (`from_trip_id`, `to_trip_id`, etc.) may be null; use `row.get(field)` or check for `None` after direct access.
- The direction loop iterates `[FROM, TO]` in that order, matching the Java behavior and preserving notice ordering in multi-error cases.
- Do not convert `stop_times_by_trip` values to `list`; keep them as `set[str]` for O(1) membership tests with `isdisjoint`.
- The `_expand_stop` helper must be a module-level function (not a nested closure) to satisfy the project's pure-function and composability conventions.
- No `ctx` (ValidationContext) fields are used by this validator; the parameter is accepted but ignored, consistent with other validators that do not need date or country context.
