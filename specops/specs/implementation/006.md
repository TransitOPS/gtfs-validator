# Implementation: BookingRulesEntityValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/booking_rules_entity.py`

No new shared utilities are required. This is a single-entity (row-level)
validator operating solely on `booking_rules.txt` with simple conditionals
per row. All logic is self-contained.

## 2. Function Signature

```python
from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_booking_rules_entity(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 4. Implementation Approach

### Constants

```python
# Booking type enum values
REALTIME = 0
SAMEDAY = 1
PRIORDAY = 2

# Fields forbidden per booking type
_REALTIME_FORBIDDEN = [
    "prior_notice_duration_min",
    "prior_notice_duration_max",
    "prior_notice_last_day",
    "prior_notice_last_time",
    "prior_notice_start_day",
    "prior_notice_start_time",
    "prior_notice_service_id",
]

_SAMEDAY_FORBIDDEN = [
    "prior_notice_last_day",
    "prior_notice_last_time",
    "prior_notice_service_id",
]

_PRIORDAY_FORBIDDEN = [
    "prior_notice_duration_min",
    "prior_notice_duration_max",
]
```

### Helper: check forbidden fields for a single row

```python
def _check_forbidden_fields(row, forbidden_fields):
    """Return list of field names that are non-null in the row."""
    return [f for f in forbidden_fields if row[f] is not None]
```

### Main validator pseudocode

```
function validate_booking_rules_entity(feed, ctx):
    # 1. Guard: required table
    if "booking_rules" not in feed:
        return []
    df = feed["booking_rules"]
    if df.is_empty():
        return []

    # 2. Iterate rows — simple conditionals, not worth vectorizing
    #    because multiple notices per row with different field sets
    #    make expression-based approach complex without real benefit
    notices = []

    for row in df.iter_rows(named=True):
        csv_row_number = row["csv_row_number"]
        booking_rule_id = row["booking_rule_id"]
        booking_type = row["booking_type"]

        # --- 3a. Forbidden fields by booking type ---
        if booking_type == REALTIME:
            offending = _check_forbidden_fields(row, _REALTIME_FORBIDDEN)
            if offending:
                notices.append(Notice(
                    code="forbidden_real_time_booking_field_value",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "booking_rule_id": booking_rule_id,
                        "field_names": ",".join(offending),
                    },
                ))

        elif booking_type == SAMEDAY:
            offending = _check_forbidden_fields(row, _SAMEDAY_FORBIDDEN)
            if offending:
                notices.append(Notice(
                    code="forbidden_same_day_booking_field_value",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "booking_rule_id": booking_rule_id,
                        "field_names": ",".join(offending),
                    },
                ))

            # --- 3b. Missing prior_notice_duration_min for SAMEDAY ---
            if row["prior_notice_duration_min"] is None:
                notices.append(Notice(
                    code="missing_prior_notice_duration_min",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "booking_rule_id": booking_rule_id,
                    },
                ))

        elif booking_type == PRIORDAY:
            offending = _check_forbidden_fields(row, _PRIORDAY_FORBIDDEN)
            if offending:
                notices.append(Notice(
                    code="forbidden_prior_day_booking_field_value",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "booking_rule_id": booking_rule_id,
                        "field_names": ",".join(offending),
                    },
                ))

            # --- 3d. Missing required PRIORDAY fields ---
            if row["prior_notice_last_day"] is None:
                notices.append(Notice(
                    code="missing_prior_notice_last_day",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "booking_rule_id": booking_rule_id,
                    },
                ))
            if row["prior_notice_last_time"] is None:
                notices.append(Notice(
                    code="missing_prior_notice_last_time",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "booking_rule_id": booking_rule_id,
                    },
                ))

        # --- Type-independent checks (run for ALL booking_type values) ---

        # --- 3c. Duration min vs max range check ---
        dur_min = row["prior_notice_duration_min"]
        dur_max = row["prior_notice_duration_max"]
        if dur_min is not None and dur_max is not None:
            if dur_max < dur_min:
                notices.append(Notice(
                    code="invalid_prior_notice_duration_min",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "booking_rule_id": booking_rule_id,
                        "prior_notice_duration_min": dur_min,
                        "prior_notice_duration_max": dur_max,
                    },
                ))

        # --- 3e. start_day forbidden with duration_max ---
        start_day = row["prior_notice_start_day"]
        if dur_max is not None and start_day is not None:
            notices.append(Notice(
                code="forbidden_prior_notice_start_day",
                severity=ERROR,
                fields={
                    "csv_row_number": csv_row_number,
                    "booking_rule_id": booking_rule_id,
                    "prior_notice_start_day": start_day,
                    "prior_notice_duration_max": dur_max,
                },
            ))

        # --- 3f. last_day vs start_day range ---
        last_day = row["prior_notice_last_day"]
        if last_day is not None and start_day is not None:
            if last_day > start_day:
                notices.append(Notice(
                    code="prior_notice_last_day_after_start_day",
                    severity=ERROR,
                    fields={
                        "csv_row_number": csv_row_number,
                        "prior_notice_last_day": last_day,
                        "prior_notice_start_day": start_day,
                    },
                ))

        # --- 3g. start_time / start_day co-dependency ---
        start_time = row["prior_notice_start_time"]
        has_start_time = start_time is not None
        has_start_day = start_day is not None

        if has_start_time and not has_start_day:
            notices.append(Notice(
                code="forbidden_prior_notice_start_time",
                severity=ERROR,
                fields={
                    "csv_row_number": csv_row_number,
                    "booking_rule_id": booking_rule_id,
                    "prior_notice_start_time": str(start_time),
                },
            ))

        if has_start_day and not has_start_time:
            notices.append(Notice(
                code="missing_prior_notice_start_time",
                severity=ERROR,
                fields={
                    "csv_row_number": csv_row_number,
                    "booking_rule_id": booking_rule_id,
                    "prior_notice_start_day": start_day,
                },
            ))

    return notices
```

**Key design decisions:**

- **Row iteration over Polars expressions.** Although AGENTS.md prefers
  vectorized Polars operations, this validator emits multiple distinct
  notice types per row with varying field payloads, and the forbidden-field
  checks need to dynamically collect offending field names into a
  comma-joined string. A row-loop with simple conditionals is clearer and
  avoids a complex multi-expression pipeline that would still need to
  `collect` and post-process rows for notice construction. The
  `booking_rules.txt` table is typically small (tens to low hundreds of
  rows), so performance is not a concern.
- **`csv_row_number` column.** Assumes the loader populates a 1-based
  `csv_row_number` column on the DataFrame, consistent with other
  validators.
- **Null semantics for field presence.** All prior-notice columns are
  loaded as nullable types (nullable integers for day/duration fields,
  nullable strings/time for time fields). A field "is set" when its value
  is not None in the row dict returned by `iter_rows(named=True)`.
- **`prior_notice_last_day_after_start_day` omits `booking_rule_id`.**
  This is an intentional compatibility choice matching the Java source
  (see analysis spec section 5).
- **Unrecognized `booking_type` values.** If `booking_type` is null or
  not in {0, 1, 2}, the type-specific branches are skipped but the
  type-independent checks (3c, 3e, 3f, 3g) still execute.

## 5. Registry Entry

In `src/gtfs_validator/validators/__init__.py`, add the import and
registry entry:

```python
from gtfs_validator.validators.booking_rules_entity import validate_booking_rules_entity

# Add to VALIDATOR_REGISTRY list:
ValidatorEntry(
    name="booking_rules_entity",
    fn=validate_booking_rules_entity,
    requires=["booking_rules"],
),
```

The `requires` list contains only `"booking_rules"` since no other tables
are referenced.
