# Implementation: UniqueGeographyIdValidator

## 1. Module location

Fix the existing file: `src/gtfs_validator/validators/unique_geography_id.py`

Two defects to correct:
1. The GeoJSON access uses `feed.get("geojson_features")` with a DataFrame column model. Replace with `feed.get("locations_geojson")` returning a `list[dict]`, matching every other validator that reads GeoJSON.
2. The validator is not registered in `VALIDATOR_REGISTRY`. Add the entry.

---

## 2. Function signature

```python
def validate_unique_geography_id(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

`feed["locations_geojson"]` is `list[dict[str, Any]]`, not a `pl.DataFrame`. `feed["stops"]` and `feed["location_groups"]` are standard `pl.DataFrame` values (or absent from the dict).

---

## 3. Notice definition

### `duplicate_geography_id`

- **Severity**: `Severity.ERROR`
- **Code**: `"duplicate_geography_id"`
- **When emitted**: The same ID string appears in two or more distinct sources among `stops.txt`, `location_groups.txt`, and `locations.geojson`. One notice per colliding ID.

| Field | Type | Description |
|---|---|---|
| `geography_id` | `str` | The colliding ID value |
| `csv_row_number_stops` | `int \| None` | First `csv_row_number` from `stops.txt` for this ID, or `None` if stops does not contain it |
| `csv_row_number_location_groups` | `int \| None` | First `csv_row_number` from `location_groups.txt` for this ID, or `None` if location_groups does not contain it |
| `feature_index` | `int \| None` | Zero-based feature index from `locations.geojson` for this ID, or `None` if geojson does not contain it |

Construction:
```python
Notice(
    code="duplicate_geography_id",
    severity=Severity.ERROR,
    fields={
        "geography_id": geo_id,
        "csv_row_number_stops": csv_row_number_stops,
        "csv_row_number_location_groups": csv_row_number_location_groups,
        "feature_index": feature_index,
    },
)
```

## 4. Implementation approach

### 4.1 Data collection

Collect all ID entries from each source into a flat list of dicts. Each dict has three keys: `"id"`, `"source"`, `"row_number"`.

**From `stops.txt`** (a `pl.DataFrame`, may be absent or empty):
```python
stops_df = feed.get("stops")
if stops_df is not None and not stops_df.is_empty() and "stop_id" in stops_df.columns:
    for row in stops_df.select("stop_id", "csv_row_number").iter_rows(named=True):
        if row["stop_id"] is not None:
            entries.append({"id": row["stop_id"], "source": "stops.txt", "row_number": row["csv_row_number"]})
```

**From `location_groups.txt`** (a `pl.DataFrame`, may be absent or empty):
```python
lg_df = feed.get("location_groups")
if lg_df is not None and not lg_df.is_empty() and "location_group_id" in lg_df.columns:
    for row in lg_df.select("location_group_id", "csv_row_number").iter_rows(named=True):
        if row["location_group_id"] is not None:
            entries.append({"id": row["location_group_id"], "source": "location_groups.txt", "row_number": row["csv_row_number"]})
```

**From `locations.geojson`** (a `list[dict]`, may be absent or empty):
```python
geojson_features: list[dict] = feed.get("locations_geojson") or []
for feature in geojson_features:
    fid = feature.get("id")
    if fid is not None:
        entries.append({"id": fid, "source": "locations.geojson", "row_number": feature.get("index")})
```

Early exit: if `entries` is empty, return `[]`.

### 4.2 Grouping and collision detection

```python
id_groups: dict[str, list[dict]] = {}
for entry in entries:
    id_groups.setdefault(entry["id"], []).append(entry)

notices: list[Notice] = []
for geo_id, group in id_groups.items():
    unique_sources = {e["source"] for e in group}
    if len(unique_sources) <= 1:
        continue  # same-source duplicates are ignored by this validator

    # Capture only the first occurrence per source (matches Java findFirst() semantics)
    csv_row_number_stops = None
    csv_row_number_location_groups = None
    feature_index = None
    for entry in group:
        src = entry["source"]
        if src == "stops.txt" and csv_row_number_stops is None:
            csv_row_number_stops = entry["row_number"]
        elif src == "location_groups.txt" and csv_row_number_location_groups is None:
            csv_row_number_location_groups = entry["row_number"]
        elif src == "locations.geojson" and feature_index is None:
            feature_index = entry["row_number"]

    notices.append(Notice(
        code="duplicate_geography_id",
        severity=Severity.ERROR,
        fields={
            "geography_id": geo_id,
            "csv_row_number_stops": csv_row_number_stops,
            "csv_row_number_location_groups": csv_row_number_location_groups,
            "feature_index": feature_index,
        },
    ))

return notices
```

### 4.3 Key rules

- **Cross-source only**: A single `stop_id` duplicated within `stops.txt` alone does not trigger this validator. The guard `if len(unique_sources) <= 1: continue` handles this.
- **First-occurrence wins**: Only the first row number per source file is captured in the notice, matching Java `findFirst()`.
- **One notice per colliding ID**: When ID `"x"` appears in all three sources, exactly one notice is emitted with all three row fields populated.
- **Null skipping**: Rows with `None` `stop_id`, `location_group_id`, or GeoJSON `id` are excluded during collection; they must not crash the validator.

## 5. Registry entry

Add to `VALIDATOR_REGISTRY` in `src/gtfs_validator/validators/__init__.py`.

Import:
```python
from gtfs_validator.validators.unique_geography_id import validate_unique_geography_id
```

Registry entry:
```python
ValidatorEntry(
    name="unique_geography_id",
    fn=validate_unique_geography_id,
    requires=[],  # handles absent tables internally; any combination may be present
),
```

`requires=[]` is correct because none of the three sources is mandatory for this validator to run — it must handle every combination of absent/present tables internally. The validator itself produces zero notices when fewer than two sources are populated.

## 6. Test plan

Tests live in `tests/test_validators/test_unique_geography_id.py`.

Each test constructs minimal DataFrames / dicts and asserts on returned notices.

### 6.1 Test cases derived from Java contracts

**`test_three_way_collision_yields_notice`**

Setup:
- `stops`: one row, `stop_id="locationId"`, `csv_row_number=1`
- `location_groups`: one row, `location_group_id="locationId"`, `csv_row_number=1`
- `locations_geojson`: one feature, `{"id": "locationId", "index": 0}`

Expected: exactly one notice with `code="duplicate_geography_id"`, `geography_id="locationId"`, `csv_row_number_stops=1`, `csv_row_number_location_groups=1`, `feature_index=0`.

**`test_unique_ids_yields_no_notice`**

Setup:
- `stops`: `stop_id="locationId2"`, `csv_row_number=1`
- `location_groups`: `location_group_id="locationId3"`, `csv_row_number=1`
- `locations_geojson`: `[{"id": "locationId1", "index": 0}]`

Expected: no notices.

### 6.2 Additional Python-specific cases

**`test_all_sources_absent_yields_no_notice`**

Feed is `{}`. Expected: `[]`.

**`test_only_stops_present_yields_no_notice`**

Feed has `"stops"` with `stop_id="x"`, no other sources. Expected: `[]`.

**`test_only_geojson_present_yields_no_notice`**

Feed has `"locations_geojson"` with `[{"id": "x", "index": 0}]`, no other sources. Expected: `[]`.

**`test_two_way_collision_stops_and_geojson`**

- `stops`: `stop_id="x"`, `csv_row_number=2`
- `locations_geojson`: `[{"id": "x", "index": 0}]`
- No `location_groups`

Expected: one notice, `geography_id="x"`, `csv_row_number_stops=2`, `csv_row_number_location_groups=None`, `feature_index=0`.

**`test_two_way_collision_stops_and_location_groups`**

- `stops`: `stop_id="y"`, `csv_row_number=3`
- `location_groups`: `location_group_id="y"`, `csv_row_number=5`
- No `locations_geojson`

Expected: one notice, `geography_id="y"`, `csv_row_number_stops=3`, `csv_row_number_location_groups=5`, `feature_index=None`.

**`test_same_source_duplicate_only_yields_no_notice`**

- `stops`: two rows, both with `stop_id="x"`, `csv_row_number=1` and `csv_row_number=2`
- No other sources

Expected: `[]`. (This is a PK violation handled by load-time validation, not this validator.)

**`test_multiple_colliding_ids_yield_multiple_notices`**

- `stops`: `stop_id="a"` (row 1), `stop_id="b"` (row 2)
- `locations_geojson`: `[{"id": "a", "index": 0}, {"id": "b", "index": 1}]`
- No `location_groups`

Expected: two notices, one for `"a"` and one for `"b"`. Assert both codes are `"duplicate_geography_id"`.

**`test_null_ids_are_skipped`**

- `stops`: one row with `stop_id=None`, `csv_row_number=1`
- `locations_geojson`: `[{"id": None, "index": 0}]`

Expected: `[]`. No crash.

**`test_first_occurrence_row_number_reported`**

- `stops`: two rows, `stop_id="x"` at `csv_row_number=1` and `csv_row_number=3`
- `locations_geojson`: `[{"id": "x", "index": 0}]`

Expected: one notice, `csv_row_number_stops=1` (first occurrence only).

### 6.3 Assertion pattern

```python
assert len(notices) == 1
n = notices[0]
assert n.code == "duplicate_geography_id"
assert n.severity == Severity.ERROR
assert n.fields["geography_id"] == "x"
assert n.fields["csv_row_number_stops"] == 2
assert n.fields["csv_row_number_location_groups"] is None
assert n.fields["feature_index"] == 0
```
