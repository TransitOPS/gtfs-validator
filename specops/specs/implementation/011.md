# Implementation: ExpiredCalendarValidator

## 1. Module Location

**Validator:** `src/gtfs_validator/validators/expired_calendar.py`

**Shared utility:** `src/gtfs_validator/calendar_utils.py` (already exists).
The existing `build_service_date_map` function computes active dates per
service ID from `calendar.txt` and `calendar_dates.txt`. This validator
reuses it directly.

No new shared utilities are needed. The existing `build_service_date_map`
already handles weekly pattern expansion, SERVICE_ADDED additions, and
SERVICE_REMOVED removals, which is exactly the date computation this
validator requires.

## 2. Function Signature

```python
from __future__ import annotations

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Notice, Severity


def validate_expired_calendar(
    feed: dict[str, pl.DataFrame],
    ctx: ValidationContext,
) -> list[Notice]:
```

## 3. Notice Definitions

All notices have severity **WARNING**.

### `expired_calendar`

Emitted when all active service dates for a service ID fall strictly
before the validation date (the service is entirely in the past).

```python
Notice(
    code="expired_calendar",
    severity=Severity.WARNING,
    fields={
        "csv_row_number": <int>,   # row in calendar.txt or min row in calendar_dates.txt
        "service_id": <str>,       # the expired service ID
    },
)
```

Referenced files: `calendar.txt`, `calendar_dates.txt`.

## 4. Implementation Approach

```
function validate_expired_calendar(feed, ctx):
    # 1. Build service date map using existing shared utility
    service_date_map = build_service_date_map(feed)

    if not service_date_map:
        return []

    validation_date = ctx.date_for_validation

    # 2. Determine whether calendar.txt is present and non-empty
    calendar_present = (
        "calendar" in feed and not feed["calendar"].is_empty()
    )

    # 3. Identify expired service IDs
    #    A service is expired if its active date set is non-empty and
    #    max(dates) < validation_date.
    #    Services with empty date sets are skipped (no notice).
    expired_services: dict[str, None] = {}   # ordered set of expired service_ids
    non_expired_exists = False

    for service_id, dates in service_date_map.items():
        if not dates:
            continue   # empty set -- skip
        if max(dates) < validation_date:
            expired_services[service_id] = None
        else:
            non_expired_exists = True

    if not expired_services:
        return []

    # 4. Build csv_row_number lookups
    notices = []

    if calendar_present:
        # Branch A: calendar.txt is non-empty
        # Emit notices only for expired services that have a row in calendar.txt.
        # Use the csv_row_number from calendar.txt.
        calendar_df = feed["calendar"]

        # Build service_id -> csv_row_number map from calendar.txt
        cal_service_ids = calendar_df["service_id"].to_list()
        cal_row_map: dict[str, int] = {}
        for i, sid in enumerate(cal_service_ids):
            if sid not in cal_row_map:
                cal_row_map[sid] = i + 2   # +2: 0-based index + header row + 1-based

        for service_id in expired_services:
            if service_id in cal_row_map:
                notices.append(
                    Notice(
                        code="expired_calendar",
                        severity=Severity.WARNING,
                        fields={
                            "csv_row_number": cal_row_map[service_id],
                            "service_id": service_id,
                        },
                    )
                )
    else:
        # Branch B: calendar.txt is empty (all services from calendar_dates.txt only)
        # Only emit if ALL service IDs are expired.
        if non_expired_exists:
            return []

        # Build service_id -> min csv_row_number from calendar_dates.txt
        cd_df = feed["calendar_dates"]
        cd_service_ids = cd_df["service_id"].to_list()
        cd_row_map: dict[str, int] = {}
        for i, sid in enumerate(cd_service_ids):
            row_num = i + 2
            if sid not in cd_row_map or row_num < cd_row_map[sid]:
                cd_row_map[sid] = row_num

        for service_id in expired_services:
            if service_id in cd_row_map:
                notices.append(
                    Notice(
                        code="expired_calendar",
                        severity=Severity.WARNING,
                        fields={
                            "csv_row_number": cd_row_map[service_id],
                            "service_id": service_id,
                        },
                    )
                )

    # 5. Sort by csv_row_number ascending
    notices.sort(key=lambda n: n.fields["csv_row_number"])
    return notices
```

**Key design decisions:**

- **Reuses `build_service_date_map`.** The existing utility in
  `calendar_utils.py` already implements the full date expansion and
  exception merging logic. No duplication needed.
- **`+ 2` for csv_row_number.** 0-based DataFrame index + 1 for
  1-based numbering + 1 for the header row, matching Java convention
  where data starts at row 2.
- **Two-branch emission logic.** When `calendar.txt` is non-empty,
  notices are emitted per expired service that has a calendar.txt row
  (orphan calendar_dates-only services are silently ignored). When
  `calendar.txt` is empty, notices are emitted only if every service
  ID is expired; otherwise all notices are suppressed.
- **Python-side iteration.** Service counts are typically small (tens
  to hundreds). Plain Python loops over the service date map are
  appropriate and match the analysis spec recommendation (Option A).
- **`max(dates) < validation_date`** for the expiration check. A
  service whose latest date equals today is NOT expired.
- **Empty date sets are skipped.** A service with all days set to 0
  and no calendar_dates additions has an empty active set. It is
  neither expired nor non-expired -- it produces no notice and does
  not count toward the "all expired" check in Branch B.

## 5. Registry Entry

In `src/gtfs_validator/validators/__init__.py`, add the import and
registry entry:

```python
from gtfs_validator.validators.expired_calendar import validate_expired_calendar

# Add to VALIDATOR_REGISTRY list:
ValidatorEntry(
    name="expired_calendar",
    fn=validate_expired_calendar,
    requires=["calendar", "calendar_dates"],
),
```

The `requires` list includes both `"calendar"` and `"calendar_dates"`.
The runner skips the validator if neither table is present. The
validator itself handles the case where one or both tables are empty
(the `build_service_date_map` utility returns an empty dict when both
are missing/empty).

**Note on `requires` semantics:** The runner treats `requires` as an
OR condition -- at least one of the listed tables must be present.
This is correct because the validator can operate with only
`calendar_dates.txt` (no `calendar.txt`), or with only `calendar.txt`
(no `calendar_dates.txt`), or with both. The validator guards
internally for the case where a table is absent.

## 6. Test Plan

Test file: `tests/test_validators/test_expired_calendar.py`

All tests construct minimal `feed` dicts with Polars DataFrames and
call `validate_expired_calendar` directly.

### Shared test helpers

```python
from datetime import date, timedelta

import polars as pl

from gtfs_validator.context import ValidationContext
from gtfs_validator.notices import Severity
from gtfs_validator.validators.expired_calendar import validate_expired_calendar

NOW = date(2024, 4, 15)  # a Tuesday
CTX = ValidationContext(country_code="US", date_for_validation=NOW)


def make_calendar(rows: list[dict]) -> pl.DataFrame:
    if not rows:
        return pl.DataFrame(
            schema={
                "service_id": pl.Utf8,
                "monday": pl.Int64,
                "tuesday": pl.Int64,
                "wednesday": pl.Int64,
                "thursday": pl.Int64,
                "friday": pl.Int64,
                "saturday": pl.Int64,
                "sunday": pl.Int64,
                "start_date": pl.Date,
                "end_date": pl.Date,
            }
        )
    return pl.DataFrame(rows)


def make_calendar_dates(rows: list[dict]) -> pl.DataFrame:
    if not rows:
        return pl.DataFrame(
            schema={
                "service_id": pl.Utf8,
                "date": pl.Date,
                "exception_type": pl.Int64,
            }
        )
    return pl.DataFrame(rows)
```
