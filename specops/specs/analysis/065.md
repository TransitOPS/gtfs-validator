# Analysis: StopTimesShapeDistTraveledPresenceValidator

## 1. Purpose

Checks that `shape_dist_traveled` is not set on any `stop_times.txt` row that
uses a GeoJSON location (`location_id`) or location group
(`location_group_id`) instead of a regular stop (`stop_id`).

## 2. Input tables

| Table | Columns used |
|---|---|
| `stop_times.txt` | `stop_id`, `location_group_id`, `location_id`, `shape_dist_traveled`, `trip_id`, `csv_row_number` |

### Column semantics

- `stop_id` — optional string; when present and non-null, this row describes a
  regular stop and the validator skips the row entirely.
- `location_group_id` — optional string; when non-null (and `stop_id` is null),
  identifies a location group for GTFS Flex.
- `location_id` — optional string; when non-null (and `stop_id` is null),
  identifies a GeoJSON location area for GTFS Flex.
- `shape_dist_traveled` — optional float; distance traveled along the shape up
  to this stop. Must not be set when the row references a flex location.
- `trip_id` — string; included in the notice payload for diagnostics.
- `csv_row_number` — integer; source CSV row number, included in notice payload.

## 3. Validation logic

This is a `SingleEntityValidator` that checks each `stop_times.txt` row
independently.

### Guard clause (`shouldCallValidate`)

Before any row is processed, the validator checks that:

1. `shape_dist_traveled` is present as a column header in `stop_times.txt`.
2. At least one of `location_id` or `location_group_id` is present as a column
   header in `stop_times.txt`.

If either condition fails (either `shape_dist_traveled` is absent, or neither
flex location column exists), the validator skips entirely and emits no notices.

### Per-row check

For each row in `stop_times.txt`:

1. If `stop_id` is non-null (i.e., `hasStopId()` is true): skip this row
   entirely — `shape_dist_traveled` is valid for regular stops.
2. If `location_group_id` is non-null OR `location_id` is non-null:
   a. If `shape_dist_traveled` is also non-null: emit
      `ForbiddenShapeDistTraveledNotice` with `csv_row_number`, `trip_id`,
      `location_group_id`, `location_id`, and `shape_dist_traveled`.
   b. If `shape_dist_traveled` is null: no notice.
3. If neither `location_group_id` nor `location_id` is non-null (and `stop_id`
   is also null): no notice is emitted. This is a malformed row but not this
   validator's concern.

The check is: row has no `stop_id` AND has at least one flex location field AND
has `shape_dist_traveled`.

## 4. Notices emitted

### `forbidden_shape_dist_traveled` (ERROR)

Emitted when a `stop_times.txt` row references a GeoJSON location or location
group (not a regular stop) and also specifies `shape_dist_traveled`.

| Field | Type | Source | Description |
|---|---|---|---|
| `csv_row_number` | int | `stop_times.csv_row_number` | CSV row number of the offending row |
| `trip_id` | string | `stop_times.trip_id` | Trip that contains the offending row |
| `location_group_id` | string | `stop_times.location_group_id` | Location group ID; empty string if not set |
| `location_id` | string | `stop_times.location_id` | GeoJSON location ID; empty string if not set |
| `shape_dist_traveled` | float | `stop_times.shape_dist_traveled` | The forbidden distance value |

**Note on null vs empty string:** The Java test constructs the notice with `""`
(empty string) when `locationGroupId` or `locationId` is not set. This matches
how the Java GTFS entity builder returns an empty string for unset string fields.
In the Python implementation, use `None` (or `""`) consistently, matching
whatever the loading layer normalizes unset optional strings to.

Condition: `stop_id` is null AND (`location_group_id` is non-null OR
`location_id` is non-null) AND `shape_dist_traveled` is non-null.

## 5. Edge cases

| Scenario | Expected behavior |
|---|---|
| `stop_times.txt` absent from feed | Return `[]` immediately. |
| `stop_times.txt` present but empty (zero rows) | No rows match; return `[]`. |
| `shape_dist_traveled` column absent from `stop_times.txt` | Guard fails; skip entirely; return `[]`. |
| Neither `location_id` nor `location_group_id` column present | Guard fails; skip entirely; return `[]`. |
| Only `location_id` column present (no `location_group_id`) | Guard passes; validator runs on rows where `location_id` is non-null. |
| Only `location_group_id` column present (no `location_id`) | Guard passes; validator runs on rows where `location_group_id` is non-null. |
| Row has `stop_id` set (regular stop) with `shape_dist_traveled` | No notice — `stop_id` presence is the early exit. |
| Row has `stop_id` null AND flex location null AND `shape_dist_traveled` set | No notice — neither flex location field is set, so this row's conditions are not met. |
| Row has `location_group_id` set, no `location_id`, `shape_dist_traveled` set | Emit notice with `location_group_id` set, `location_id` empty/null. |
| Row has `location_id` set, no `location_group_id`, `shape_dist_traveled` set | Emit notice with `location_id` set, `location_group_id` empty/null. |
| Row has both `location_group_id` and `location_id` set, `shape_dist_traveled` set | Emit one notice with both fields populated. |
| Row has flex location set but `shape_dist_traveled` null | No notice. |
| Multiple rows violating the rule | One notice per offending row. |

## 6. Test contracts

The Java test file contains one test method.

### `locationWithShapeDistanceShouldGenerateNotice`

- Input: three stop_time rows for `trip_id = "first trip"`:
  - Row 1 (`csv_row_number=1`): `location_group_id="loc1"`, `location_id=null`,
    `stop_id=null`, `stop_sequence=2`, `shape_dist_traveled=10.0`.
  - Row 2 (`csv_row_number=2`): `location_group_id=null`, `location_id="loc2"`,
    `stop_id=null`, `stop_sequence=42`, `shape_dist_traveled=45.0`.
  - Row 3 (`csv_row_number=3`): `location_group_id=null`, `location_id=null`,
    `stop_id="stop1"`, `stop_sequence=46`, `shape_dist_traveled=64.0`.
- Expected: exactly two notices:
  - `ForbiddenShapeDistTraveledNotice(csv_row_number=1, trip_id="first trip",
    location_group_id="loc1", location_id="", shape_dist_traveled=10.0)`
  - `ForbiddenShapeDistTraveledNotice(csv_row_number=2, trip_id="first trip",
    location_group_id="", location_id="loc2", shape_dist_traveled=45.0)`
- Row 3 is not flagged because `stop_id` is set (early exit condition).
- Covers: location group violation, location id violation, and the stop_id
  early-exit in a single test.

### What is NOT covered by the Java test suite

- `stop_times.txt` absent entirely.
- The `shouldCallValidate` guard paths (missing `shape_dist_traveled` column or
  missing both flex location columns).
- Empty `stop_times.txt` (zero rows).
- Row where neither `stop_id` nor any flex location field is set but
  `shape_dist_traveled` is present.
- Row where both `location_group_id` and `location_id` are set simultaneously.
- Multiple offending rows across multiple trips.
- Row with flex location but `shape_dist_traveled` absent (no notice expected).

## 7. Implementation notes

### Algorithm strategy

All conditions are per-row with no cross-row aggregation needed. This is a
simple vectorized filter followed by notice construction.

### Recommended Polars approach

```python
def validate_stop_times_shape_dist_traveled_presence(
    feed: dict[str, pl.DataFrame], ctx: ValidationContext
) -> list[Notice]:
    if "stop_times" not in feed:
        return []

    st = feed["stop_times"]

    # Guard: shape_dist_traveled must exist, plus at least one flex location column
    if "shape_dist_traveled" not in st.columns:
        return []
    if "location_id" not in st.columns and "location_group_id" not in st.columns:
        return []

    if st.is_empty():
        return []

    # Build filter: no stop_id AND at least one flex location field AND shape_dist_traveled set
    has_stop_id = pl.col("stop_id").is_not_null() if "stop_id" in st.columns else pl.lit(False)

    has_flex_location = pl.lit(False)
    if "location_group_id" in st.columns:
        has_flex_location = has_flex_location | pl.col("location_group_id").is_not_null()
    if "location_id" in st.columns:
        has_flex_location = has_flex_location | pl.col("location_id").is_not_null()

    violations = st.filter(
        ~has_stop_id
        & has_flex_location
        & pl.col("shape_dist_traveled").is_not_null()
    )

    notices: list[Notice] = []
    for row in violations.iter_rows(named=True):
        notices.append(
            ForbiddenShapeDistTraveledNotice(
                csv_row_number=row["csv_row_number"],
                trip_id=row["trip_id"],
                location_group_id=row.get("location_group_id"),
                location_id=row.get("location_id"),
                shape_dist_traveled=row["shape_dist_traveled"],
            )
        )
    return notices
```

### Guard clause ordering

1. `"stop_times"` not in feed → return `[]`.
2. `"shape_dist_traveled"` not in `stop_times.columns` → return `[]`.
3. Neither `"location_id"` nor `"location_group_id"` in `stop_times.columns` →
   return `[]`.
4. `stop_times` is empty (0 rows) → naturally returns `[]` from the filter; can
   also short-circuit for clarity.

### Polars vs plain Python

- All conditions are row-independent vectorized predicates; Polars filter
  expressions are the right tool.
- `iter_rows(named=True)` is used only for notice construction over the
  (typically small) violation set.
- No joins, aggregations, or graph traversal needed.

### Notice dataclass

```python
@dataclass
class ForbiddenShapeDistTraveledNotice:
    code: ClassVar[str] = "forbidden_shape_dist_traveled"
    severity: ClassVar[str] = "ERROR"
    csv_row_number: int
    trip_id: str
    location_group_id: str | None
    location_id: str | None
    shape_dist_traveled: float
```

### Optional column handling

`stop_id`, `location_group_id`, and `location_id` are all optional columns in
`stop_times.txt`. The guard and filter logic must check whether each column
exists before referencing it. If a column is absent from the DataFrame entirely,
treat it as universally null for filter purposes.

### Feed dict keys

- `"stop_times"` — `stop_times.txt`

No other tables are required.

### Validator registration

Required tables: `["stop_times"]`.

Feature flag: none needed. The validator runs whenever `stop_times.txt` is
present and satisfies the column guards.

### Notice code derivation

The Java class is `ForbiddenShapeDistTraveledNotice`. The Python notice code
follows snake_case convention: `"forbidden_shape_dist_traveled"`.
