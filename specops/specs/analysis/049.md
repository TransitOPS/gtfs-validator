# Analysis: RouteColorContrastValidator

## 1. Purpose

Validates that `route_color` and `route_text_color` in `routes.txt` have sufficient luminance contrast so that text remains legible against the route background color.

## 2. Input tables

| Table | Columns used |
|---|---|
| `routes.txt` | `route_id`, `csv_row_number`, `route_color`, `route_text_color` |

No other tables are read. This is a single-table, per-row validator.

## 3. Validation logic

### Step 1: Guard — skip rows where either color is absent

If a route row does not have an explicit `route_color` value OR does not have an explicit `route_text_color` value, skip that row entirely. No notice is emitted for rows with missing color fields.

In Python: filter the `routes` DataFrame to rows where both `route_color` and `route_text_color` are non-null.

### Step 2: Compute Rec 601 luma for each color

For each color stored as a 6-digit hex string (e.g., `"FFFFFF"`), compute its Rec 601 luma using the formula:

```
luma = int(0.30 * R + 0.59 * G + 0.11 * B)
```

where R, G, B are the 8-bit integer channel values extracted from the hex string. The result is an integer in the range [0, 255].

The W3C Rec 601 formula coefficients reflect human perception of brightness (green contributes most, blue least).

### Step 3: Compare luma difference against threshold

Compute the absolute difference between the two luma values:

```
luma_diff = abs(luma(route_color) - luma(route_text_color))
```

The threshold constant is `MAX_ROUTE_COLOR_LUMA_DIFFERENCE = 72`.

- If `luma_diff < 72`: emit a `route_color_contrast` WARNING for that row.
- If `luma_diff >= 72`: the colors are sufficiently contrasting — no notice.

Note: the comparison is strict less-than. A difference of exactly 72 does **not** trigger a notice.

## 4. Notices emitted

### `route_color_contrast` (WARNING)

Emitted when both `route_color` and `route_text_color` are present but their Rec 601 luma difference is less than 72.

| Field | Type | Source | Description |
|---|---|---|---|
| `route_id` | string | `routes.route_id` | ID of the offending route record |
| `csv_row_number` | integer | `routes.csv_row_number` | Row number of the offending route record |
| `route_color` | string | `routes.route_color` | The route's background color as a 6-digit hex string (without `#`) |
| `route_text_color` | string | `routes.route_text_color` | The route's text color as a 6-digit hex string (without `#`) |

Severity: WARNING.

Java class: `RouteColorContrastNotice`.

Python notice code: `route_color_contrast`.

## 5. Edge cases

| Scenario | Expected behavior |
|---|---|
| `routes.txt` absent from feed | Return no notices immediately. |
| `routes.txt` present but empty | Return no notices. |
| `route_color` is null/absent for a row | Skip that row; no notice. |
| `route_text_color` is null/absent for a row | Skip that row; no notice. |
| Both colors absent for a row | Skip that row; no notice. |
| Both colors present and identical | Luma diff = 0 < 72; emit WARNING. |
| Both colors present with diff exactly 72 | Diff is not less than 72; no notice (passes). |
| Both colors present with diff exactly 71 | Diff < 72; emit WARNING. |
| White (`FFFFFF`) vs black (`000000`) | Luma diff = 255 >= 72; no notice (passes). |
| Two near-identical dark colors, e.g. `4a4444` vs `3d3838` | Luma diff = 12 < 72; emit WARNING. |
| `route_color` column entirely absent from file | All rows treated as null for that field; all rows skipped; no notices. Schema loading must guarantee column presence or the null-guard handles it. |

## 7. Implementation notes

### Luma helper function

The Rec 601 luma calculation must be implemented as a reusable pure helper, since it is applied to two separate color columns. The formula is:

```python
def rec601_luma(hex_color: str) -> int:
    """Compute Rec 601 luma [0, 255] from a 6-digit hex color string (no '#')."""
    v = int(hex_color, 16)
    r = (v & 0xFF0000) >> 16
    g = (v & 0x00FF00) >> 8
    b = (v & 0x0000FF)
    return int(0.30 * r + 0.59 * g + 0.11 * b)
```

The Java implementation uses integer truncation (cast to `int`), not rounding. Python's `int()` also truncates, so behavior is identical.

### Polars approach

The luma computation can be done entirely with Polars expressions to avoid Python-level row iteration.

```python
MAX_ROUTE_COLOR_LUMA_DIFFERENCE = 72

def _hex_luma_expr(col_name: str) -> pl.Expr:
    """Compute Rec 601 luma from a 6-digit hex color column."""
    v = pl.col(col_name).str.to_integer(base=16)
    r = (v >> 16) & 0xFF
    g = (v >> 8) & 0xFF
    b = v & 0xFF
    return (r.cast(pl.Float64) * 0.30 + g.cast(pl.Float64) * 0.59 + b.cast(pl.Float64) * 0.11).cast(pl.Int32)
```

Then the validation filter:

```python
routes = feed.get("routes")
if routes is None or routes.is_empty():
    return []

# Only process rows where both colors are present
both_present = routes.filter(
    pl.col("route_color").is_not_null() & pl.col("route_text_color").is_not_null()
)
if both_present.is_empty():
    return []

flagged = both_present.with_columns([
    _hex_luma_expr("route_color").alias("_luma_color"),
    _hex_luma_expr("route_text_color").alias("_luma_text"),
]).filter(
    (pl.col("_luma_color") - pl.col("_luma_text")).abs() < MAX_ROUTE_COLOR_LUMA_DIFFERENCE
)

notices: list[Notice] = []
for row in flagged.iter_rows(named=True):
    notices.append(Notice(
        code="route_color_contrast",
        severity=Severity.WARNING,
        fields={
            "route_id": row["route_id"],
            "csv_row_number": row["csv_row_number"],
            "route_color": row["route_color"],
            "route_text_color": row["route_text_color"],
        },
    ))
return notices
```

`iter_rows` is acceptable here because the number of color-contrast violations is expected to be small. The heavy lifting (hex parsing, luma math, filtering) is all done in Polars before iteration.

### Threshold constant

`MAX_ROUTE_COLOR_LUMA_DIFFERENCE = 72` — define at module level.

The Java validator comment notes that W3C WCAG recommends 125 for normal body text, but GTFS route colors are large display elements (line name logos), so a more permissive threshold of 72 is intentionally used.

### Validator registration

Required tables: `["routes"]`.

Guard: skip if `"routes"` is absent from the feed dict or is an empty DataFrame.
